## 1. KDPを開いて、新しいペーパーバックを作る

```bash
start https://kdp.amazon.co.jp/
```

1. 黄色い **「サインイン」** ボタンを押し、Amazonのアカウントでログイン（**パスワード入力は本人**）
2. 上のメニューの **「本棚」** を押す
3. 画面左上の **「＋ 作成」**（または「新しいタイトルを作成」）を押す
4. 「ペーパーバック」の下の **「ペーパーバックを作成」** を押す

→ 3つのタブ「ペーパーバックの詳細」「ペーパーバックのコンテンツ」「ペーパーバックの価格設定」が並んだ画面になる。

### カテゴリー

**「カテゴリーを選択」** を押し、出てきた窓の検索欄に `塗り絵` と打つ。出てきた候補から最大3つ。
選ぶ基準：①大人向けの塗り絵 ②風景・旅・地域（北海道）③絵画・イラストの技法。
選んだら **「カテゴリーを保存」**。何が出たか分からなければ、その画面のスクリーンショットを送ってもらえれば選ぶ。

### シリーズについて（推奨）

全47都道府県を並べるので、最初から**シリーズ**にしておくと、Amazonの商品ページに「シリーズの他の本」が並ぶ。

| 項目 | 推奨 |
|---|---|
| シリーズ名 | `大人の旅ぬりえ` |
| この本の番号 | **1**（都道府県コードの順にすると、北海道＝1、青森＝2 … 沖縄＝47。地方版・東西版・全国版は48以降） |

## 3. タブ2「ペーパーバックのコンテンツ」

### ISBN

1. **「無料のKDP ISBNを取得」** を選ぶ
2. **「ISBNを割り当てる」** を押す → 確認の窓で **「ISBNを割り当てる」** をもう一度
   ⚠ **ISBNを割り当てると、書名・副題・著者名は変更できなくなる。** 割り当て前に、タブ1の文字をもう一度見直す
3. 「ローコンテンツ本」のチェックは**入れない**（解説ページがあるので通常の本として出す。ISBNが付き、「なか見!検索」も使える）

### 出版日
空欄のまま。

### 印刷オプション

| 欄 | 選ぶもの |
|---|---|
| インクと用紙の種類 | **白黒インクと白い用紙** |
| 判型 | **「別の判型を選択」** → **21.0 × 29.7 cm（A4）** |
| 裁ち落とし設定 | **裁ち落としなし** |
| 表紙の仕上げ | **つや消し（マット）** ※えんぴつ画の落ち着いた色に合う。光沢のほうが色は鮮やか。好みで |
| 読む方向 | **左から右（横書き）** |

### 原稿
**「原稿をアップロード」** → `hokkaido_interior.pdf` を選ぶ → 「アップロード完了」まで待つ（86MBなので数分）

### 表紙
1. **「既に用意してある表紙をアップロード」**（「表紙作成ツール」ではない方）を選ぶ
2. **「表紙ファイルをアップロード」** → `hokkaido_cover.pdf` を選ぶ
3. 「バーコード」について聞かれたら、**KDPにバーコードを入れてもらう**方（そのまま）でよい。裏表紙の右下を空けてある

### AI生成コンテンツ（必須の申告）

**「はい」** を選び、出てきた項目を次のとおり入れる。

| 種類 | 使ったか | 量・編集の程度 | ツール名 |
|---|---|---|---|
| 文章 | **はい** | 本全体（解説文・使い方・内容紹介をAIが下書きし、著者が確認・修正） | `Claude` |
| 画像 | **はい** | 本全体（表紙・本文の絵すべて。作り直し・部分修正あり） | `Gemini` |
| 翻訳 | いいえ | — | — |

申告は販売ページには表示されない。申告しないとKDPの規約違反になる。

### 本のプレビュー
1. **「プレビューアーを起動」** を押す（変換に数分）
2. 右の欄に「問題」が出ていないか見る。**1件でも出たら、そのまま画面のスクリーンショットを送る**
3. 何ページかめくって、ぬりえが右ページ、解説が左ページになっていることを確かめる
4. 問題なければ右下の **「承認」** を押す

画面下の「印刷コスト」が **530円** と出ていることを確認（A4・白黒・110ページ以下の固定料金）。

黄色い **「保存して続行」** を押す。

## 5. 校正刷り（推奨）と出版

### 校正刷り（実物を1冊取り寄せる）
40枚のうち23枚は小さい元画像を約2.7倍に拡大している。**画面では分からない印刷のにじみを、実物で一度確かめるのが安全。**
価格設定タブの下のほう **「校正刷りを注文」** → 冊数 `1` → **「校正刷りを注文」** → Amazonのカートで購入（**支払いは本人**）。
届いたら、特に 04羊ヶ丘・15大雪山・31味噌ラーメン あたり（拡大率の大きい絵）の細い線を見る。

### 出版
**⚠ ここで一度止まる。押す前に「出版してよいか」を最終確認する。**
画面いちばん下の黄色い **「ペーパーバックを出版」** を押すと審査に入る（最大72時間）。審査が通るとAmazonに並ぶ。

## 困ったとき

- プレビューアーで「余白の外にコンテンツがあります」等が出た → スクリーンショットを送る（ぬりえは紙の端から12mm以上離してある）
- 「表紙のサイズが合わない」と出た → ページ数が86でないと背幅が変わる。プレビューアーの総ページ数を確認して教える
- 画面の文言がこの手順と違う → スクリーンショットを送る。**推測で総当たりしない**（Etsyで丸1日溶かした教訓）
