**弁護士の見解ではなく、条文と公開情報に基づく調査。** 迷うものは公開前に専門家か施設に確認する。

## 判断の根拠（全題材に共通・以後の都道府県でも使う）

### 1. 建物は描いて売ってよい（著作権法46条）

屋外に恒常的に設置された「建築の著作物」は、**どんな方法でも利用できる。** 例外は4つだけ:

| 号 | 例外 | ぬりえに関係するか |
|---|---|---|
| 1号 | 彫刻を増製して売る | しない |
| 2号 | **建築の著作物を建築で複製**して売る（同じ建物を建てる） | しない |
| 3号 | 屋外に恒常設置するための複製 | しない |
| 4号 | **専ら美術の著作物**の複製物の販売目的 | **建物には適用されない。ただし銅像・彫刻（美術の著作物）には適用される** |

→ 建物のぬりえ本は、新しい建物でも古い建物でもOK。
→ **屋外の銅像・モニュメントを主役にしたページは4号に当たりうる。** 作者の没後70年を過ぎたものだけにする。
→ **屋内の展示物は46条の対象外**（屋外でないため）。描かない。

米国（Amazon.comで売る場合）も同様で、公共の場所から見える建物の絵・写真は著作権侵害にならない（17 U.S.C. §120(a)）。

### 2. 一番の落とし穴は「下絵の元にした写真」

建物は自由でも、**他人が撮った写真には撮影者の著作権がある。** 構図・アングル・切り取り方まで
そのまま線画にすると、写真の複製・翻案になりうる。

| 下絵の作り方 | リスク |
|---|---|
| 自分で撮った写真から起こす | ◎ 最も安全 |
| 生成AIで描かせる（特定の写真を入力しない） | ○ ただし有名な写真の構図そっくりに出たら作り直す |
| 複数の資料を見て構図を自分で組み直す | ○ |
| **ネットの写真1枚をトレース** | ✕ 避ける |
| **自治体の観光写真ライブラリの写真を元にする** | ✕ 避ける（下記） |

**札幌の公式写真ライブラリ（ようこそさっぽろ）は使わない。** 商用利用可とあるが、
「写真集、素材集、絵はがきなど、画像そのものを目的とした商用利用」は禁止、
用途は「札幌の観光振興に寄与するもの」に限定されている。ぬりえの下絵はこの禁止に近い。

### 3. 名称（商標）は説明として使う分には問題ない

「札幌時計台」「さっぽろテレビ塔」を、そのページの題材名・本の内容紹介として書くのは、
商品の内容を説明する使い方なので一般に商標権侵害にならない（商標法26条）。
ただし次はしない:

- 施設の**ロゴ・公式マーク**を描く、表紙に載せる
- 「公式」「○○監修」など、**施設公認の商品だと誤解させる**書き方
- 書名を施設名だけにする（例:「さっぽろテレビ塔」という題の本）

※ さっぽろテレビ塔の商標登録の有無は今回未確認。上記の使い方なら登録の有無に関係なく安全側。

### 4. キャラクター・看板・広告は描かない

ご当地キャラ・マスコット・施設のキャラクターは、建物と違って**46条で自由にならない**（美術の著作物）。
建物に付いている看板・広告・ポスターも省いて描く。

### 5. 自分で撮影に行くとき

公道から外観を撮るのは自由。**敷地内・館内での商用目的の撮影は、施設ごとに申請が要る場合がある**
（札幌市は時計台について「各施設に問い合わせ」としている）。撮るなら公道から、または事前に施設へ確認。

### 6. KDP側のルール

- 生成AIで作った絵（中身・表紙とも）は、**出版時の質問で「AI生成」と申告が必須**。申告しても販売ページには出ない
- 権利の確認責任は出版者側にある、と明記されている
- 内容を説明する書名・説明文に施設名を入れること自体は問題ない（上記3）

## 題材ごとのメモ

### 札幌時計台
- 1878年完成。設計は開拓使の技術者で、著作権はとうに消滅。国の重要文化財、札幌市所有
- 描いてよい: 外観、時計、星のマーク（開拓使の北極星。150年前のもので権利なし）
- 注意: 館内撮影は施設に要確認。公式写真ライブラリの写真は下絵に使わない

### さっぽろテレビ塔
- 1957年完成。設計の内藤多仲は1970年没 → 建築の著作権は2040年末まで残る計算。
  **ただし屋外の建築なので46条で描いてよい**（2号の「建築で複製」にしか当たらない）
- **描かない: 「テレビ父さん」**（塔の人気キャラクター。グッズ販売されている。権利者不明＝使えない）
- 塔の電光時計の表示は描いて問題ないが、企業広告が出ている時期の写真を元にするなら広告部分は省く

### 北海道庁旧本庁舎（赤れんが庁舎）
- 1888年完成。重要文化財。北海道所有
- 2022〜2024年度に改修、**2025-07-25にリニューアルオープン済み**。外観は保存・復原なので従来どおり描ける
- 注意: 前庭の池・樹木はそのまま描いてよい。新設のレストラン・カフェのロゴは描かない

### 五稜郭
- 1864年完成の星形の西洋式城郭。特別史跡。著作権の問題なし
- 描いてよい: 星形の全景（上空から）、堀と桜、石垣、**箱館奉行所**（2010年に函館市が復元。屋外の建築なので46条でOK）、**五稜郭タワー**の外観（同じく建築）
- **描かない: 五稜郭タワー館内の土方歳三のブロンズ像**（屋内の美術の著作物＝46条の対象外）
- 史跡内で商用目的の撮影をするなら、函館市（五稜郭公園・箱館奉行所の管理者）に事前確認。条件は今回の調査では未確認
