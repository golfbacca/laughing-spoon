# 09 Canvaで表紙の文字を入れる手順（2026-11-18）

本人がCanvaで書名・副題を入れて試すための素材と手順。

## 素材（`kdp_coloring/hokkaido/canva/`）

| ファイル | 中身 |
|---|---|
| `帯だけ_著者名あり.jpg` | パターンCから**書名・副題だけを抜いた**もの。白い帯・著者名・下絵の円とラベル・裏表紙はそのまま |
| `帯だけ_文字なし.jpg` | 表紙の文字を**全部抜いた**もの（書名・副題・著者名・円のラベル）。円そのものと裏表紙は残す |
| `位置ガイド.jpg` | どこに何を置いてよいかの図（見るだけ。Canvaには入れない） |

どちらも 5095×3582ピクセル・300dpi ＝ **16.984×11.940インチ**（裏表紙＋背＋表紙＋裁ち落とし）。KDPの表紙と同じ大きさ。

### 位置ガイドの見方

| 色 | 意味 |
|---|---|
| 赤 | 仕上がり線。外側0.125inは裁ち落とされる。中央の2本の赤い縦線の間が背（幅0.19in） |
| 青 | 文字を置いてよい範囲（仕上がり線から0.375in内側） |
| 緑 | 白い帯。書名・副題はこの中に |
| 黄 | KDPがバーコードを自動で入れる場所。何も置かない |

## Canvaでの手順

### 1. 表紙と同じ大きさのデザインを作る
1. Canvaを開く
```bash
start https://www.canva.com/
```
2. 画面右上の **「デザインを作成」**（紫のボタン）を押す
3. 出てきた窓の下のほう **「カスタムサイズ」** を押す
4. 単位の欄（「px」と出ている）を **「in」**（インチ）に切り替える
5. 幅に `16.984`、高さに `11.94` を入れる
6. **「新しいデザインを作成」** を押す

### 2. 画像を背景に敷く
1. 画面左の縦メニュー **「アップロード」** を押す
2. **「ファイルをアップロード」** を押し、`帯だけ_著者名あり.jpg`（または `帯だけ_文字なし.jpg`）を選ぶ
3. アップロードされた画像を、真ん中の白いページの上へドラッグして置く
4. 置いた画像を右クリック → **「画像を背景として設定」** を押す（ページぴったりに広がる）

### 3. 書名・副題を入れる
1. 左の縦メニュー **「テキスト」** → **「見出しを追加」** を押す
2. 出てきた文字を `大人のぬりえ 北海道めぐり` に書き換える
3. 上のバーのフォント名の欄を押して、フォントを選ぶ。大きさの欄で文字の大きさを変える
4. 文字をドラッグして、**右半分（表紙）の白い帯の中**へ動かす。左右の位置は、ドラッグ中に出る紫の中心線に合わせると真ん中にそろう
5. 同じように **「小見出しを追加」** で副題 `繊細なえんぴつデッサンで描く 名所・自然・味覚の40景` を入れる

⚠ 文字を表紙の端（右端・上端）や、背に近い左端に寄せすぎない。**位置ガイドの青い枠の内側**に収める。

### 4. KDP用のPDFで書き出す
1. 画面右上の **「共有」** を押す
2. **「ダウンロード」** を押す
3. ファイルの種類で **「PDF（印刷）」** を選ぶ
4. **「トリムマークと塗り足し」のチェックは入れない**（画像にすでに裁ち落とし分が入っている。入れると大きさがずれてKDPで弾かれる）
5. **「ダウンロード」** を押す

できたPDFを送ってもらえれば、大きさ（16.984×11.940in）・文字の位置・フォントの埋め込みをこちらで検査する。

## 注意

- **Canvaの「Pro」マーク（王冠）が付いた素材やフォントは、無料プランでは透かしが入る。** 書き出したPDFに透かしが無いか必ず見る
- Canvaのフォントは、Canvaのライセンスの範囲で本の表紙に使える。王冠マーク付きはProの契約中のみ
- 書名の文字を変えると、KDPに登録する書名と違ってしまう。**表紙の書名・副題は、KDPに入れる文字と一字一句同じにする**（違うと審査で差し戻される）
