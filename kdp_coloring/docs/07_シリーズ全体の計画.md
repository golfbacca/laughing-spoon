# 07 シリーズ全体の計画（2026-11-18）

## 本人の決定

- **全都道府県分を作る**（47冊）
- 加えて **各地方版・東日本版／西日本版・全国版** も出す
- **絵はダブらせない**（1枚の絵は1冊にしか入れない。`02` のC「重複」リスク対策と一致）
- **「ダブらせない」は解釈A**：絵が別なら、同じ名所を別の本に入れてよい（2026-11-18 本人）
- **1都道府県40枚はマスト**（30枚に減らす案は不採用）

- **絵は表（右ページ）だけ。裏に絵は入れない**（北海道版の組み方＝ぬりえは右ページ、裏は文字の解説、で既に満たしている）

## 決めておきたいこと（本人に確認）

### 1. 同じ名所を、別の絵で別の本に入れてよいか → **A（本人決定）**

「絵はダブらせない」が**絵の使い回し禁止**なのか、**題材（名所）のかぶりも禁止**なのかで、計画が大きく変わる。

| 解釈 | 例 | 影響 |
|---|---|---|
| A：絵だけ別ならよい | 青森県版にねぶた（夏・正面）、東北版にねぶた（夜・横から）、全国版にねぶた（祭りの通り） | 地方版・全国版でも各地の代表的な名所を出せる。売れる題材を外さずに済む |
| B：題材もかぶらせない | 東北版には、6県の県版に入らなかった名所だけ | 地方版・全国版が「2軍の名所集」になり、売れにくい |

**推奨はA。** KDPの重複判定は「同じ内容の本」を見る。題材が同じでも絵が違えば別の内容。
買う側にとっても、全国版に東京タワーや富士山が無いのは不自然。

### 2. 小さな県で40題材が埋まるか → **40枚はマスト（本人決定）。名所だけで足りない県は、自然・生きもの・味覚・祭り・工芸で埋める**

東京・京都・北海道は余るほどあるが、鳥取・佐賀などは40の名所を立てると、地方版・全国版と合わせて同じ題材を何度も描くことになる。
→ **県版は30枚でもよいことにする**（KDPのぬりえは24ページ以上が目安。30枚なら解説込みで約66ページ）。題材の数で県ごとに決める。

### 3. 出版の順番と速さ

- KDPの新刊は**1日3冊まで**（2023年からの制限。現在も有効かは未確認）
- 1冊の制作（下絵40枚の生成・検査・作り直し、解説文、組版、表紙）は、北海道版の実績で数日〜1週間
- **最初は観光客の多い道府県から**（売れ筋で早く学ぶ）：北海道 → 京都 → 東京 → 沖縄 → 大阪 → 奈良 → 神奈川（鎌倉・箱根）→ 長野 …
- ~~北海道版を出して売れ方を見てから量産する~~ → **本人方針：棚に並べることを最優先し、全都道府県を順次出す**

## 作業の流れ（北海道版で確立した手順）

1. 題材40案を作る（権利の検査つき：`01` のチェック表）
2. Geminiで下絵を生成（**大きいサイズ・縦長**。共通条件の英語を付ける。`prompts/北海道_40案.md`）
3. ZIPで受け取り、`tools/check_lineart.py` で検査（解像度・透かし・色かぶり）＋目視で実物と照合
4. 作り直し（指示文は種の特徴・実物の特徴を言葉で全部書く。`04`）
5. 解説文（事実確認つき。`05`）
6. `tools/build_pages.py` → `tools/make_content.py` → `tools/build_interior.py` で本文PDF
7. 表紙：1枚をGeminiで彩色 → `tools/build_cover.py`
8. KDPで登録（本人が操作）

**北海道版の学び（次の県で最初から守る）**
- 最初から**縦長・大きいサイズ**で出す（横長3枚・小さい30枚の手戻りがあった）
- 生き物は種の特徴を全部書く（タンチョウの首が白くなった）
- 建物は「無いもの」も書く（赤れんがに時計が付いた、旗が付いた）
- 枠線のずれを数値で検査する（ペンギン）
