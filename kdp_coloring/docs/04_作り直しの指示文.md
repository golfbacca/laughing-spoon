# 04 作り直しの指示文（Gemini用・2026-11-14）

## 共通の注意

- **Geminiの設定で `Media watermark` を Off** にしてから作る（✦が入らない）
- **大きいサイズで出す。** ZIP2の6枚（1728×2464）と同じ方法で作ると、そのまま223dpi。標準の864×1232は111dpiしか無い
- **縦横比は 3:4** が本のページ（8.5×11in＝0.77）に一番近い
- **他人の写真を読み込ませない。** 言葉だけで指示する
- 出来上がったら ZIP で渡す → `tools/check_lineart.py` で検査

## P03 札幌時計台（手前の情景を実物に合わせる）

```
大人向けぬりえの1ページ。札幌時計台（旧札幌農学校演武場）の正面を描いてください。
白い下見板張りの2階建て木造洋館。切妻屋根の正面中央に四角い時計塔が載り、時計塔の正面に丸い時計。
正面の三角の妻壁に小さな五つ星の飾りが2つ並ぶ。その下に文字のない横長の板。
1階中央に小さな張り出し玄関。
建物の両脇に葉の落ちた広葉樹、手前に低い石の門柱と歩道、古風な街灯。
背景には高層ビルが2〜3棟（都心の街中にある雰囲気）。
季節は冬、屋根と地面に雪。
黒い細い線だけの線画、白背景、グレーの塗りや濃い陰影は入れない。
文字・看板・ロゴ・人物は描かない。縦長、縦横比3:4、周りに細い枠線。
```

**実物との照合（2026-11-14・本人提供の写真で確認）:** 背景に高層ビル、妻壁に赤い五つ星2つ、
その下に黒い横長の板、張り出し玄関、石の門柱、葉の落ちた広葉樹、街灯。
前回の絵は森の中の曲がった小道・針葉樹で、ここが実物と違っていた。

**語の選び方:** 「文字・看板は描かない」は前回の崩れた看板対策。「周りにビル」で実物の街中の立地を出す。

## P29 ペンギン（旭山動物園の「ペンギンの散歩」に変える）

```
大人向けぬりえの1ページ。冬の動物園で、キングペンギンが4〜5羽、一列になって雪の道を歩いている場面。
道の両側に雪の壁と低いロープの柵、奥に冬の木立と動物園の低い建物。
観客や飼育員は描かない。
黒い細い線だけの線画、白背景、グレーの塗りや濃い陰影は入れない。
文字・看板・ロゴは描かない。縦長、縦横比3:4、周りに細い枠線。
```

**語の選び方:** 旭山動物園で散歩するのはキングペンギン。動物園の名前は絵に入れず、**解説ページで「旭山動物園の冬の名物」と書く**（名前を説明として使う分には問題ない）。
観客を描かないのは、人の顔や服のロゴが崩れて出るのを防ぐため。

## P04 赤れんが庁舎（ドームの時計を外す）

```
大人向けぬりえの1ページ。札幌の北海道庁旧本庁舎（赤れんが庁舎）の正面を描いてください。
左右対称の2階建てれんが造りの洋館。中央の屋根の上に八角形の塔があり、その上に丸いドーム。
ドームの正面には半円形の小さな窓が1つだけ。時計は無い。ドームの頂上に手すりと細い旗竿。
屋根には小さな三角の屋根窓がいくつも並び、れんがの煙突が何本も立つ。
1階中央に半円アーチの玄関。
手前は左右対称の芝生と、正面へまっすぐ延びる広い通路。通路の両側に円すい形に刈り込んだ低木と松の木。
背景に高層ビルが2棟ほど。季節は初夏。
黒い細い線だけの線画、白背景、れんがの目地は細い線で、グレーの塗りや濃い陰影は入れない。
文字・看板・ロゴ・人物は描かない。縦長、縦横比3:4、周りに細い枠線。
```

**実物との照合（2026-11-14・本人提供の写真で確認）:** 八角塔のドームに**時計は無く、半円窓の小窓**。頂上に旗。
屋根窓と煙突が多数、正面アーチ玄関、左右対称の前庭と円すい形の低木、背景に高層ビル。
前回の絵（P04）はドームに時計が描かれていた（札幌時計台と混ざったとみられる）。
**「時計は無い」と明記するのが今回の修正点。**

※照合に使った写真は札幌観光写真ライブラリのもの。素材集・写真集のような使い方が禁止されているので、**Geminiに読み込ませない。**
