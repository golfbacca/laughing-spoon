## 共通の注意

- **Geminiの設定で `Media watermark` を Off** にしてから作る（✦が入らない）
- **各指示文の最後に、元の40案の「共通で必ず付ける条件」（英語）をそのまま付ける**
- **判型はA4縦のままでよい。** KDPのペーパーバックにはA4（8.27×11.69in）の判型がある。既存の下絵（864×1232＝0.701）もA4（0.707）とほぼ同じ形
- **四辺10mmの余白も妥当。** KDPの余白の下限は外側6.4mm、綴じ側は150ページ以下で9.6mm（151ページ以上は12.7mm）
- **大きいサイズで出す。** ZIP2の6枚（1728×2464）は、Geminiの出力をさらに別のAIで加工したもの（本人談・詳細は思い出し中）
- **他人の写真を読み込ませない。** 言葉だけで指示する
- 出来上がったら ZIP で渡す → `tools/check_lineart.py` で検査

## P04 赤れんが庁舎（元案#7に、実物との照合結果を足す）

```
赤レンガ造りの北海道庁旧本庁舎を正面から描く。左右対称の2階建ての洋館で、中央の屋根の上に八角形の塔、その上に丸いドーム。

建物のレンガ模様、窓、屋根の細部を繊細な鉛筆線で表現。グレースケール陰影付きデッサン風塗り絵、文字・人物・旗・ロゴなし。
```
＋共通条件

**実物との照合（札幌観光写真ライブラリの写真）：** ドームに**時計は無く、半円窓の小窓**。前回の絵は時計台と混ざって時計が付いていた。

旗竿は実物にあるが、元案の「旗なし」を守り、竿だけにした。
※照合に使った写真は写真ライブラリの規約上、素材としての利用が禁止。**Geminiに読み込ませない。**

## P29 ペンギン（元案#38を、実際の「ペンギンの散歩」に寄せる）

元案は「実在施設を描かない」ために雪の野外を歩かせたが、**北海道に野生のペンギンはいない**ので誤解を招く。
施設名や建物の特徴は出さず、「冬の動物園の散歩」と分かる程度にする。

```
冬の動物園で、キングペンギンが4〜5羽、一列になって雪の散歩道を歩く場面。
道の両側に雪の壁と低いロープの柵、奥に冬の木立。特定の動物園と分かる建物や看板は描かない。観客や飼育員も描かない。
ペンギンの羽毛や雪面を繊細な鉛筆線で表現。グレースケール陰影付き塗り絵、文字・人物・ロゴなし。
```
＋共通条件

**語の選び方：** 旭山動物園で散歩するのはキングペンギン。動物園の名前は絵に入れず、**解説ページで「旭山動物園の冬の名物」と書く**（名前を説明として使う分には問題ない）。
