# 04 作り直しの指示文（Gemini用・2026-11-14）

## 共通の注意

- **Geminiの設定で `Media watermark` を Off** にしてから作る（✦が入らない）
- **大きいサイズで出す。** ZIP2の6枚（1728×2464）と同じ方法で作ると、そのまま223dpi。標準の864×1232は111dpiしか無い
- **縦横比は 3:4** が本のページ（8.5×11in＝0.77）に一番近い
- **他人の写真を読み込ませない。** 言葉だけで指示する
- 出来上がったら ZIP で渡す → `tools/check_lineart.py` で検査

## P03 札幌時計台（手前の情景を実物に合わせる）

```
大人向けぬりえの1ページ。札幌時計台（旧札幌農学校演武場）の正面を描いてください。
白い下見板張りの2階建て木造洋館で、屋根の上に時計塔。時計塔の正面に丸い時計。
建物は街の中心にあり、周りには低めのビルが少し見える。建物の前には小さな芝生と植え込み、低い柵、歩道。
季節は冬、屋根と植え込みに雪。
黒い細い線だけの線画、白背景、グレーの塗りや濃い陰影は入れない。
文字・看板・ロゴ・人物は描かない。縦長、縦横比3:4、周りに細い枠線。
```

**語の選び方:** 「文字・看板は描かない」は前回の崩れた看板対策。「周りにビル」で実物の街中の立地を出す。

## P25 森と湖（アイヌ文様を外す）

元の絵は秋の森・湖・とがった山。**支笏湖と恵庭岳**の構図に近いので、題材をそこに固定する。

```
大人向けぬりえの1ページ。北海道の支笏湖と、その奥にそびえる恵庭岳を、湖畔の森から眺めた秋の風景。
手前に白樺とカエデの木、湖面、遠くに山。
木の幹は自然な樹皮だけにし、模様や装飾は入れない。

文字・看板・人物は描かない。縦長、縦横比3:4、周りに細い枠線。
```

**語の選び方:** 「幹に模様や装飾を入れない」が今回の修正点そのもの。

## P29 ペンギン（旭山動物園の「ペンギンの散歩」に変える）

```
大人向けぬりえの1ページ。冬の動物園で、キングペンギンが4〜5羽、一列になって雪の道を歩いている場面。
道の両側に雪の壁と低いロープの柵、奥に冬の木立と動物園の低い建物。
観客や飼育員は描かない。
黒い細い線だけの線画、白背景、グレーの塗りや濃い陰影は入れない。
文字・看板・ロゴは描かない。縦長、縦横比3:4、周りに細い枠線。
```

**語の選び方:** 旭山動物園で散歩するのはキングペンギン。動物園の名前は絵に入れず、**解説ページで「旭山動物園の冬の名物」と書く**（名前を説明として使う分には問題ない）。
観客を描かないのは、人の顔や服のロゴが崩れて出るのを防ぐため。
