# 10 購入者特典：彩色済みサンプルをnoteで見せる（2026-11-19・検討）

## 本人の案
note（https://note.com/）に、40ページ全部の**彩色済みサンプル**を載せる。
**本を買った人だけが見られる**ように、URLは「なか見!検索」など購入前に見られる場所以外（奥付など）に載せたい。

## 調べて分かったこと

| 論点 | 結果 |
|---|---|
| noteに「URLを知っている人だけ見られる」機能はあるか | **確認できなかった。** 通常の記事は公開され、プロフィールの記事一覧やnote内検索・Google検索から誰でも見られる。近い機能は note pro の「LINE友だち限定」（2025年7月〜、月9,800円。全ユーザー向けの有料機能化が予告されていた） |
| 本にURLを載せてよいか | 本文中のURLを直接禁じる規定は見つからなかった。**禁止なのは商品ページ（内容紹介・A+）へのURL**。電子書籍では「読書体験を高めるリンク」は可。購入者向けの色見本はこれに当たる |
| 「なか見!検索」で見えるページ | 割合は公表されていない（体験談では冒頭10〜20%）。**さらに「Surprise me（ランダム表示）」で途中のページも見え、紙の本でも本文の文字検索ができる**。→ **どのページなら絶対に見えない、とは言えない** |

## 推奨

1. **URLは文字で書かず、QRコードだけにする**（文字検索で拾われない）
2. **置く場所は巻末の「試し塗りのページ」**（色を試すページから色見本へ、で流れが自然。冒頭の数%には入らない）
3. **「完全に購入者限定」は無理と割り切る。** 載せる場所で「見つけにくくする」まで。漏れても困るのは彩色見本だけで、ぬりえ本体の価値は下がらない
4. 本当に限定したいなら、noteではなく**「リンクを知っている人のみ」で共有できる場所**（Googleドライブのフォルダ、Googleフォトの共有アルバム等）。検索にも出ない。ただしnoteのような見栄え・発信力は無い
5. noteで出すなら、**公開されてもよい前提で「特典ページ」として作る**。noteを宣伝の窓口にもできる（47都道府県を並べる時に効く）

## noteのページで避けること
- ほかの店（Amazon以外）での購入へ誘導するリンク
- 個人情報を集めるフォーム
- 彩色サンプルはAIで作ったことを一言書く（本の奥付と同じ扱い）
