## A. Geminiの下絵について

| 論点 | 結論 |
|---|---|
| 商用利用 | 可。Googleは生成物の所有権を主張しない。ただしGoogleの禁止用途ポリシーに従うことが前提 |
| **画像右下の ✦（Geminiの透かし）** | **本に載せてはいけない。** Geminiの設定に `Media watermark` の On/Off ができた（2026年）。**Offにして作り直すのが正規ルート**。消去ツールで消すのは「出所を偽る回避行為」として規約違反になりうるので使わない |
| 見えない透かし（SynthID） | 残るが問題なし。どのみちKDPでAI生成と申告するため |
| KDPの申告 | **中身・表紙ともAI生成と申告が必須**（手で修正しても「AI生成」扱い）。申告は販売ページに出ない |
| 下絵の著作権 | **日米とも、AIだけで作った絵には著作権が発生しにくい。** 他人に真似されても守りにくいということ。販売には支障なし。解説文・構成・自分で描き足した部分は自分の著作物になる |

### 下絵1枚ずつの検査項目（作成済みの下絵は全部これを通す）

1. 右下などに **✦ 透かし**が残っていないか
2. **ロゴ・看板・広告・企業名**が描き込まれていないか
3. **銅像・彫刻・キャラクター**が描き込まれていないか（`01` の判定表を参照）
4. **崩れた文字**（読めない日本語・英語風の文字列）が入っていないか
5. 実在の有名写真と**構図がそっくり**でないか
6. 線画として使えるか（グレーの塗り・影が残っていないか。KDPのぬりえで差し戻しが多い理由）

→ **下絵をZIPで添付してもらえれば、1〜4と6はこちらで数値・目視で検査できる。**

## B. 日本と米国の両方で売ることについて

- 権利面の結論は日米とも同じ。米国でも公共の場所から見える建物の絵は著作権侵害にならない（17 U.S.C. §120(a)）
- 名称の使用も、内容の説明である限り米国でも問題ない
- KDPは1冊を全マーケットに出せるが、**米国向けは英語の書名・説明・解説が必要**。
  日本語版と英語版は**別の本（別タイトル）として出す**ほうが検索で見つかる。
  → ただし下記Cの「重複」に注意（下絵が同じでも言語が違う版は、KDPでは翻訳版として通常扱われる）

## C. ★多展開（都道府県版・地方版・東西版・全国版）の最大リスク：同じ絵の使い回し

**同じ下絵を北海道版・東日本版・全国版に入れると、KDPの品質チェックで「既存の本とほぼ同じ内容」と判定される恐れがある。**

- KDPは、カタログ内の既存の本と**実質的に同じ本**を検出する仕組みを持つ（第三者の解説。Amazon公式の基準値は非公開）
- 同じ型・同じ構成のローコンテンツ本（ぬりえ等）を量産すると、審査が厳しくなりやすい
- 品質問題とされると、販売停止や販売ページへの警告表示、最悪はアカウント停止

### 対策（推奨：**1枚の下絵は1冊にしか入れない**）

| 版 | 中身の作り方 |
|---|---|
| 都道府県版 | その県の名所・名物を**主役の絵**で |
| 地方版 | 同じ名所でも**別アングル・別の季節・別の構図**で作り直す。名物・祭り・特産品の比率を上げる |
| 東日本版／西日本版 | 地方版とも重ならない絵で |
| 全国版 | 各県1〜2枚、**専用に描き直した絵**で |

Geminiなら描き直しの手間は小さいので、**使い回しによるアカウントリスクを取る理由がない。**

### もう1つの制約：1日に出せる新刊は3冊まで

KDPは2023年から**新規タイトルを1日3冊まで**に制限している（現在も有効かは要確認）。
都道府県×言語で100冊近くになるので、**計画的に分けて出す**必要がある。

## D. 表紙・裏表紙・目次・解説・着色サンプルの注意

| ページ | 注意点 |
|---|---|
| 表紙 | 施設のロゴ・公式マークは入れない。「公式」と書かない。**書名を施設名だけにしない**（例: ✕「さっぽろテレビ塔」 ○「北海道 名所めぐり ぬりえ」） |
| 書名・副題 | KDPは書名にキーワードを詰め込むのを禁止している。副題は内容の説明として自然な範囲で |
| 解説ページ | 年号・高さなどの**事実は自由に使える**。ただし**文章は自分で書く。** Wikipedia・公式サイト・観光サイトの文をコピーしない（WikipediaはCC BY-SAのため、写すと本全体に条件がかかる） |
| 着色サンプル | 自分の下絵を塗ったものなら問題なし。AIで塗った場合もAI生成の申告に含まれる |
| フォント | 表紙・解説に使うフォントが**商用利用可**か確認。Google Fonts（OFL）なら安全。「フリーフォント」でも商用不可のものがある |
| 目次 | 権利上の問題なし |
