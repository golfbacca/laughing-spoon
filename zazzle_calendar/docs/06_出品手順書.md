## 第2部 空の写真カレンダーに13枚を入れる

### 2-1 商品ページを開き、先にオプションを決める

1. 10-18 に開いた商品ページを開く

```bash
start "https://www.zazzle.com/pd/spp/pt-zazzle_calendar?color=white&size=standard&style=twopage_calendar"
```

2. 右上が `Sign In` ならログインする（本人）
3. 右側の選択肢を、上から順にこう合わせる

| 欄 | 選ぶもの | 理由 |
|---|---|---|
| `Start Date` | **January** ／ **2027** | 写真は1月始まりで並べてある |
| `Calendar Months` | **12 Months** | — |
| `Culture` | **English, U.S.** | 米国向け |
| `Holidays` | **United States Events and Holidays** | 米国の祝日が升目に入る |
| `Layout` | **Two Page**（右側の、紙が2枚に分かれた絵） | 本人が選んだ型 |
| `Size` | **Medium**（真ん中） | 出品はこのサイズだけにする（第4部） |
| `Wire Binding Color` | **白**（左の丸） | 写真の邪魔をしない |
| `Grid Transparency` | **Not Transparent** | 升目を読みやすく |
| `Grid Style` | **Classic Frameless**（左上） | いちばん控えめ。写真が主役 |

4. 黄色い `Add to Cart` の下の、**青い `Add your design`** をクリック

### 2-2 写真を入れる（1ページずつ）

編集画面：上に `Design` / `Options` / `Review`、左に縦のメニュー、右に縦のページ一覧（`Cover` → `Back` → `Back` → `Page 1` → `Page 2` …）。

**1枚目（表紙）の入れ方：**

1. 右のページ一覧で **`Cover`** をクリック
2. 左の縦メニューの **`Uploads`**（雲に上向き矢印の絵）をクリック
3. アップロードのボタンをクリック → `00_cover_snowfall.jpg` を選ぶ
4. アップロードが終わったら、出てきた写真の小さな絵を**クリック**（または真ん中の白い枠へドラッグ）
5. 写真が枠いっぱいに広がっているか見る
   - **枠の外側の灰色の線（11 in × 8.5 in の外枠）まで写真が届いていること**。緑の点線（Safe area）までではない
   - 届いていなければ、写真の角をつまんで外枠まで広げる（**縦横比は変えない**＝角をつまむ。辺の真ん中はつままない）
6. **ここでスクリーンショットを送る**（1枚目だけ。合っていれば残りも同じやり方）

**2枚目以降：**`Page 1` 〜 `Page 12` を順にクリックし、**上半分の写真の枠**に、第1部の表のファイルを同じ手順で入れる。
- `Page 1` の下半分が「January • 2027」になっていることを確かめてから入れる
- `Back`（2つ）は**何も入れない**

### 2-3 保存

左上に `Saved`（緑の点）と出ていれば自動で保存されている。

## 第4部 出品の画面（ここから先は画面を未確認）

1. 上の **`Review`** をクリック
2. 出品のボタン（`Post for Sale` / `Sell This` / `Sell it` のような名前）を探してクリック
   - **見つからなければスクリーンショットを送って止まる**
3. 出品の画面が開いたら、**まずスクリーンショットを送る**（欄の名前を確かめてから入力を案内する）

入れる中身（`02_出品文言_確定版.md` から）：

| 欄 | 入れるもの |
|---|---|
| 商品名（Title） | `02` 第1章 |
| 説明文（Description） | `02` 第2章（英語の部分だけ） |
| タグ（Tags・10個） | `02` 第3章 |
| カテゴリ | カレンダーに近いもの（Office & School か Home & Living。画面で確認） |
| ストアのカテゴリ | 0-4 で作った `Calendars` |
| 対象（Audience / Rating） | 全年齢（G） |
| ロイヤリティ（Royalty） | **10%（初期設定のまま）**。上げると客の払う値段が上がり、売れにくくなる。Pinterest 経由なら別に紹介料が入る（`04`） |
| **`Product Merchandising` → `Product Style Control`** | **`The current style and color only`**（サポートの回答どおり。ミディアムだけを売る） |
| **カスタマイズ** | **無効にする**（サポートの回答：客がデザインツールを開いて開始月などを変えられなくなる） |
| AI の申告 / `generativecontent` | **付けない**（写真は父の撮影。修正は切り抜きと、周りの画素で埋めるゴミ取りだけ） |

4. 全部入れたら、**公開ボタンを押す前に、画面全体のスクリーンショットを送って止まる**
5. こちらで確認してから、本人が公開ボタンを押す

## 第5部 公開後の確認（客の目で見る）

1. ブラウザの**プライベートウィンドウ**（Edge なら `Ctrl + Shift + N`）を開く
2. 公開した商品のページを開く（出品後の画面に出る URL）
3. 確かめること

| 確かめること | 望ましい状態 |
|---|---|
| `Size` | **Medium しか選べない** |
| `Start Date` | **変えられない**（変えられたら説明文の注意書きが頼り。サポートに再質問） |
| `Personalize` / `Add your design` | **出ない** |
| 値段 | ミディアムの値段（$22.95 前後。セール表示は変わる） |

4. アドレス欄の URL をコピーして送る
   - **`?` から後ろは消す**（`?rf=` が付いていたら特に。付いたままだと取り分が 15% に下がる）
   - これが Pinterest に貼る**素の商品 URL**になる

開始月を **January 2027** に固定して売るので、この商品は**2027年のカレンダー**になる。
