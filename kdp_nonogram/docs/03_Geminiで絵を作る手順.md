# 03 Geminiでドット絵を作り、ノノグラムに落とす手順（2026-11-24）

## なぜこの手順か

| 作り方 | 実績 |
|---|---|
| こちらが写真を見て手で描く | 20×20の4点中、使えたのは1点（たぬき） |
| 本人がGeminiに描かせた絵を、こちらが30×30に落とす | 4点中3点が採用（柴犬・丹頂・和傘） |

本人が使ったプロンプト（2026-11-24 本人談）:

```text
ドット絵を描いて。
柴犬。ノノグラムの絵。一辺が20マスの正方形。モノクロ。
不明な点は質問して。
```

**Geminiは「一辺が20マス」を守らず、約40マスの細かい絵を出した。** 30×30には落とせたが、
同じ絵を20×20・25×25に落とすと崩れた（柴犬の20×20だけ辛うじて読める。`tools/import_art.py` で8通りを試した）。
→ **20×20・25×25用は、最初から粗い絵を描かせる必要がある。**

## 改良したプロンプト（本人がGeminiに貼る）

`【題材】` と `【マス数】` だけ書き換える。

```text
ノノグラム（お絵かきロジック）の答えになるドット絵を1枚描いて。

題材：【題材】
マス目：縦【マス数】×横【マス数】。これより細かくしない。1マスは大きな正方形。

決まり：
・白と黒の2色だけ。灰色、色、影、ぼかしは使わない
・絵は枠いっぱいに大きく描く。背景は白
・細い輪郭線で描かず、面を黒く塗って形を見せる
・線が必要なところは2マス以上の太さにする
・1マスだけ離れた点や、斜めの点線は使わない
・マス目の線は薄い灰色。文字や説明は入れない
```

## こちらの処理

```bash
cd kdp_nonogram
python3 tools/import_art.py 画像 マス数 puzzles20_draft/名前.txt "Romaji 日本語 (English)"
```

- 「黒と判定する基準」（50%→15%）と「線を太らせる向き」を総当たりし、論理だけで解ける中で、もとの絵に一番近いものを選ぶ
- あと12マス以内なら黒を足して直す
- どうやっても解けなければ、その大きさでは無理と報告する

画像はZIPにまとめて送ってもらう（チャットに直接貼ると縮小される）。ファイル名を題材名にしてもらうと取り違えない。
