# 01 ノノグラム本：仕組みと見本（2026-11-21）

米国 amazon.com 向け。日本の題材の絵が出るノノグラム（お絵かきロジック）の本。
方針と市場の実測は `docs/KDP戦略20案.md`・`docs/KDP_ぬりえ以外の案の検証.md`（リポジトリ直下の docs）。

**題名・説明に Picross は使わない**（任天堂の米国登録商標）。Nonogram を使う。

## できたもの

| ファイル | 中身 |
|---|---|
| `tools/nonogram.py` | 手がかりの計算と検査 |
| `tools/preview.py` | 解答図の一覧画像を作る |
| `tools/build_sample.py` | 見本PDFを作る。**検査に通らない問題が1つでもあれば止まる** |
| `puzzles/*.txt` | 絵柄。`#`＝黒、`.`＝白。1行目の `;` の後ろが題名（英語） |
| `sample/sample_v3.pdf` | 見本（7問＋解答） |
| `sample/絵柄一覧_v3.png` | 解答図の一覧 |

作り直すとき:

```bash
cd kdp_nonogram
python3 tools/build_sample.py sample/sample_v3.pdf
python3 tools/preview.py sample/絵柄一覧_v3.png
```

## 検査の基準

1. **行と列の論理だけで最後まで解ける**こと（当てずっぽうが要らない）。これが通れば解は必ず1つ
2. 通らない問題は本に入れない

実際に検査で落ちた例（2026-11-21）:

| 絵柄 | 結果 | 直し方 |
|---|---|---|
| おにぎり（輪郭だけの絵） | 解は1つだが論理だけでは167マス残る | 中を塗りつぶした |
| 湯のみ（湯気が斜めの点線） | **解が複数** | 湯気の太さを左右で変えた。2回目も16マス残り、3回目で合格 |

**輪郭だけの絵・斜めの点線は落ちやすい。**

## 見本の実測

- 8.5×11インチ、1ページ1問、15×15マス
- マスの大きさ 10.6〜11.4 mm（大きな字の本として売れる大きさ）
- 7問すべて検査に合格

## 分かっている弱点

- **絵が素朴。** 15×15の手描きの影絵。上位の競合は30×30以上の細かい絵で、表紙にもそれを使っている。
  大きい絵を量産する描き方が要る（次の課題）
- 絵はAIが描いたもの → **KDP登録時に「AI生成の画像」と申告する**

## 次に決めること

1. 絵の描き方（大きいマス目の絵をどう量産するか）
2. 1冊の構成（問題数・大きさの段階・ページ数。110ページまでは印刷費が同じ $2.84）
3. 題名・表紙

## 本人の指摘と第2版（2026-11-21）

第1版で「03・05・07がぱっと見で分からない」との指摘。

| 絵柄 | 指摘 | 直し方 |
|---|---|---|
| 03 おにぎり | 縦長すぎる | 15×13の横長にした。ご飯を白、海苔を黒に戻し、輪郭を太くして検査に通した |
| 05 ちょうちん | 上下の黒い部分を段々にしないほうが提灯らしい | 上下を同じ幅の四角にした |
| 07 湯のみ | 模様が何だか分からない | 中の模様をやめ、黒一色の器と湯気にした |

**学び：白地に輪郭だけの絵は論理で解けなくなりやすいが、輪郭を2マスの太さにすると通ることがある。**
**器の中に模様を入れると、15×15では何の絵か分からなくなる。**
空の行・列には 0 を表示するようにした。

第3版（同日）：04 だるまのおなかの模様を、縦線1本から3本にした（本人の提案）。検査に合格。

## 30×30の試作（2026-11-21）

本人：問題ページの見た目はOK。次は30×30。

### 描き方

`tools/draw30.py`。丸・四角・多角形を組み合わせて絵を描き、1マス＝20ピクセルで塗って、
マスごとに半分以上黒なら黒にする。手で900マスを打つより曲線がなめらかで、直すのも数字を変えるだけ。

```bash
cd kdp_nonogram
python3 tools/draw30.py                                   # puzzles30/ に書き出し、全点を検査
python3 tools/preview.py sample/絵柄一覧_30x30_v2.png puzzles30
python3 tools/build_sample.py sample/sample_30x30_v2.pdf puzzles30
```

### 結果

6点（富士山・鳥居と日の出・だるま・招き猫・ちょうちん・桜）すべて検査に合格。
マスの大きさは 5.6〜5.9 mm。

### 途中で落ちたもの

| 絵柄 | 症状 | 原因と直し方 |
|---|---|---|
| 富士山 | 解が複数（42マス決まらず） | 最初は湖の波を疑って直したが変わらず。**決まらないマスの位置を表示したら、雪の細い輪郭と太陽だった。** 雪を山の縁から1.2マス内側に取ったら合格。10通り試して全部合格 |
| だるま | おなかの筋が消えた | 筋の幅1マスがマス目の境をまたぎ、半分ずつになって黒に丸められた。**細い線はマス目の整数位置に置く** |

**学び：落ちたら推測で直さず、まず「決まらないマスの位置」を出す。**

### 弱点

- 絵の周りに空の行・列が4〜8本あり、そのぶんマスが小さくなっている。絵を枠いっぱいに描けばマスを大きくできる
- 手がかりの数字が小さい（2桁の数字は約2mm）。大きな字の本としては売れない大きさ
- 招き猫はまだ猫に見えにくい

第2版（同日）：鳥居の柱の間の太陽を外した。本人から「下の黒い部分は何？」と指摘。宙に浮いた黒い丸は太陽に見えない。**黒一色の絵では、説明が要る飾りは入れない。**
