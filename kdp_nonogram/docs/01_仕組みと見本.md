# 01 ノノグラム本：仕組みと見本（2026-11-21）

米国 amazon.com 向け。日本の題材の絵が出るノノグラム（お絵かきロジック）の本。
方針と市場の実測は `docs/KDP戦略20案.md`・`docs/KDP_ぬりえ以外の案の検証.md`（リポジトリ直下の docs）。

**題名・説明に Picross は使わない**（任天堂の米国登録商標）。Nonogram を使う。

## できたもの

| ファイル | 中身 |
|---|---|
| `tools/nonogram.py` | 手がかりの計算と検査 |
| `tools/preview.py` | 解答図の一覧画像を作る |
| `tools/build_sample.py` | 見本PDFを作る。**検査に通らない問題が1つでもあれば止まる** |
| `puzzles/*.txt` | 絵柄。`#`＝黒、`.`＝白。1行目の `;` の後ろが題名（英語） |
| `sample/sample_15x15_v6.pdf` | 見本（7問＋解答） |
| `sample/絵柄一覧_15x15_v5.png` | 解答図の一覧 |

作り直すとき:

```bash
cd kdp_nonogram
python3 tools/build_sample.py sample/sample_15x15_v6.pdf
python3 tools/preview.py sample/絵柄一覧_15x15_v5.png
```

## 検査の基準

1. **行と列の論理だけで最後まで解ける**こと（当てずっぽうが要らない）。これが通れば解は必ず1つ
2. 通らない問題は本に入れない

実際に検査で落ちた例（2026-11-21）:

| 絵柄 | 結果 | 直し方 |
|---|---|---|
| おにぎり（輪郭だけの絵） | 解は1つだが論理だけでは167マス残る | 中を塗りつぶした |
| 湯のみ（湯気が斜めの点線） | **解が複数** | 湯気の太さを左右で変えた。2回目も16マス残り、3回目で合格 |

**輪郭だけの絵・斜めの点線は落ちやすい。**

## 見本の実測

- 8.5×11インチ、1ページ1問、15×15マス
- マスの大きさ 10.6〜11.4 mm（大きな字の本として売れる大きさ）
- 7問すべて検査に合格

## 分かっている弱点

- **絵が素朴。** 15×15の手描きの影絵。上位の競合は30×30以上の細かい絵で、表紙にもそれを使っている。
  大きい絵を量産する描き方が要る（次の課題）
- 絵はAIが描いたもの → **KDP登録時に「AI生成の画像」と申告する**

## 次に決めること

1. 絵の描き方（大きいマス目の絵をどう量産するか）
2. 1冊の構成（問題数・大きさの段階・ページ数。110ページまでは印刷費が同じ $2.84）
3. 題名・表紙

### 結果

マスの大きさは 5.6〜5.9 mm。

### 途中で落ちたもの

| 絵柄 | 症状 | 原因と直し方 |
|---|---|---|
| 富士山 | 解が複数（42マス決まらず） | 最初は湖の波を疑って直したが変わらず。**決まらないマスの位置を表示したら、雪の細い輪郭と太陽だった。** 雪を山の縁から1.2マス内側に取ったら合格。10通り試して全部合格 |

**学び：落ちたら推測で直さず、まず「決まらないマスの位置」を出す。**

### 弱点

- 絵の周りに空の行・列が4〜8本あり、そのぶんマスが小さくなっている。絵を枠いっぱいに描けばマスを大きくできる
- 手がかりの数字が小さい（2桁の数字は約2mm）。大きな字の本としては売れない大きさ
- 招き猫はまだ猫に見えにくい

## 題は「日本語のローマ字（英語）」にする（2026-11-21・本人の提案）

本人：「日本語入れたらいいのでは？ Fuji-San, Chouchin, Sakura-no-hana とか」→ 採用。

| 題 | 読み | 英語の補い |
|---|---|---|
| Fuji-san (Mount Fuji) | ふじさん | 富士山 |
| Torii (shrine gate) | とりい | 神社の門 |
| Daruma (wishing doll) | だるま | 願かけの人形 |
| Maneki-neko (lucky cat) | まねきねこ | 幸運の猫 |
| Chōchin (paper lantern) | ちょうちん | 紙のちょうちん |
| Sakura (cherry blossom) | さくら | 桜の花 |
| Onigiri (rice ball) | おにぎり | ご飯の玉 |
| Gojū-no-tō (five-story pagoda) | ごじゅうのとう | 五重の塔 |
| Yunomi (tea cup) | ゆのみ | 茶のカップ |

こちらで決めた書き方（本人未確認）:
- **長音は ō・ū（ヘボン式の長音記号）**。Chouchin と書くと英語話者は「チョウチン」ではなく「チャウチン」と読みやすい
- 桜は Sakura-no-hana ではなく **Sakura**。英語圏で Sakura は花の名として通じる。かっこの cherry blossom が「花」を補う
- 最初の1字だけ大文字、かっこの中は小文字

### 同時に見つけて直した不具合

- **PDFの書体が埋め込まれていなかった**（`pdffonts` で確認。Helvetica が emb=no）。KDPは全書体の埋め込みが必須で、
  このままでは入稿ではじかれる。同じ字幅の Liberation Sans に替え、全書体 emb=yes を確認
- 2桁の数字を横に詰める設定が戻っておらず、解答ページの題が2つ横に詰まっていた。直した

**日本語の文字（提灯 など）も添えるなら、日本語の書体の追加が要る**（この環境にあるのは中国語の字形の書体と点描の書体だけ）。

## 日本語の文字を添える・塔と桜の入れ替え（2026-11-21・本人の決定）

### 題の形（確定）

`ローマ字 日本語 (英語)`　例：`Chōchin 提灯 (paper lantern)`、`Yama 山 (mountain)`

- 日本語は IPAexゴシック、ローマ字は DejaVu Sans（ō・ū を持つ）で描き分ける（`nonogram.title_runs`）
- IPAexゴシックは `apt-get install fonts-ipaexfont-gothic` で入れた。**新しい環境では入れ直しが要る**
- Noto Sans CJK も入れたが、PDFを作る道具（reportlab）が読めない形式だったので使っていない
- 全書体の埋め込みを `pdffonts` で確認済み

### 塔と桜の入れ替え

本人：「15×15の塔は五重ではなく三重。五重塔は30×30でないと描けない気がする。桜を15×15に」→ そのとおりだった。

| 絵 | 対応 |
|---|---|
| 五重塔 30×30（新規） | 屋根5枚＋相輪。3回描き直した（下） |
| 桜 15×15（新規） | 手描き。図形から15×15に落とすと花びらがつながって塊になり、解も2つあった |
| 三重塔 15×15・桜 30×30 | `puzzles_spare/` に保管（本には入れていない） |

五重塔の描き直し:
1. 壁に窓の白い帯を入れた → 骨組みだけに見えた。軒先が屋根から離れて浮いた点になった
2. 壁を黒一色に、軒先を軒の真上に → 壁と屋根の幅が近く、**木に見えた**
3. 壁を屋根の半分ほどの幅に → 屋根5枚が読める

**学び：塔は「屋根の張り出し」で塔に見える。壁は屋根の半分以下の幅にする。**

## 五重塔を本人の参考画像に合わせて描き直し（2026-11-21）

本人が参考画像（細身の五重塔の影絵）を示し「30×30に置き換えて」。

| 試したこと | 結果 |
|---|---|
| 画像をそのまま30×30に縮める（`tools/from_image.py`・4通り） | 検査は合格だが、**屋根と壁がつながった塊**になり塔に見えない。もとの絵は30×30よりずっと細かい |
| 特徴だけ拾って行ごとに組む：屋根を下ほど大きく広げる | **クリスマスツリーに見えた** |
| 参考画像の比率を測って合わせる（一番上の屋根が一番下の約半分の幅） | 塔に見えた。採用 |

採用した形：1マス幅の相輪、屋根5枚（半幅5・6・7・8・9マス、両端が1マス反り上がる）、
屋根の間に2段の壁（下の段に白い窓）、入口のある初層、階段つきの基壇。中心は15列目（0始まりで14）。

**学び：細かい参考画像は機械的に縮めても使えない。比率（幅と高さ、上と下の幅の比）を数値で測り、特徴だけを描き直す。**
**塔が木に見える原因は「下ほど広がりすぎ」。上下の幅の比は約1:2まで。**

参考画像の出どころは未確認（画面の操作ボタンから画像生成AIの出力と見ている）。採用した絵は画像の写しではなく、特徴を参考にした描き直し。

### 元の写真との比較（2026-11-21 追記）

本人が元の写真（実在の五重塔。最下層に裳階＝小さい屋根が付く形）を送ってくれた。先の影絵はこの写真から作られたもの。
建物そのものに著作権は無いが、**写真には撮影者の権利がある。写真・影絵そのものは本に使わない**（使っていない）。

写真から測った比率と、採用した絵の比較:

| 項目 | 写真 | 採用した絵 |
|---|---|---|
| 一番上の屋根の幅 ÷ 一番下の屋根の幅 | 約0.61 | 0.58（11マス÷19マス） |
| 相輪の高さ ÷ 全体の高さ | 約23% | 17%（5行÷30行） |
| 屋根の間隔 | ほぼ等間隔 | 等間隔（4行ごと） |
| 最下層の小さい屋根（裳階） | あり | なし |

屋根の比率は合っている。相輪は写真より短い。
