# 01 ノノグラム本：仕組みと見本（2026-11-21）

米国 amazon.com 向け。日本の題材の絵が出るノノグラム（お絵かきロジック）の本。
方針と市場の実測は `docs/KDP戦略20案.md`・`docs/KDP_ぬりえ以外の案の検証.md`（リポジトリ直下の docs）。

**題名・説明に Picross は使わない**（任天堂の米国登録商標）。Nonogram を使う。

## できたもの

| ファイル | 中身 |
|---|---|
| `tools/nonogram.py` | 手がかりの計算と検査 |
| `tools/preview.py` | 解答図の一覧画像を作る |
| `tools/build_sample.py` | 見本PDFを作る。**検査に通らない問題が1つでもあれば止まる** |
| `puzzles/*.txt` | 絵柄。`#`＝黒、`.`＝白。1行目の `;` の後ろが題名（英語） |
| `sample/sample_v1.pdf` | 見本（7問＋解答） |
| `sample/絵柄一覧_v1.png` | 解答図の一覧 |

作り直すとき:

```bash
cd kdp_nonogram
python3 tools/build_sample.py sample/sample_v1.pdf
python3 tools/preview.py sample/絵柄一覧_v1.png
```

## 検査の基準

1. **行と列の論理だけで最後まで解ける**こと（当てずっぽうが要らない）。これが通れば解は必ず1つ
2. 通らない問題は本に入れない

実際に検査で落ちた例（2026-11-21）:

| 絵柄 | 結果 | 直し方 |
|---|---|---|
| おにぎり（輪郭だけの絵） | 解は1つだが論理だけでは167マス残る | 中を塗りつぶした |
| 湯のみ（湯気が斜めの点線） | **解が複数** | 湯気の太さを左右で変えた。2回目も16マス残り、3回目で合格 |

**輪郭だけの絵・斜めの点線は落ちやすい。**

## 見本の実測

- 8.5×11インチ、1ページ1問、15×15マス
- マスの大きさ 10.6〜11.4 mm（大きな字の本として売れる大きさ）
- 7問すべて検査に合格

## 分かっている弱点

- **絵が素朴。** 15×15の手描きの影絵。上位の競合は30×30以上の細かい絵で、表紙にもそれを使っている。
  大きい絵を量産する描き方が要る（次の課題）
- 絵はAIが描いたもの → **KDP登録時に「AI生成の画像」と申告する**

## 次に決めること

1. 絵の描き方（大きいマス目の絵をどう量産するか）
2. 1冊の構成（問題数・大きさの段階・ページ数。110ページまでは印刷費が同じ $2.84）
3. 題名・表紙
