■ ★最優先の確認事項★　Cは特集に間に合うかもしれない
──────────────────────────────────────────────

当初は「審査1〜2週間＋参加受付を考えると間に合わない」として、
特集の露出を当てにしない設計（120円・特集チェックなし）にしていた。
この前提が2つとも崩れた。

  ▼ 崩れた前提1：審査が想定よりずっと速かった
    B1・B2・A は 8/5〜8/6 申請 → 8/8 承認。実測2〜3日。
    「1〜2週間」は保守的すぎた。
    いま出せば 8/31 までに承認が下りる可能性が高い。

  ▼ 崩れた前提2：特集の参加受付は、特集開始前に閉まらないらしい
    2025年の同名企画「意外と使える！ネガティブ表現スタンプ特集」の実績：

        特集期間　　： 2025/09/16 〜 10/31
        審査受付期間： 2025/08/07 11:00 〜 10/14 10:59

    受付は特集開始の約3.5週間前に開き、特集終了の約2.5週間前まで
    開いたまま。つまり受付は特集期間中もずっと続いていた。

    今回の特集（2026/08/31 11:00 〜 10/12 10:59）が同じ形なら、
    受付は8月上旬にはすでに開いており、9月下旬頃まで開いている。
    ★いま申請すれば間に合う。仮に8/31の初日に間に合わなくても、
    　特集期間の途中から参加できる可能性がある★

  ▼ ただしこれは2025年からの外挿であって、確認した事実ではない
    2026年版の受付期間そのものは確認できていない
    （creator.line.me にこちらから到達できないため）。

  ▼ だから、次にやることはこれ1つ
    ★Creators Market で Cの申請フォームを開き、
    　「特集に参加する」のチェックボックスが出るかどうかを見る★
    　5分で終わる。ここで全部決まる。

      ┌─ ある（＝まだ受付中）
      │    → チェックを入れる
      │    → 価格は 250円（特集の参加条件が190円以上のため）
      │    → 販売開始設定は「手動」（8/31前に勝手に始まらないように）
      │    → 8/31 11:00 に押すのは3セットではなく★4セット★になる
      │
      └─ ない／受付終了
           → チェックせずそのまま申請する
           → 価格は 120円（特集に出ないなら最低価格が正しい）
           → 8/31 に押すのは3セットのまま。Cは承認され次第いつ出してもよい

    どちらに転んでも「今日申請する」は変わらない。待つ理由はもう無い。

  ▼ 参加条件について1点だけ注意
    特集によっては「8枚以上が敬語であること」のような
    内容条件が付くものがある（別企画で確認された条件）。
    今回の特集で読み取れている条件は「金額：￥190〜 以上」のみで、
    B1（敬語2枚）が参加チェック済みで承認されているので、
    敬語条件はこの特集には無いと判断してよい。
    ただしフォームに条件表示があれば必ず読むこと。
    参考までに Cの敬語は5枚（01・05・09・12・16）。

■ このセットの設計方針（シリーズBとの違い）
──────────────────────────────────────────────

シリーズBの黒さ ＝「攻撃されている黒さ」（客・カスハラ）
シリーズCの黒さ ＝「見られていない黒さ」

  削ったものは口の中に入って二度と見られない。
  作った人の名前はどこにも出ない。
  この不可視性が、この界隈の感情の核。

★宛先の設計（ここが一番重要）★
  技工士の不満の最大の鉱脈は歯科医師・指示書だが、そこは取引先であり、
  同じLINEグループにいることもある。人を直接叩く札を作ると
  「職場で使えないスタンプ」になり、使えないものは売れない。
  だから攻撃先は 指示書・納期・再製 という無生物にずらしてある。
  「主語を書かない」設計はシリーズBと共通。

  この方針の結果、16枚のどれも特定の職種・個人を非難していない。
  審査でもここが効く。

★16枚に1枚だけ勝ち札を入れてある★
  09「適合、出ました」。全部黒くすると送る機会が減る。
  丸ゴシック＋微回転で、このセットで唯一あたたかい札にしてある。

★15「見えないところが一番きれい」は誇り札★
  黒さだけのセットにしない。技工士の職能そのものを肯定する1枚が
  無いと、界隈から「愚痴だけを売っている」と見られる。

■ 用語の検証結果（2026-08-08 実施・公開情報のみ）
──────────────────────────────────────────────

制作者は歯科技工士ではなく、現役技工士の知り合いもいない。
そこで「人に聞く」前に、公開情報で潰せるところを先に潰した。
以下は裏が取れている。ここは疑わなくてよい。

  ✓ 「再製」… 標準語。保険診療の正式用語。
     補綴物維持管理料の施設基準で「2年以内に再製の必要が生じた場合は
     自院の責任において再製作しなければいけない」と規定されている。
     兵庫県保険医協会・厚労省資料で確認。
     → 04「本日の再製報告」は業界の正式語を使っている。問題なし。
     　 かつ「無償でやり直す」という痛点が制度として裏打ちされている。

  ✓ 「咬合器」… 歯科技工士国家試験の出題範囲に含まれる基本用語。
     顎口腔機能学・有床義歯技工学の必修概念。
     → 02 の用語自体は正しい。

  ✓ 「適合」… 歯科技工所が自社サイトの見出しで使っている語
     （「高精度 適合・コンタクト」等）。「適合精度」で定着。
     → 09・技工物の品質を指す語として正しい。

  ✓ 「指示書」… 歯科技工指示書。歯科技工士法で義務づけられた法定文書。
     施行規則第12条で記載事項が定められている（患者の氏名、設計、
     作成の方法、使用材料、発行年月日、発行した歯科医師の氏名 等）。
     2年間の保存義務もある。
     → 05「指示書、白紙です」は、ただの愚痴ではなく
     　「法定記載事項が埋まっていない」という告発になっている。
     　 想定より強い札。ただし特定の歯科医師を指していないので審査は通る。

  ✓ 「短納期・徹夜が常態」… 「患者さんの予約が入っているから」という理由で
     無理な短納期を強いられ、深夜残業や休日出勤が常態化する、という記述が
     業界向け記事に複数ある。
     → 08「明日まで、が常態」は誇張ではなく実態。

  ✓ 競合の不在… LINE STORE の歯科系スタンプは、歯磨き・歯科矯正・
     歯医者キャラなど患者向け／歯科医院向けばかり。
     歯科技工士に向けたものは見つからなかった。

  ▼ 唯一、裏が取れていない点
    09「適合、出ました」の「出る」という言い回し。
    「適合」が正しい語であることは確認できたが、「適合が出る」という
    動詞の組み合わせまでは公開情報で確認できなかった。
    製造業では「精度が出る」「寸法が出る」は極めて一般的な現場語なので、
    技工所でも自然に通る可能性は高いと見ているが、確証はない。

      安全側に倒すなら → 「適合、良好」／「適合、ばっちり」
      現場語らしさを取るなら → 現行のまま

    判断がつくまでは現行のままでよい。直すのは gen_setC.py の
    09番の文言を書き換えて `python3 gen_setC.py` を再実行するだけ。
    文言を変えたら docs 側のタグと対応表も直すこと。
