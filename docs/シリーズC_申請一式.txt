■ ★唯一の残リスク：大量申請行為★
──────────────────────────────────────────────

「大量申請行為」は、一般の審査NG事項であるだけでなく
★この特集の明示的なNG事項★でもある。Cはこの特集への4本目になる。

  ▼ とはいえリスクは低いと判断する。理由は3つ
    1. すでに3本が同じ特集の参加チェック付きで承認されている。
       LINEはこのクリエイターから3本受け取った時点で弾いていない
    2. 最も「大量」に見えたのは3本を同時申請した 8/5〜8/6 で、
       そこを通過済み。4本目は1〜2週間空いた単発申請になる
    3. 中身が別界隈（コールセンター → 歯科技工士）で、
       同じものを水増ししている類ではない

  ▼ だから、こうする
    ★申請日をB・Aから10日以上空ける（8/16以降を目安）★
    受付は9/23まであるので急ぐ必要がまったくない。
    間隔を空けるだけでリスクが下がるなら、空けたほうが得。

  ▼ 万一Cがリジェクトされても
    失うのはCだけ。B・Aは承認済みで影響を受けない。
    リジェクト理由を見て、期間内（9/23まで）に出し直せる。

■ ★確定：Cの販売開始は 2026/9/12(土)★
──────────────────────────────────────────────

バナー掲載は 8/31〜10/12 の6週間ある。8/31に4セットまとめて出す案と
Cだけ後ろにずらす案を比べ、後者を採った。

  ▼ この判断の理由
    1. 新着欄に載る機会が2回になる。8/31は他のクリエイターも
       一斉に出す日で、新着欄の競争が最も激しい
    2. Cは界隈が違う。コールセンター3セットと同時に並べても
       互いの客を取り合うだけで足し算にならない
    3. 申請（8/16〜8/20）から販売開始まで間隔が空くので、
       「大量申請行為」に見える度合いがさらに下がる

  ▼ 特集期間　9/12 → 10/12 で 30日
    B・Aの42日より短いが、1か月あれば露出としては十分。

  ▼ 時刻は問わない
    8/31の11:00厳守は「特集開始前に押すと新着欄から外れる」ため。
    9/12は特集期間の途中なので、その日のうちなら何時でもよい。

  ▼ 申請スケジュールは変えない
    8/16〜8/20 申請 → 8/23頃 承認 → 9/12 販売開始。
    承認を早めに取っておけば、9/12に気が変わっても対応できる。

  ▼ 押し忘れだけが唯一の失敗パターン
    9/12はこちらの都合で選んだ日で、公式の締切ではない。
    1〜2日ずれても実害はない。★本当の最終期限は 10/12 10:59★
    カレンダーに 9/12 と、保険の 10/5 を入れておくこと。
    手順は docs/販売開始日_手順.txt

■ このセットの設計方針（シリーズBとの違い）
──────────────────────────────────────────────

シリーズBの黒さ ＝「攻撃されている黒さ」（客・カスハラ）
シリーズCの黒さ ＝「見られていない黒さ」

  削ったものは口の中に入って二度と見られない。
  作った人の名前はどこにも出ない。
  この不可視性が、この界隈の感情の核。

★宛先の設計（ここが一番重要）★
  技工士の不満の最大の鉱脈は歯科医師・指示書だが、そこは取引先であり、
  同じLINEグループにいることもある。人を直接叩く札を作ると
  「職場で使えないスタンプ」になり、使えないものは売れない。
  だから攻撃先は 指示書・納期・再製 という無生物にずらしてある。
  「主語を書かない」設計はシリーズBと共通。

  この方針の結果、16枚のどれも特定の職種・個人を非難していない。
  審査でもここが効く。

★16枚に1枚だけ勝ち札を入れてある★
  09「適合、出ました」。全部黒くすると送る機会が減る。
  丸ゴシック＋微回転で、このセットで唯一あたたかい札にしてある。

★15「見えないところが一番きれい」は誇り札★
  黒さだけのセットにしない。技工士の職能そのものを肯定する1枚が
  無いと、界隈から「愚痴だけを売っている」と見られる。

■ 用語の検証結果（2026-08-08 実施・公開情報のみ）
──────────────────────────────────────────────

制作者は歯科技工士ではなく、現役技工士の知り合いもいない。
そこで「人に聞く」前に、公開情報で潰せるところを先に潰した。
以下は裏が取れている。ここは疑わなくてよい。

  ✓ 「再製」… 標準語。保険診療の正式用語。
     補綴物維持管理料の施設基準で「2年以内に再製の必要が生じた場合は
     自院の責任において再製作しなければいけない」と規定されている。
     兵庫県保険医協会・厚労省資料で確認。
     → 04「本日の再製報告」は業界の正式語を使っている。問題なし。
     　 かつ「無償でやり直す」という痛点が制度として裏打ちされている。

  ✓ 「咬合器」… 歯科技工士国家試験の出題範囲に含まれる基本用語。
     顎口腔機能学・有床義歯技工学の必修概念。
     → 02 の用語自体は正しい。

  ✓ 「適合」… 歯科技工所が自社サイトの見出しで使っている語
     （「高精度 適合・コンタクト」等）。「適合精度」で定着。
     → 09・技工物の品質を指す語として正しい。

  ✓ 「指示書」… 歯科技工指示書。歯科技工士法で義務づけられた法定文書。
     施行規則第12条で記載事項が定められている（患者の氏名、設計、
     作成の方法、使用材料、発行年月日、発行した歯科医師の氏名 等）。
     2年間の保存義務もある。
     → 05「指示書、白紙です」は、ただの愚痴ではなく
     　「法定記載事項が埋まっていない」という告発になっている。
     　 想定より強い札。ただし特定の歯科医師を指していないので審査は通る。

  ✓ 「短納期・徹夜が常態」… 「患者さんの予約が入っているから」という理由で
     無理な短納期を強いられ、深夜残業や休日出勤が常態化する、という記述が
     業界向け記事に複数ある。
     → 08「明日まで、が常態」は誇張ではなく実態。

  ✓ 競合の不在… LINE STORE の歯科系スタンプは、歯磨き・歯科矯正・
     歯医者キャラなど患者向け／歯科医院向けばかり。
     歯科技工士に向けたものは見つからなかった。

  ▼ 唯一、裏が取れていない点
    09「適合、出ました」の「出る」という言い回し。
    「適合」が正しい語であることは確認できたが、「適合が出る」という
    動詞の組み合わせまでは公開情報で確認できなかった。
    製造業では「精度が出る」「寸法が出る」は極めて一般的な現場語なので、
    技工所でも自然に通る可能性は高いと見ているが、確証はない。

      安全側に倒すなら → 「適合、良好」／「適合、ばっちり」
      現場語らしさを取るなら → 現行のまま

    判断がつくまでは現行のままでよい。直すのは gen_setC.py の
    09番の文言を書き換えて `python3 gen_setC.py` を再実行するだけ。
    文言を変えたら docs 側のタグと対応表も直すこと。

■ この界隈を選んだ判断の記録
──────────────────────────────────────────────

  ▼ 良い理由
    ・内輪語の密度がコルセンより高い（再製・適合・咬合器・指示書）。
    　「同業しかわからない」という設計の核と噛み合いが良い
    ・競合が事実上ゼロ。歯科医院向け・歯科衛生士向けはあるが、
    　技工士専用はほぼ無い
    ・界隈がXに固まっていて、導線2が効きやすい

  ▼ 悪い理由（承知の上でやる）
    ・母数が2桁小さい。就業歯科技工士は全国で約3.4万人。
    　コールセンターは100万人規模。天井は低い
    ・オープンチャット文化が薄い。職場LINEグループとXが主戦場なので、
    　「同業の他人に投げる」という前提が弱い。
    　→ だから16番（了解／承知）のような業務連絡で発火する札を入れた
    ・呪詛の宛先が取引先になる。→ 無生物にずらして解決済み

  ▼ 判断
    売上の期待値ではなく、シリーズの型が別の界隈でも動くかの検証として
    やる価値がある。ここで型が通れば、次の界隈（介護／保育／薬剤師／
    トラック運転手）にそのまま横展開できる。
