【このセットの設計方針】
・対象：問い合わせ／苦情対応の電話オペレーター
・送る場所：オープンチャット（同業の他人が受け手）
・トーン：怒りではなく「壊れの実況」。主語を書かないことで黒くする
・禁止：説教くさいポジティブ／シモ・下ネタ／暴力・脅迫語／特定企業名
・キャラなし、文字のみ


────────────────────────────────────────
■ 0. 事前準備（最初の1回だけ）
────────────────────────────────────────

▼ Canva Proが必要
背景透過PNGの書き出しはPro限定。無料版は白背景しか出ず使えない。
7日間無料トライアルあり。
→ 16枚まとめて作る日を決めて、その日にトライアル開始するのが賢い。

▼ フォントの在庫確認（先にやる）
Canvaでテキストを1つ置き、「フォント」→検索窓で以下を打って存在確認。

  明朝（主力）   しっぽり明朝
    代替 → Zen Old Mincho → Noto Serif JP
  極太（叫び）   DELA Gothic One
    代替 → Kaisei Decol の Bold
  細字（無感情） Noto Sans JP ※ウェイトLight
    代替 → M PLUS 1p の Light
  手書き（震え） Yusei Magic
    代替 → はれのそら明朝

▼ カラーパレット（この4色だけ）
  墨     #1A1A1A   基調
  血     #7B1E1E   呪い・敵意
  灰     #6E6E6E   無感情・麻痺
  白     #FFFFFF   全案のフチ（例外なし）


────────────────────────────────────────
■ 1. 白フチの作り方（最重要）
────────────────────────────────────────

LINEのトーク背景は黒や写真も普通にある。
透過PNGの黒文字は背景次第で完全に消える。
16枚すべてにこの処理が要る。

※前提：Canvaに「袋文字」という項目は存在しない。
　以下の2通りで代用する。


【方法A】太いフォント用 ── 本物の袋文字
　該当：31・33・37・21・10

　1. テキストを配置し、色を指定の色にする
　2. そのテキストを選択 →「…」→「複製」
　3. 複製は同じ位置に重なって生成される。絶対に動かさない
　4. 複製が選択された状態のまま →「色」→ 白 #FFFFFF
　5. そのまま →「エフェクト」→「中抜き」→ 太さを最大（100）
　6. そのまま →「…」→「背面へ移動」（元テキストの後ろへ）
　7. 文字の周りに白い縁が出れば完成

　★コツ：手順3〜6の間、一度も指でドラッグしない。
　　ズレたら二度と合わない。ズレたら複製し直すのが早い。


【方法B】細いフォント用 ── 白の座布団
　該当：32・34・35・36・38・39・40・29・23・27・1

　細い明朝に中抜きを最大で掛けると線が太りすぎて文字が潰れる。
　細字は必ずこちら。

　1. テキストを選択 →「エフェクト」→「背景」
　2. 色：白 #FFFFFF
　3. 角の丸み：80
　4. スプレッド：各スタンプの指定値（12〜18）
　5. 透明度：90 ※100だとベタっとするので少し抜く

　見た目は「白い座布団に文字が乗る」状態。
　テキストスタンプでは一般的で、むしろ読みやすさが上がる。


────────────────────────────────────────
■ 2. 基本テンプレを1枚作る
────────────────────────────────────────

　1. Canvaアプリ → ホーム右下の「+」→「カスタムサイズ」
　2. 幅 370 ／ 高さ 320 ／ 単位 px →「新しいデザインを作成」
　3. 背景には何も置かない
　　（背景色を白にしない。透過にならなくなる）
　4. このデザインを「…」→「コピーを作成」で16個複製してから
　　中身を差し替えると速い

　★セーフエリア：文字は 横350px × 縦300px の中に収める。
　　端まで攻めるとLINE側で切れる。

　★行ごとに別のテキストボックスを作ること。
　　1つのボックス内で文字サイズを変えるのはモバイルだと不安定。

　★「サイズ」の数値はCanvaのフォントサイズ欄に直接打つ値。

　2行目 決めた規約    DELA Gothic One / 54 / 墨 #1A1A1A
　3行目 じゃない      DELA Gothic One / 54 / 墨 #1A1A1A
　配置：中央揃え、3行を縦中央
　白フチ：方法A（3行それぞれに実施）

──────────────────────────────
【03】助けて、は言えない
──────────────────────────────
用途：限界だが言えない時。16枚で最も強い可能性がある1枚
　1行目 助けて      しっぽり明朝 / 78 / 血 #7B1E1E
　2行目 は言えない  しっぽり明朝 / 24 / 灰 #6E6E6E
　配置：1行目は中央やや上。2行目は1行目の右下に小さく添える
　白フチ：方法B（1行目スプレッド16 ／ 2行目スプレッド10）

──────────────────────────────
【04】本日の被弾報告
──────────────────────────────
用途：退勤後の定例投稿
　本文 本日の被弾報告  しっぽり明朝 / 46 / 墨 #1A1A1A
　文字間：「間隔」→ 文字間隔を +30（間延びさせると報告書感が出る）
　装飾：文字の下に線を1本
　　「+」→「素材」→ 検索「線」→ 直線
　　色 墨 ／ 太さ 3 ／ 幅 300px ／ 文字の12px下
　配置：全体を縦中央
　白フチ：方法B（スプレッド15）
　※線にはエフェクトが掛からないので太さ3で目立たせる

──────────────────────────────
【05】隣の席、静かになった
──────────────────────────────
用途：同僚が飛んだ／消えた日。言わない黒さの代表作
　1行目 隣の席、      しっぽり明朝 / 40 / 墨 #1A1A1A
　2行目 静かになった  しっぽり明朝 / 44 / 墨 #1A1A1A
　行間：「間隔」→ 行間を 1.6（2行の間の空白が怖さになる）
　配置：中央揃え、縦中央
　白フチ：方法B（スプレッド13）

──────────────────────────────
【06】今の、生き物だった
──────────────────────────────
用途：常軌を逸した客を切った直後
　1行目 今の、        しっぽり明朝 / 38 / 墨 #1A1A1A
　2行目 生き物だった  しっぽり明朝 / 50
　　　　→ 2行目は文字を長押しして「生き物」だけ部分選択し、
　　　　　 色を 血 #7B1E1E に。「だった」は墨のまま
　　　　→ 部分選択がうまくいかない場合は
　　　　　「生き物」52血 と「だった」38墨 の2ボックスに分ける

　配置：中央揃え
　白フチ：方法B（スプレッド14）

■ 4. 並び順（この順番で登録する）
════════════════════════════════════════

上記【01】〜【16】の番号がそのまま登録順。
理由：ストアで最初に目に入る4枚に
　　　「一番使う実況」「シリーズの看板」「一番刺さる1枚」
　　　「定例投稿になる1枚」を置いてある。
　　　ここで刺さらないと残り12枚は見られない。

■ 5. 書き出し手順（1枚ずつ）
════════════════════════════════════════

　1. 右上の共有アイコン（↑）→「ダウンロード」
　2. ファイルの種類：PNG
　3. 「背景透過」のトグルを ON  ←忘れると全部やり直し
　4. サイズ：1x  ←2xだと740×640になり規定外
　5. 「ダウンロード」

▼ 書き出したら1枚ずつカメラロールで開いて確認（2点だけ）
　□ 背景が市松模様（透過）になっているか
　□ スマホをダークモードに切り替えて文字が読めるか
　　 ← 白フチが効いているかの唯一の実地テスト

════════════════════════════════════════
■ 7. LINEスタンプメーカーへの取り込み
════════════════════════════════════════

　1. アプリを開く →「スタンプを作る」→ セット名を入力
　2. 「写真・画像を選ぶ」→ カメラロールから透過PNGを選択
　3. ★切り抜き画面で「フチ」の設定を必ず確認★
　　 スタンプメーカーはデフォルトで白フチを自動追加する。
　　 Canvaで付けた白フチと二重になって汚くなるので、
　　 フチの太さを「0」または「なし」にする
　4. 位置とサイズを調整して保存 → 16枚繰り返す

■ 8. 申請前チェックリスト
════════════════════════════════════════

　□ スタンプ画像 16枚すべて 370×320px 以内・背景透過PNG
　　 ※LINEは 8 / 16 / 24 / 32 / 40枚単位でしか申請できない
　□ メイン画像 240×240px・背景透過PNG
　□ タブ画像 96×74px・背景透過PNG
　□ 全枚数、上下左右に10px以上の余白がある
　□ 全枚数、ダークモードで文字が読める
　□ スタンプメーカー側のフチ設定が「0／なし」になっている
　□ 暴力・脅迫語、特定企業名、実在人物を想起させる表現がない
　□ 並び順が【01】〜【16】の通りになっている

　審査期間の目安：1〜2週間
　→ 審査待ちの間に2セット目を仕込むと回転が速い

■ 9. 次のセットの仕込み（審査待ちの間に）
════════════════════════════════════════

▼ シリーズB 2セット目の候補（今回落とした24案から）
　A群：人としてカウント外／会話が成立しない／番号、覚えました／
　　　 声、忘れないからね／謝罪を食べる人／名乗った瞬間終わった／
　　　 二度と鳴らないで／録音、残ってます
　B群：心、先に退勤した／感情、在庫切れ／もう痛くない／
　　　 泣き方を忘れた／頭の中だけ叫んでた／目、開いてるだけ／
　　　 私の声じゃない／途中から記憶がない／笑いながら削れてる／
　　　 まだ手が震えてる
　C群：上を出せ、私も出したい／謝罪はタダだと思ってる／
　　　 品質より秒数／離席が罪になる職場／代わりはいるらしい／
　　　 席だけ埋まってる

▼ 横展開テンプレ（切り口違い・3セット目用）
　①「私が決めた規約じゃない」系
　　私が値上げしたんじゃない／作った人はここにいない／
　　決定権、私にはない／伝えるだけの人です／決めた人と話してほしい
　②「心、先に退勤した」系
　　体だけ座ってる／私の代わりが喋ってる／声だけ出勤してる／
　　中身は昨日から不在／応対してるのは誰？
　③「隣の席、静かになった」系
　　昨日までいた人／席、片付いてた／研修の子、来なくなった／
　　名札だけ残ってる／次は私かもしれない
　④「本日の被弾報告」系
　　本日の戦績、全敗／只今、着弾しました／被害報告いいですか／
　　本日2件目です／まだ午前中です
　⑤「今の、生き物だった」系
　　言語が通じなかった／日本語ではあった／会話ではなかった／
　　種類が違う／分類できない何か

▼ 凍結中：シリーズA「諦念版」（ちいかわ寄り）
　健気さが売りのトーン。こちらはキャラを乗せると強くなるので、
　起こすタイミングでキャラ設計（STEP6）を実行する。
