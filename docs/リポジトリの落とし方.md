# リポジトリのファイルをPCに落とす方法

**※ このリポジトリは非公開。** どの方法でも、そのブラウザで
**GitHubにログインしている**ことが前提。

いま作業しているブランチ： **`claude/great-mayer-lissxp`**

---

## 方法A：丸ごとZIPで落とす（約270MB）

出品画像も入稿データも全部いるとき。

```bash
start https://github.com/golfbacca/laughing-spoon/archive/refs/heads/claude/great-mayer-lissxp.zip
```

押すとダウンロードが始まる。解凍すると
**`laughing-spoon-claude-great-mayer-lissxp`** というフォルダができる。

### 画面から操作する場合

1. リポジトリを開く

```bash
start https://github.com/golfbacca/laughing-spoon
```

2. ファイル一覧の左上、**「main」と書かれたボタン**を押す
3. 出てきた一覧から **`claude/great-mayer-lissxp`** を選ぶ
   （見つからないときは検索欄に `great` と打つ）
4. ファイル一覧の右上、**緑の「Code」ボタン**を押す
5. 一番下の **「Download ZIP」** を押す

⚠ **手順2〜3を飛ばすと、中身が空の `main` ブランチが落ちてくる。**

## 方法C：git clone（2回目以降が速い）

一度クローンしておけば、次からは `git pull` で差分だけ落ちる。

```bash
git clone -b claude/great-mayer-lissxp https://github.com/golfbacca/laughing-spoon.git
```

更新を取るとき：

```bash
cd laughing-spoon && git pull
```
