トトンと よるの トイレ ／ レタッチのための手引き
================================================================
作成: 2026-09-01

生成で直しきれなかったぶんを手で直すための資料。
「どのファイルを触るか」「触るときの制約」「どこが崩れているか」
の3つを書いてある。


----------------------------------------------------------------
1. 触るファイル
----------------------------------------------------------------
  docs/絵本KDP_3冊目_画像/*.jpg   ← ここの20枚だけ

  ・4096 x 4096 の正方形 JPEG
  ・文字はまだ入っていない（絵だけ）
  ・レタッチ後も【同じファイル名・同じ寸法】で上書き保存する

  触らないもの:
    docs/絵本KDP_3冊目_完成ページ/  … 文字を載せたあとの出力。自動生成
    docs/絵本KDP_3冊目_入稿/        … EPUB・PDF。自動生成
    _anchor_*.jpg                   … 生成用の参照画。ページではない

  レタッチが済んだら、こちらで下記を回して作り直す:
    compose3.py → compose_cover3.py → build_epub3.py
                → build_pdf3.py → build_cover_wrap3.py

2. 守ってほしい制約
----------------------------------------------------------------
(1) 全面ぬり。白い縁を作らない
    印刷用に塗り足しを取るので、絵は四辺の端まで描かれている必要がある。
    枠や余白を付けない。

(2) 正方形 4096 x 4096 を保つ
    トリミングして縦横比が変わると、組版でずれる。

(3) 文字が乗る帯を静かに保つ
    各ページの上または下に文字を後載せする。その帯には
    細かい模様や濃い色を置かない。文字色は濃い茶（74,55,45）なので、
    帯は明るいままにしておく。

    帯の位置と高さ（画像の端から測った px）:

(4) 判定の基準（この本で崩れやすい4点）
    ・敷布団＝クリーム、掛け布団＝もえぎ。
      ミオの体が触れている面は必ずクリーム。緑は上か横だけ
    ・あかりはドーム型。笠の直径は座面の3分の2。キノコ型にしない
    ・丸椅子はクルミ色（床板よりはっきり濃い）。貫は横一本
    ・トトンは起きているとき必ず黄土色のリュックを背負う。
      眠るのは 03 と 18 の2枚だけで、そこでは外して床に置く

4. 別世代から差し替えたいとき
----------------------------------------------------------------
  20枚ぶんが4世代、git に残してある。作業中のファイルに触れずに
  別の場所へ取り出せる。

    a6fb60a  08-30  寝具を直す前（緑が敷パッドになっていた）
    0e5a209  08-31  寝具・消灯・廊下の間取りを直した
    de694e9  09-01  袖・リュック・12/13の洗面台を直した
    70ba278  09-01  あかり・丸椅子・廊下の壁をそろえた（＝現在）

  20枚まとめて取り出す:
    git archive a6fb60a "docs/絵本KDP_3冊目_画像" | tar -x -C /tmp/gen1

  1枚だけ取り出す:
    git show de694e9:"docs/絵本KDP_3冊目_画像/04_場面03_でられない.jpg" > /tmp/06_v3.jpg


----------------------------------------------------------------
5. なぜ生成で詰んだか（次の本のために）
----------------------------------------------------------------
  1か所直すと別の場所が崩れる。これは腕の問題ではなく、
  【毎回、絵ぜんぶが引き直される】という仕組みそのものによる。
  20ページで各1割崩れれば、全ページ無傷の状態は事実上作れない。

  対処として有効だったのは、崩れやすい要素ごとに参照画を切り分けること
  （作業記録8章）と、機械で外れページを特定すること（同16章）。
  それでも残差は消えなかった。

  次の本では、生成で詰める範囲をあらかじめ狭くしておくとよい:
    ・部屋の中の固定物（家具・戸・窓）を減らす
    ・カメラ位置の種類を減らす
    ・小道具は「形が単純で言葉で一意に決まるもの」にする
      （今回の「あかり」は、ドーム型とキノコ型の間で最後まで揺れた）
