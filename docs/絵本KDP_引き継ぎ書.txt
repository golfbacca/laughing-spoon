トトンと おでかけトイレ ／ 引き継ぎ書
================================================================
作成: 2026-08-17
この文書は「セッション側でやったこと」と「利用者しかできないこと」を
分けて書いたものである。上から順に潰せば出版できる。


----------------------------------------------------------------
A. セッション側で完了しているもの
----------------------------------------------------------------

  ■ 入稿ファイル（docs/絵本KDP_入稿/）

    トトンとおでかけトイレ.epub
        Kindle固定レイアウト。13ページ。著者「はりま せいじ」。
        表紙は 1600x2560（Kindleの比率）。そのまま登録できる。

    本文_ペーパーバック_8.5inch角.pdf
        24ページ ／ 8.75 x 8.75 インチ（仕上がり8.5角＋塗り足し0.125×2）
        構成: 中扉1 ＋ 奥付1 ＋ 本文12 ＋ 白10（最小24ページに合わせるため）
        検証済み: 全24ページが同一寸法。

    表紙ラップ_8.5inch角_背0.0540in.pdf
        1ページ ／ 17.304 x 8.75 インチ
        内訳: 裏8.5 ＋ 背0.054 ＋ 表8.5 ＋ 左右塗り足し0.25
        背が細いため背文字は入れていない。
        検証済み: 寸法・ページ数とも一致。

  ■ 完成ページ（docs/絵本KDP_完成ページ/）

    本文12場面（4096x4096・300dpi）に文字を載せたもの。
    PB_表表紙_正方形.jpg / PB_裏表紙_正方形.jpg  ペーパーバック用（正方形）
    01_表表紙_Kindle_1600x2560.jpg / 01_表表紙_2to3.jpg / 14_裏表紙_2to3.jpg
                                                  Kindle用（縦長）

    ※ペーパーバックは正方形、Kindleは縦長で、表紙の絵が別になっている。
      判型が違うため同じ絵は使えない。文字の書体は揃えてある。

  ■ 組版スクリプト（docs/絵本KDP_組版/）

    compose.py            本文ページに文字を載せる
    compose_cover_pb.py   ペーパーバック表紙・裏表紙に文字を載せる
    build_epub.py         EPUBを組む
    build_pdf.py          本文PDFを組む
    build_cover_wrap.py   表紙ラップを組む（引数で背幅インチを渡せる）
    fonts/                Zen Maru Gothic / M PLUS Rounded 1c
                          どちらも SIL Open Font License。
                          商用利用・埋め込み・再配布が可能。

    文字の色・サイズ・位置は各スクリプト冒頭の設定だけで変えられる。
    直したくなったら編集して再実行すれば全部作り直せる。

----------------------------------------------------------------
B. 利用者にしかできないこと（順番に並べてある）
----------------------------------------------------------------

■ B-1. 著者名 → 決定済み「はりま せいじ（HARIMA SEIJI）」

  build_epub.py / build_pdf.py / 入稿ファイルに反映済み。
  KDPの登録画面の著者欄にも同じ表記を入れること。

  ※既刊（塗り絵4点）は「ツカサ マコト」表記。
    KDPは著者名を文字列で扱うため、両者は別著者として扱われる。
    まとめたい場合は表記を寄せる必要がある。
    分けたい場合は意図的な使い分けとして成立する。
    同名チェックの実測は末尾「E」を参照。

■ B-2. KDPの画面の値 → 確定済み（2026-08-17）

  利用者がKDPの画面で確認し、次の値が確定した。反映済み。

    最小ページ数   24ページ          → 本文PDFを24ページで作成
    判型           8.5 x 8.5 インチ  → カスタムサイズで指定可能
                                       （標準の一覧に正方形は無い）
    背幅           0.054 インチ      → 表紙ラップに反映
    用紙           本文プレミアムカラー（白）90g/m²

  ★ 入稿時に必ず選ぶこと

    裁ち落とし設定 → 「裁ち落とし (PDF のみ)」を選ぶ
      画面の初期値は「裁ち落としなし」になっている。
      本文PDFは塗り足し込みで作ってあるので、
      「なし」のままだと絵の端が白く残るか、寸法が合わずに弾かれる。

  ■ まだ確認が要るもの

    □ 印刷費と最低販売価格
        紙の絵本の実売帯は 900〜1,320円（作業指示書5章の実測）。
        その帯に収まらないなら紙は見送るか、ページ数を減らす。
    □ 電子の70%ロイヤリティが取れる価格帯
        希望価格は300円（9章）。画面のロイヤリティ表示で確認する。

■ B-3. Amazonの検索窓で3語を目視確認する   【推奨】

  ご自分の端末でAmazonの検索窓に「絵本」と打ち、候補に
  「絵本 0歳／1歳／2歳」が出るかを見る。
  サジェストは履歴と地域で変わるため、実測値と違う可能性がある。
  違っていたら、実際に出た語をキーワードに使う。

■ B-4. KDPに登録する          【必須】

  9章の出版文をそのまま使う。
    タイトル      トトンと おでかけトイレ
    サブタイトル  2さい 3さい 4さいの「いま いきたい」が いえるようになる絵本
    内容紹介文    9章の本文をコピー
    カテゴリ      絵本（Kindleストア）＋ 学習 ＋ 就寝前の読み聞かせ
    キーワード7個 9章の【】付きの7語をそのまま
    KDPセレクト   登録する（90日Amazon独占）

■ B-5. AI生成コンテンツの申告   【必須・省略不可】

  画像はすべて生成AI（Gemini API / gemini-3.1-flash-image）で作った。
  KDPの登録画面のAI申告項目で「AI生成」を申告する。
  隠して出すのは規約違反で、出版停止のリスクがある。
  申告しても出版はできる。
  ※本文PDFの奥付にも「この本のイラストは生成AIを使って制作しました」と
    入れてある。ただし商品説明への記載は義務ではなく、KDPの申告とは別物。

■ B-6. 口座と税情報の登録      【必須・初回のみ】

  KDPの支払い設定。セッションからは触れない。

■ B-7. 出す前の最終チェック

  9章の「出す前の最終チェック」を上から潰す。
  特に、全ページを原寸で1枚ずつ見ること（12章の結論）。


----------------------------------------------------------------
C. 判断が要る（決めれば私が作業する）
----------------------------------------------------------------

  □ 中扉と奥付のデザイン
      いまは文字だけの簡素なページ。絵を入れることもできる。
  □ 本文の文字サイズ
      いま4096px幅に対して150px。大きくも小さくもできる。
  □ 白ページの扱い
      24ページに満たない分を白で埋めている。
      場面を割って本文を増やす手もある（7章のB案）。
  □ 電子版に中扉・奥付を入れるか
      いまEPUBは表紙＋本文12ページのみ。紙と揃えることもできる。


----------------------------------------------------------------
D. 既知の残件（直さずに出せる水準・記録のみ）
----------------------------------------------------------------

  ・表紙のトトンがミオちゃんの腰の高さ。本文は膝の高さ
  ・場面05のトトンが膝丈より大きく見える（寄りの構図）
  ・場面08と09でドアの意匠が少し違う（下框の有無）
  ・「おでかけ先のトイレ」という切り口は、需要語としての実在を
    確認できていない。本設計で唯一の賭け（7章）

E. 著者名の同名チェック（実測 2026-08-17）
----------------------------------------------------------------

Amazon.co.jp を実際に検索して、同名の先客がいるかを確認した。

■ 採用した「HARIMA SEIJI ／ はりま せいじ」

    検索語            件数   内容
    Harima Seiji        0件   なし
    播磨 誠治            0件   なし
    ハリマ セイジ        0件   なし
    はりま せいじ        2件   別人の本。
                              『政治はケンカだ! 明石市長の12年』
                              『性同一性障害の医療と法』
                              いずれも「はりま」「せいじ」が
                              書名・内容の語に部分一致しただけで、
                              同名の著者ではない。

  → 同名の著者は見つからなかった。著者名としては空いている。

■ 参考: 「AMASE HIJIRI ／ あませ ひじり」

    Amase Hijiri        0件   なし
    あませ ひじり        0件   なし
    天瀬 聖              2件   別人。アニメ『魔都精兵のスレイブ』の
                              アクリルスタンド2点。書籍ではない。

  → こちらも同名の著者はいない。どちらを選んでも競合しない。

■ 前任「つかさ まこと」との比較（2026-08-17 実測）

    ツカサ マコト      15件   全部が別人の本
    つかさ まこと      15件   ほぼ同じ顔ぶれ
    同名・類似名の別著者が3系統存在していた
      （つかさ まこと／司 真／コロナ・コミックスの作品群）

  → 名前を変えたことで、同名の先客がいる状態から
    いない状態に移った。これは実測で確認できた改善である。

■ 注意（実測の限界）

  ・0件は「Amazonの検索結果に出てこない」という意味であって、
    その名前の著者が世界に存在しないという意味ではない。
  ・検索結果は日々変わる。出版直前にもう一度確認するとよい。
  ・そもそも同名の別人がいてもKDPは出版を止めない。
    ここで見ているのは「読者が著者名で検索したときに
    別人の本が先に並ばないか」という導線の話である。
