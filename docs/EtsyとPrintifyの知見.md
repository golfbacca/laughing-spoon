# EtsyとPrintifyの知見（案件をまたいで使う）

**ゴルフタオル9商品とガーデンフラッグ5商品で実際に詰まった点と、その答え。**
新しい商品カテゴリを始めるときは、**まずこれを読むこと。** 同じ穴に落ちなくて済む。

出典は `garden_flag/docs/` の各文書。詳細はそちらを見る。

---

## 1. ★画面に出ない制約（ここで丸1日溶かした）

### 名入れの説明文に「全大文字の語」は1つまで

**Etsyの制約。超えると Printify の Publish が汎用エラーで失敗し、理由はどこにも出ない。**

```
Sorry, we couldn't publish this product. Please try again later or
get in touch with support if the issue reoccurs.
```

旧版の文には `SMITH` / `THE` / `SMITHS` の**3つ**あった。これだけで5商品とも公開できず、
接続・支払い・タグ・配送プロファイル・引用符・文字数上限と6つ潰して**丸1日かかった。**

**検査ツール：**

```bash
python3 garden_flag/tools/check_personalization.py "文面"
```

上限1に対して**0にしておくのが安全**（PrintifyとEtsyで数え方がずれても落ちない）。

### 詰まったときの動き方

**推測で総当たりしない。ログを持っている側に人間を要求するほうが速い。**

| | |
|---|---|
| Printifyのサポートは**まずボット** | 「ドキュメントに記載がありません」しか言えない |
| **人間に回す言い方** | `If support cannot see that either, please say so directly.`（見られないならそうとはっきり言ってください）**白黒つけさせる質問はボットが処理できない** |
| サポートチャットは**1通500字** | 超えると**黙って切れる**。切れたことに気づかず1次対応のテンプレ返答をもらった |
| 送る順番 | **1通目に「相手の前提の否定」と「そちらにしかできない依頼」を固める。** 2通目以降が読まれなくても効く |

## 2. Printify → Etsy の公開

| 事実 | 意味 |
|---|---|
| **Publish は Etsy で即公開**（下書きにならない） | **セールは公開直後に掛ける。** 定価のまま棚に出る時間ができる |
| `Synced product details` の **`Tags` は初期OFF** | **入れないとタグがEtsyへ送られない。** `Listing health` は「13/13 tags added ✓」と出るので気づけない |
| **`Tags` のチェックは `Save as draft` で外れる** | **`Publish` を押す直前に入れ、`Save as draft` を挟まない** |
| `Mockups` タブの **`⬆ Upload`** に自前の出品画像を入れられる | **Etsy側での写真アップロード作業が丸ごと不要になる。** Primaryを1枚目に指定する |
| `Mockups` の同期チェックは**入れたままにする** | 自前画像がモックアップそのものなので、外すと再公開で送られない |
| 写真の並びは**アップロード完了順**になる | ファイル名順ではない。**Etsy側でドラッグして直す** |
| **印刷エリアは1つしか持てない** | 複数サイズを選ぶと**大きい方の解像度に切り替わり、1枚の画像が cover で両方に使われる**。大きい方に合わせて作る |
| 配送プロファイルは**その商品のproviderのもの**を選ぶ | 別商品のプロファイルを選ぶと送料と納期が混ざる |
| **「Pricing: Too high」は無視してよい** | 上のサイズの金額で機械的に出る警告。**Printifyの既定価格のままでも出る** |

## 3. Etsyの手数料（逆算して3回検算済み）

```
Etsy手数料 = 買い手が払う総額 × 9.5% + $0.45
             （取引6.5% ＋ 決済3%）   （決済$0.25 ＋ 出品$0.20）
```

**利益 = 表示価格 − 製造原価 − 手数料**（送料は買い手負担なら収支に影響しない）

Printifyの画面が出す Profit と**1セントまで一致**した。この式は信用してよい。

## 4. Etsyの上限・仕様

| 項目 | 上限・仕様 |
|---|---|
| タイトル | **140字** |
| タグ | **13個・各20字**・重複不可 |
| 説明文 | 13,000字 |
| 写真 | **20枚**（＋動画2本） |
| 名入れの説明文 | Etsy 255字 / **Printifyの入力欄は120字** |
| 名入れの文字数上限 | 1〜1024（Printifyでは必須項目） |

### サムネイル

**Etsyは1枚目の写真を正方形・縦長・横長に切ってサムネイルにする。**
`Adjust thumbnails` のスライダーを動かすと**寄りすぎて何の商品か分からなくなる。触らない。**
**1枚目は、正方形に切っても商品が丸ごと収まる構図で作る。**

### 属性（Attributes）

**検索結果の左の絞り込みの材料。** タグと違い、**埋めていないと候補にすら入らない。**

- `Item Options` タブの下の方にある
- `+ Add all` はEtsyのAIの推測。**押したあと値を必ず見る**
- `Materials` は最大5だが、**仕様書に literally 書いてある語だけ入れる。** 枠を埋めようとしない
  （書いていない語を足すと誤認させた責任がこちらに来る）
- **カテゴリによって出る欄が違う**（色の欄が無いカテゴリもある）

## 5. Etsy Ads

| 事実 | 意味 |
|---|---|
| **クリック課金** | `Spend $0` は「0クリック」の意味であって、止まっているわけではない |
| **Shop Stats の `Views` と Etsy Ads の `Views` は別物** | Shop Statsは**商品ページが開かれた回数**、Adsは**広告が表示された回数** |
| **自動では止まらない** | 期間を決めたら**手で止める。** カレンダーに入れる |
| Etsy自身が「**30日は変更するな**」と言う | 触ると学習がやり直しになる |
| 「予算を$25に」の案内が出る | **$25/日 × 30日 ＝ $750。** 押さない |

### $3/日を使い切るのに必要な表示回数

| CPC | CTR | 必要な表示 |
|---:|---:|---:|
| $0.20 | 1% | 1,500回/日 |
| $0.30 | 1% | **1,000回/日** |
| $0.30 | 2% | 500回/日 |
| $0.45 | 2% | 333回/日 |

**新規リスティングは実績が無いのでオークションに勝てず、初期は表示が桁違いに少ない。**
（ガーデンフラッグは初日 約31回/日＝必要量の約3%）

⚠ **予算が消化されないとテストが成立しない。**
「0件だったから撤退」が「そもそも誰にも見せていない」だけになる。
**消化額を必ず見る。**

## 6. Etsyの検索順位

- **新規リスティングには一時的な露出ブーストがある**（数日で切れる）
  ガーデンフラッグは公開初日に `golf garden flag` で5件とも1ページ目・最高2位だった
- **ブーストは「実績を作るための猶予期間」。** その間に売上とレビューを作れないと後ろへ落ちる
- 順位を決めるのは**クリック率と購入率**（リスティング品質スコア）。
  **表示がゼロだとスコアは永久に育たない** → 広告は「スコアを育てる表示を買う」行為
- **自分の広告はクリックしない**

### 価格の見え方

**検索結果のグリッドに出るのは表示価格で、送料は出ない。**
送料無料にすると総額はほぼ同じでも**表示価格が上がり、棚での見え方が悪化する。**
（例：$27.99＋送料$6.39＝$34.38 → 送料無料$35.99。総額は+$1.61だが、
隣の競合$22.49と比べて「24%高い」が「60%高い」になる）

**セールは期限で自動的に切れる。** 掛け直すか判断する日を決めておく。

## 7. 運用

### 名入れは手作業

Printifyの名入れ機能は**買い手の入力を中継するだけ**で、こちらのフォントや配置では組めない。

```
Etsyの注文画面で名字を読む
  → スクリプトで画像を生成
  → Printifyで Edit design → 差し替え
  → 注文をPrintifyに送る
```

### 画像の受け渡し（クラウドのClaude Codeへ）

**ZIPにまとめて添付する。** `/root/.claude/uploads/` に**無変換**で届く。
チャットに画像を直接添付すると**WebPへ再圧縮され幅1368px程度に縮小される。**

### 生成AIの出力は柄が壊れていることがある

**目視で気づく前に周期を数値で測る。**
実績：縞1本だけ2.1倍、タータンのセットが縦横で不一致、名入れが利用可能幅の56%しか使っていない。
