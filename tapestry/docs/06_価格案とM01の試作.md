- **26×36 は「入口」。** 利益は薄いが、検索結果の一覧に出る価格を

## 3. M01 の試作（4色）

`tools/make_mountain.py` → `source/M01_<色>.svg`（入稿用）・`preview/M01_<色>.png`（確認用）

| 色 | 名前（案） | 狙う検索語 |
|---|---|---|
| `dawn` | 夜明け：桃色〜すみれ | mountain / sunrise / pink |
| `dusk` | 夕暮れ：テラコッタ | mountain / sunset / **boho** |
| `night` | 夜：紺・三日月・星 | mountain / **celestial** / moon |
| `sage` | 森：セージグリーン | mountain / sage green / nature |

**形（稜線・太陽の位置）は4色共通。** パレットだけ差し替えるので、シリーズとして揃い、色の追加も1行で済む。

### 実測・検査

| 項目 | 値 |
|---|---|
| ファイル | 0.02〜0.03MB（上限20MB） |
| 図形数 | 11（夜は星を含め111）（上限20,000） |
| 太陽の範囲 | x 4,573〜9,077 / y 4,198〜8,702 → **安全域（x 1,420〜12,230 / y 1,230〜14,895）の内側** |
| 月の範囲 | x 4,911〜8,739 / y 3,747〜7,576 → 安全域の内側 |
| 三日月の面積 | 描画した画素数 166,473 ／ 理論値 166,285（**差0.1%**） |
| 26×36 での見え方 | 左右7.3%が切れても、奥の2峰（中心 u=0.17 / 0.83）は残る |

### 自分で見つけて直したこと

1. **月が三日月になっていなかった**（円を2つ重ねたため、輪が2つ交差した形になっていた）→ 円弧2本で正確に作り直した
2. **山が丸く、砂丘に見えた** → 奥の3層を尖った峰に、手前の3層だけ丸い丘にした
3. 拡大すると三日月の先端に欠け、奥の谷底に平らな線 → 円弧の計算と峰の幅で解消
