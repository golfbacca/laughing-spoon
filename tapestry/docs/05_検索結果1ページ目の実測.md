## 1. ★最大の発見：上位は「織り（woven）の綿」。こちらの「印刷のポリエステル」とは別の商品

1ページ目の大半は、**ジャカード織りの綿のブランケット兼タペストリー（房付き）**。
タイトルに `Woven` `Cotton` `Blanket` が入り、絞り込みのチップにも
**`Cotton` `Linen` `Woven` `Natural Fiber`** が出ている。

PrintifyのIndoor Wall Tapestry は**ポリエステルに昇華印刷**（`docs/01`）。**織りではない。**

| | 織り（woven・綿） | 印刷（printed・ポリエステル） ← こちら |
|---|---|---|
| 1ページ目の割合 | **約6〜7割** | 約2〜3割 |
| 価格帯（セール後） | $25〜$90 | **$15〜$35**（大判の布キャンバスは$35〜40） |
| 見た目 | 房・織り目・厚み | 平ら・薄い・発色が良い |

⚠ **出品文に `woven` `cotton` を入れてはいけない。** 書いていないことを書くと誤認の責任がこちらに来る
（`docs/EtsyとPrintifyの知見.md` §4 の Materials と同じ考え方）。

| 語 | 1ページ目の中身 |

| `celestial` | 紺地に星・月の**織りブランケットが席巻**。印刷は EmpoweringDecor（2.7k）が強い |

## 3. 26×36 の採算（送料無料・送料$5.29は最小サイズの値と仮定）

```
利益 = 表示価格 − 原価$16.75 − 送料$5.29 − (表示価格×9.5% + $0.45)
```

| 表示価格 | 手数料 | 利益 |
|---:|---:|---:|
| $24.99 | $2.82 | **$0.13** |
| $27.99 | $3.11 | $2.84 |
| **$29.99** | $3.30 | **$4.65** |
| $32.99 | $3.58 | $7.37 |
| $34.99 | $3.77 | $9.18 |

⚠ **相場 $27〜31 に合わせると、26×36 の利益は$3〜5。** ガーデンフラッグで「広告の獲得単価（約$15）を吸収できない」
と書いた問題（`garden_flag/docs/15` ③）がもっと悪い形で出る。

→ **利益は大きいサイズで取る設計にする**（`large` がオートコンプリートに出ていた＝大判を探す人がいる）。
50×60 / 68×80 / 88×104 の**送料が分からないと計算できない。**

## 4. 提案

**題材：平塗りの「層状の山並み＋太陽／月」。**

- `mountain` に正面から入り、太陽・月で `celestial` にも掛かる
- 1ページ目に**同じ作風の実売例が2店**ある（需要の裏付け）
- SVG（平塗り＋グラデ）で**最も描きやすい**。`docs/04` でグラデ・透明が出ることも確認済み
- 色違い（夜明け・夕暮れ・夜）で**シリーズ化しやすい**

**差別化**：競合2店は1枚絵／細長い2枚組。こちらは**縦長4サイズ（88×104まで）を選べる**ことと、
**色の組み立て**で勝負する。（作風の具体案は次の文書で出す）
