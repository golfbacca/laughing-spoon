## 2. ★サイズの縦横比がそろっていない（実測）

知見 §2「**印刷エリアは1つしか持てない。複数サイズを選ぶと大きい方に切り替わり、
1枚の画像が cover で両方に使われる**」がそのまま当たる。

最大の 88×104 に合わせて1枚作った場合、各サイズで**どれだけ切れるか**：

| サイズ | 縦横比 | 切れ方 | 残る割合 |
|---|---:|---|---:|
| 34×40 | 0.850 | 上下 | 99.5% |
| 50×60 | 0.833 | 左右 | 98.5% |
| 68×80 | 0.850 | 上下 | 99.5% |
| 88×104 | 0.846 | — | 100% |
| **26×36** | **0.722** | **左右** | **85.4%** ← 左右が7%ずつ消える |
| **57×57** | **1.000** | **上下** | **84.6%** ← 上下が8%ずつ消える |

**→ 34×40 / 50×60 / 68×80 / 88×104 の4サイズは1枚の絵で出せる（差1.5%以内）。**
**26×36 と 57×57 は同じ絵を使うと端の要素が切れる。** 出すなら別商品にするか、
端に何も置かない構図にする。

⚠ ただしこれは「Printifyが cover で中央合わせする」前提の計算。
ガーデンフラッグで観測した挙動なので、タペストリーでも同じかは画面で確認する。

## 3. ガーデンフラッグの反省を、着手前に当てはめる

| 前回の詰まり | タペストリーでどうするか |
|---|---|
| ゴルフタオル：検索流入ゼロ | **広告を最初から予算に入れる** |
| 利益$6.54では広告の獲得単価（約$15）を吸収できない（`garden_flag/docs/15` ③） | **単価を上げられる商品を選ぶ。** タペストリーは大判で$30〜60帯が普通なので、ここは有利な可能性 → 原価を見て計算する |
| クリスマス案は**誰も検索していない語**だった（`garden_flag/docs/08`） | **デザインより先に、Etsyのオートコンプリートで検索語の実在を確かめる** |

## 4. 本人に確認してもらうこと

### ① Printifyの画面で読む（クラウドからは見えない）

1. 上のURLを開く
2. ページの中ほどにある **プロバイダの一覧**（`Print providers` 等の見出し）を見る
3. **米国拠点（`United States`）のプロバイダ**を1つずつ見て、次を控える：
   - プロバイダ名
   - **選べるサイズ**
   - **サイズごとの原価**（`Price` / `Production cost`）
   - **米国への送料**（1枚目 / 2枚目以降）
   - 製造日数
4. 1つ選んで **`Start designing`**（緑色のボタン）を押す
5. 画面下でサイズを1つ選び、左の **`Upload`** に出る **推奨ピクセル寸法**を控える
   （**最大サイズ 88×104 で**。複数サイズを選ぶと大きい方に切り替わるため）
6. **何も保存せずに閉じてよい**

→ 数字はスクショで送ってもらえれば、こちらで表に起こす。
