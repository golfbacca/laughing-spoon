## Etsyの店名の決まり

- **4〜20文字・英字と数字だけ**（空白・記号・日本語は不可）。単語の区切りは大文字で見せる
- 他の店と同じ名前は使えない → **空いているかは本人がEtsyの画面で確認**（クラウドからEtsyに届かない）
- ⚠ **Etsyは1アカウントにつき1店。** 別の店を作るには、別のメールアドレスで新しいアカウントが要る。
  Printifyは1アカウントで複数の店をつなげる

## 新しい店を作るか、OnePureStrike に出すか（比較・2026-10-19）

### 前提（いまの OnePureStrike の実績）

| | 実績 |
|---|---|
| 商品 | ゴルフタオル9・ガーデンフラッグ5 |
| 売上・レビュー | **0件・0件** |
| 広告 | $3/日で稼働中（ガーデンフラッグのテスト・11/18まで） |

→ **引き継げる信用（レビュー・販売実績）はまだ何も無い。** 既存の店を使う利点の大半はここで消える。

### 新しい店を作る

| メリット | 中身 |
|---|---|
| **広告のテストが混ざらない** | Etsy Ads は**店ごとに1つのキャンペーン・1つの予算**。同じ店に出すと、新しい出品は広告対象に自動で入ることがあり、**$3/日をガーデンフラッグとタペストリーで取り合う**。11/18の撤退判断が濁る |
| **店の見た目が揃う** | 買い手が店のページを開くと、山のタペストリーの横にゴルフタオルが並ぶ。説明文の「他の色は店で見てください」も、専門店のほうが効く |
| **成績を別々に測れる** | Shop Stats・広告の数字がタペストリーだけになる |
| 名前を作風に合わせられる | 「QuietPeakStudio」など |

| デメリット | 中身 |
|---|---|
| **手間（本人の作業）** | 別メールで新アカウント → 本人確認・入金口座・税の情報（**本人のみ**）→ 店の方針・配送設定 → **Printifyに新しい店をつなぐ（本人がOAuth許可）** → 下書き4つを新しい店へ移す。**半日〜1日** |
| **公開が遅れる** | 新しい店はEtsyの審査で数日止まることがある。**年末の贈り物需要に入るのが遅れる** |
| 費用 | Etsyは地域によって**新規出店時に一度だけの手数料**を取る場合がある（⚠ 金額・対象は要確認） |
| 管理が2つになる | ログイン・メール・注文の確認が2か所 |

### OnePureStrike に出す

| メリット | デメリット |
|---|---|
| **今日すぐ公開できる**（下書きはこの店につながっている） | 広告の予算をガーデンフラッグと取り合う（タペストリーを広告から外せば避けられるが、その場合タペストリーは広告なしになる） |
| 手間・費用ゼロ | ゴルフの店名で山の絵。店のページが「何の店か分からない」 |
| | 成績が混ざる |

### 判断

**新しい店を作るほうを勧める。** 理由は、既存の店に引き継げる実績が無い（売上0・レビュー0）ので、
**既存の店を使う最大の利点がそもそも存在しない**こと。逆に、広告の取り合いと店の印象のずれは、出した瞬間から効く。

**ただし、公開を急ぐなら逆。** 年末商戦を重く見るなら、OnePureStrike に出して**タペストリーは広告から外す**のが最短。

**本人決定（2026-10-19）：新しい店を作る。** 手順は `docs/12`。
