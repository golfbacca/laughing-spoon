# 08. 出品文言（M01・4色）

**検査：`python3 tapestry/tools/copy_m01.py`**（タイトル140字・タグ13個×20字・禁止語を検査。4色とも合格）

## 0. 語の選び方

| 英語 | 日本語 | なぜ入れるか |
|---|---|---|
| **Mountain Tapestry** | 山のタペストリー | 主軸の検索語（`docs/03`）。**全色でタイトルの先頭**（Etsyは先頭40字を重く見る） |
| **Wall Hanging** | 壁掛け | オートコンプリートで4語とも1位（`docs/03`）。tapestry の言い換えとして買い手が普通に使う |
| **Large** | 大きい | オートコンプリートに `large` が出る。88×104まであるので嘘にならない |
| **Boho** | ボヘミアン風 | 題材ではなく雰囲気の語（`docs/05`）。部屋の趣味で探す人を拾う |
| **Minimalist** | ミニマル（簡素） | 平塗りの作風を正直に表す語 |
| **Bedroom Decor / Dorm Room Decor** | 寝室の飾り／学生寮の飾り | タペストリーの使われ方そのもの。**寮（dorm）は米国の定番需要** |

**入れない語：** `woven` `cotton` `linen` `fringe` `handmade`（この商品に当てはまらない。`docs/05`）

### なぜ「織りではない」とわざわざ書くか

1ページ目の6〜7割が織りの綿（`docs/05`）。**買い手は織りを想像して買う可能性がある。**
届いてから「薄い」「房がない」で低評価が付くのが、レビュー0の店にとって一番痛い。
先に書いておけば、それを承知の人だけが買う。
