## 3. 安全域（⚠ 2026-10-04 訂正）

### 訂正の理由

最初は「3サイズを選ぶと、Printifyが全サイズ共通の安全域を点線で出す」と読んだが、**誤り**だった。
そのときのキャンバスの縦横比を測り直すと **537÷723 = 0.743**。
これは **26×36＋塗り足し（29×39インチ ＝ 0.744）そのもの**で、
**エディタが 26×36 のキャンバスを表示していただけ**だった。
（4サイズ選択時のM01のスクショでは 612÷723 = 0.847 ＝ 88×104 の形。どのサイズを表示するかの規則は未解明）

### 測り直した値

Printifyの点線は、**どのサイズでもキャンバスの端から約3インチ**（塗り足し約1.5インチ＋余白約1.5インチ）：

| | キャンバス | 点線までの割合 | インチ換算 |
|---|---|---:|---:|
| 88×104（`docs/03`） | 91×107.5インチ | 横3.7% | 約3.4インチ |
| 26×36（上の誤読したスクショ） | 29×39インチ | 横10.4% | 約3.0インチ |

### 作図ルール（13650×16125 で描く・縦長4サイズ共通）

26×36 で最も厳しくなる。26×36 では絵が約413px/インチに縮むので、3インチ ≒ 1,240px。

```
左右：26×36で切れる分 約835px ＋ 余白 1,240px ＝ 約2,075px
上下：切れない ＋ 余白 1,240px ＝ 約1,240px

重要な要素 … x: 2,075〜11,575 / y: 1,240〜14,885 の内側
           ＝ 幅の約70% × 高さの約85%
```

（旧ルール x 1,420〜12,230 は**誤り**。M01の太陽・月は新ルールでも内側に入っている）
