### 商品ページ（`Printify Choice` タブ）

| 項目 | 値 |
|---|---|
| 製造 | **Printify Choice**（注文ごとにPrintifyがプロバイダを自動で選ぶ） |
| 原価 | **USD 16.75〜**（Premiumなら USD 12.12〜）※最小サイズの値と思われる |
| 送料 | **USD 5.29〜**（Economy / Standard） |
| 製造日数 | 1.5日（米国注文の平均） |
| サイズ | **8種類**「26"×36" 〜 104"×88"」 |

| 付加機能 | Branded inserts / Gift messages |

⚠ **公開ページ（Web検索）の6サイズと数が合わない。** `104"×88"` という表記から、
**横長の向きが別サイズとして入っている**と推測。8種類の正確な一覧は未確認。

### エディタ（88"×104" を選んだ状態）

| 項目 | 値 |
|---|---|
| **Production cost** | **USD 47.62** |
| **Print area size** | **13650 × 16125 px** |
| 背景色 | #ffffff（初期値） |
| 注意書き | 灰色の塗り足しまで絵で埋める。重要な要素は**点線の安全域の内側**に置く |

### 入稿サイズの解釈（計算）

```
13650 ÷ 88  = 155.1 px/インチ
16125 ÷ 104 = 155.0 px/インチ
→ 約155 px/インチ（ガーデンフラッグの300 DPIの約半分）
縦横比 13650/16125 = 0.8465（88/104 = 0.8462 と一致）
画素数 = 2億2千万画素。8bit RGBで非圧縮 約660MB
```

**本人の判断どおり、PNGでの入稿は非現実的。** Gemini等の出力（2〜4Kpx程度）を
ここまで拡大すると約4〜7倍になる。

## 2. PrintifyのSVG入稿の制約（ヘルプセンター）

| 制約 | 値 |
|---|---|
| 対応形式 | JPEG / PNG / **SVG** |
| **SVGのファイルサイズ上限** | **20MB** |
| **パス要素の上限** | **20,000個** |
| テキスト | **使えない。** 文字はパス（アウトライン）に変換してから入れる |
| 写真・ラスター画像 | SVGには**向かない**（中に埋め込むなら PNG/JPG で出せ、とのこと） |

出典: [What type of print files does Printify require?](https://help.printify.com/hc/en-us/articles/4483617936657) / [SVG vs PNG for printing](https://printify.com/knowledge-hub/svg-vs-png-for-printing/)

### ここから決まること

1. **絵柄は「平塗りのベクター画」に限られる。** 水彩・油絵・写真風は SVG にできない
   （無理にトレースすると20,000パスを超えるか、なぞった跡が見える）
2. **Gemini の画像をそのまま使う流れは使えない。** 代わりに
   **こちらがSVGをコードで直接書く。** 「生成はこちら」の分担はそのまま
3. **文字を入れるならアウトライン化が必須。** こちらで変換して入れる
4. **入稿前にこちらで検査する項目：** パス数 ≤ 20,000 / ファイル ≤ 20MB /
   `<text>` 要素ゼロ / 埋め込み画像ゼロ
5. ⚠ **グラデーション・クリップ・フィルタがPrintifyで正しく出るかは未確認。**
   最初の1枚は平塗りだけで作り、エディタのプレビューで確かめてから使う

### 平塗りベクターで成立する売れ筋の作風（候補・未検証）

タペストリーで定番の作風のうち、平塗りで描けるもの：

- 太陽と月・星（celestial）
- 山並み・夕日（ミッドセンチュリー風の層状の風景）
- ボーホー柄（虹のアーチ・アーチ状の幾何学）
- 抽象画（Matisse風の切り絵・有機的な形）
- キノコ・植物の平面的なイラスト

**どれが実際に検索されているかは、次のオートコンプリート確認で決める。**
