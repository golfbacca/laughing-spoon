## ④ Printify に新しい店をつなぐ

Printifyは1アカウントで**最大5店**（無料プラン）。今のPrintifyアカウントに足す。

```bash
start https://printify.com/app/stores
```

1. **`Add new store`**（新しい店を追加）を押す
2. **Etsy** を選ぶ → **`Connect`**
3. Etsyの画面に飛ぶ。**新しい店のアカウントでログインしていることを確かめてから**、許可（本人）
   ⚠ 今の OnePureStrike で許可してしまうと、同じ店がもう1つつながるだけになる

## ⑤ 下書き4つを新しい店へコピー

Printifyのヘルプ（[How do I duplicate products in Printify?](https://help.printify.com/hc/en-us/articles/4483625856017-How-do-I-duplicate-products-in-Printify)）より：

1. Printifyの左上で、**今の店（OnePureStrike）**が選ばれている状態で `My Products` を開く
2. タペストリー4つの左の**四角にチェック**
3. **`More actions`** → **`Copy to other store`**（他の店へコピー）→ 新しい店を選ぶ
4. 新しい店に切り替えて、4つ入ったか見る

⚠ ヘルプに「**販売先の制限で一部の情報が失われることがある**」とある。**1つずつ開いて確かめる**：
写真7枚と Primary（寝室）・タイトル・説明文・タグ13個・価格4つ・Offsite Ads OFF・名入れ OFF・
`Variant visibility` 初期値。**`Tags` の同期は公開直前に入れる**（変わらず）。

確かめ終わったら、**今の店（OnePureStrike）側の下書き4つは消してよい**（誤って公開しないため）。

### ⑤-2 説明文を新版に貼り替える（2026-10-22 追加）

4つとも `Listing details` の Description を全部消して、各色の `description.txt`（新版）を貼り直す。

### ⑤-3 製造パートナーを登録する

POD（受注印刷）の商品は、**製造パートナー（Printify / MWW On Demand）を店の設定に登録**する必要があると言われている
（`docs/EtsyとPrintifyの知見.md` §9）。開店の途中か、公開時の `About this listing` で聞かれたら登録する。

  > **Etsy アカウントにリンクできませんでした** — Etsy ペイメントの設定に利用した Payoneer アカウントとは**異なるアカウント**へのアクセスを許可されたようです。正しい Payoneer アカウントにログインしたか確認してください。

  → 推測で総当たりせず、**Etsy のサポートに人間で確認する**（どの Payoneer に結び付いているかは Etsy しか見えない）。

- **2026-11-03：Etsy サポートにメールで問い合わせ済み。チケット ID #28386469**（件名 "Cannot link Payoneer to my second shop StillValleyHome (Vacation Mode)"・エラー画面のスクショ添付）。
  返事の目安 1〜2日。届いた返事は `https://help.etsy.com/hc/en-us/requests/28386469` でも見られる

### Etsy サポートの返事（#28386469・2026-11-03 受信・要約と訳）

| 原文の要点 | 訳 |
|---|---|
