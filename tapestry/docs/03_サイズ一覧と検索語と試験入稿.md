画面の案内：**「Optimal listings have between 5-15 variants」**（1商品のサイズは5〜15個が理想）。

### 方針（提案）

- **縦長と横長は1商品に混ぜない。** 印刷エリアが1つなので、縦の絵は横には使えない
- 縦長4サイズを1商品にする場合、**26×36 で左右7.3%ずつ切れる。**
  → 絵の重要な要素は**中央の約78%幅**に収める（7.3% ＋ Printifyの安全域3.7%）
- ⚠ 「中央合わせで切られる」はガーデンフラッグでの観測。**下の試験入稿で実測して確定させる**

## 2. Etsyのオートコンプリート（本人のスクショ）

| 打った語 | 出た候補 |
|---|---|
| `tapestry` | wall hanging / art / wall art / fabric / hanging |
| `celestial tapestry` | wall hanging / hanging / **（単体）** / **large** / wall |
| `mountain tapestry` | wall hanging / hanging / **（単体）** / **large** / wall art |
| `boho tapestry` | wall hanging / wall art / hanging / **（単体）** / **large** |
| `abstract tapestry` | 未確認 |
| `mushroom tapestry` | 未確認 |

**読み取れること**

1. **3語とも実在する検索語。** クリスマスのガーデンフラッグ案（候補が出なかった）とは違う
2. **3語とも `large` が出る。** 大きいサイズを探す人がいる → 大判サイズを外さない理由になる
3. **`wall hanging`（壁掛け）が3語とも1位。** タイトル・タグに必ず入れる語
   - `wall hanging` ＝「壁に掛けるもの」。tapestry の言い換えとして買い手が普通に使う語
4. ⚠ **オートコンプリートは「検索する人がいるか」しか分からない。競合の強さは分からない。**
   作風を1つに絞るには、検索結果1ページ目の価格とレビュー数が要る（`garden_flag/docs/12` と同じ測り方）

Etsyの「今週の人気検索」は halloween decorations / friendsgiving favors / halloween wreath /
grinch mask / trick or treat bag（2026-10-03）。季節ものが強い時期。
