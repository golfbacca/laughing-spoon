# ショップのブランド素材（Etsy: OnePureStrike）

案件横断の素材。`make_logo.py` で作り直せる。

```bash
cd shop_brand && python3 make_logo.py
```

## ショップアイコン

**採用：`logo_D.png`**（500×500・旗とグリーン・文字なし）

| 案 | 中身 | 70pxでの見え方 |
|---|---|---|
| **D** | **旗とグリーン・文字なし** | **✅ はっきり読める。採用** |
| A | 旗とグリーン・文字あり | 文字が潰れ、そのぶん図が小さい |
| E | ゴルフボール・文字なし | **ディンプルが消えてただの白い丸になる** |
| C | 文字だけ（3行） | 形は残るが読めるとは言いがたい |
| B | ゴルフボール・文字あり | 文字もボールも小さい |

比較は `_comparison.png`（原寸・140px・70pxを並べてある）。

### 設計の根拠

| 判断 | 理由 |
|---|---|
| **文字を入れない** | **Etsyはアイコンの隣に必ずショップ名を文字で出す**（検索結果の `By OnePureStrike`）。アイコンが名前を綴る必要はなく、外したぶん図を大きくできる |
| **旗とグリーン** | ガーデンフラッグの出品画像と同じモチーフ（R02・R05に同じ緑とピンがある）。店と商品が揃う |
| **赤を入れる** | 小さいアイコンが並ぶ一覧で、緑や白ばかりの中から見つけてもらえる |
| 緑は `(22,86,52)` | 出品画像の `ACC` と同じ（`garden_flag/tools/mockup/listing_img.py`） |

### ★小さいときに読めるかを必ず測る

Etsyのショップアイコンは**検索結果やレビュー欄で70px前後まで縮む。**
**500pxで作って満足せず、70pxに縮めて確認すること。**
`make_logo.py` は比較シートを自動で出すので、新しい案を足したら必ず見る。

## アップロードの場所

```
Shop Manager → Settings → Info & appearance → Shop icon
```

`Etsy search visibility` のページに出る **`Add logo`** ボタンからも行ける。
