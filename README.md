### 導線は2本だけ

**オープンチャットは使いません。** 制作者はどこにも参加しておらず、
自作スタンプを広めるために今から入るのは、`docs/導線_非当事者としての売り方.txt` が
明確に禁じているアストロターフィングに当たるため。残るのは
**① 特集バナー**（8/31〜10/12・個人が金で買える露出ではない）と
**② X**（自力で動かせる唯一の導線）の2本。
→ `docs/販売開始日_手順.txt` の「導線の確定」

### 公開の原則

**プレビューシート（16枚一覧）を公開してよいのは、そのセットの承認が下りた後。**
文言もコンセプトも法的にほぼ保護されない（短い語句は著作物性が認められにくく、
アイデアは保護対象外、LINEの審査も新規性を見ない）。止める手段が無い以上、
予防しかない。承認が手元にあれば追随者は発売で先行できないので、そこが解禁日。
検品は「用語の質問だけ」（画像なし）か有料の1対1相談で行う。
→ `docs/導線_非当事者としての売り方.txt`

**特集は「取れたらラッキー」。参加を前提に設計を歪めない。**

**⚠️ 2026-08-25 訂正：価格の前提が間違っていました。**
「最低価格は120円、特集条件が￥190〜なので250円へ上げる必要がある」と
考えていましたが、**LINEの最低価格は190円で120円は存在しません**

### ⚠️ 価格変更はしない（プレミアムが自動でOFFになる）

**販売中の価格を変えるには販売停止が必要で、停止すると
「LINEスタンプ プレミアム」への参加設定が自動的に[参加しない]になります。**
プレミアムの分配はこのシリーズの収益設計の本体なので、
**60円の値下げのために触る価値がありません**（戻し忘れれば恒久的な損失で、
気づく手段もない）。加えて3時間以上の販売停止と24時間の変更ロックも付きます。

**B1・B2・Aは250円のまま置きます。** 10/13の値下げ計画は撤回。
それでも変更する場合の手順は `docs/申請用_販売情報.txt` の
「価格変更の落とし穴」節に、プレミアム再設定を含めて書いてあります。

特集のために次の3つは絶対にやらない — 締切に合わせて検品を省略する／
申請を早めて大量申請リスクを取る／参加条件のために中身を歪める
（例：ネガティブ枚数を稼ぐために勝ち札・誇り札を削る）。

## 設計方針

- 「可愛い絵」ではなく **感情のショートカットキー** として設計
- 怒りではなく **「壊れの実況」** を描く。主語を書かないことで黒くする
- 禁止：説教くさいポジティブ／シモ・下ネタ／暴力・脅迫語／特定企業名
- キャラなし、文字のみ

## セット構成

| | 界隈 | テーマ | 向き |
|---|---|---|---|
| B 1セット目 | コールセンター | 実況と連帯 | 外へ投げる黒さ。オープンチャットに放り込む言葉 |
| B 2セット目 | コールセンター | 壊れの実況 | 内向きの黒さ。自分が壊れるのを他人事として報告する |
| C 1セット目 | 歯科技工士 | 不可視 | 見られていない黒さ。手がけたものは口の中に入って二度と見られず、作った人の名前も出ない。**15だけが反転し、気づかれないことが勝利になる** |
| D 1セット目 | 歯科衛生士 | 誤認 | 間違われている黒さ。助手と呼ばれ、15分で終わると思われ、磨けていると言われる |
| E 1セット目 | 部活動顧問（専門外） | 未経験 | やったことがないのにやらされている黒さ。顧問も競技も土日も選べない |

各シリーズは**黒さの宛先**で設計が決まる。ここを外すと職場で使えないスタンプになる。

- **B（コールセンター）**… 宛先は客。外部で匿名なので、そのまま外へ投げられる
- **C（歯科技工士）**… 宛先が歯科医師になりかけたが、取引先で同じLINEグループにいる。
  → **指示書・納期・再製という無生物にずらした**
- **D（歯科衛生士）**… 患者は外部で匿名なので、Bと同じ「外へ投げる黒さ」が使える。
  ただし医療職が患者を揶揄すると炎上するため、**直接的な揶揄は1枚も入れず**、
  黒さを予約・時間・自分の身体の側に寄せてある
- **E（部活動顧問）**… 保護者も生徒も管理職も叩けない。**宛先の選択肢が無い。**
  → 黒さは全部 土日・手当・勤務時間という制度に向く。選択肢が無いぶん設計が一意に決まった。
  15「生徒は悪くないんです」は**絶対に外さないこと** — この1枚があることで、
  16枚全体が「生徒への不満」ではなく「制度への不満」だと読める

## 画像の作り直し

```
pip install Pillow
apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra fonts-motoya-l-maruberi
python3 gen_set1.py
python3 gen_set2.py
python3 gen_setA.py
python3 gen_setC.py
python3 gen_setD.py
python3 gen_setE.py
```

`gen_set*.py` の `STICKERS = [...]` が全16枚の設計データ。文言・フォント・サイズ・色・配置を
そこだけ書き換えれば全枚数を再生成できる。確認用のコンタクトシート
（`stickers/set*/_preview_light.png` / `_preview_dark.png`）も同時に出力され、
余白10px以上・透過・ファイルサイズが自動検証される。

次のセットを作るときは `gen_set2.py`（文字のみ）か `gen_setC.py` をコピーして
`STICKERS` を差し替えるだけでよい。別の界隈に横展開する場合は、まず
「その界隈の黒さは誰に向いているか」を決めること。宛先が取引先や同僚になる界隈では、
シリーズCと同じく攻撃先を無生物にずらさないと、職場で使えないスタンプになる。

## LINE申請時の注意

- スタンプは **8 / 16 / 24 / 32 / 40枚** 単位でしか申請できない（各セット16枚）
- 申請時に **「LINEスタンプ プレミアムに提供する」を必ず選ぶ**
  （使用回数に応じた分配が入る。このシリーズの収益設計の要）
- ファイルは `01.png` 〜 `16.png` の番号順でアップロードする
- LINEスタンプメーカー経由の場合、**フチの自動追加を「0／なし」にする**
  （画像側に白フチが入っているため二重になる）
