## 1. プロジェクトの成り立ち

三原誠司さん（63歳）のライフストーリー文書から出発しました。社会人40年・5社目、
ゴルフ歴40年で練習に数百万円を投じながら2005年からベストスコアを更新できていない——
この実体験を、そのままブランドの声にしています。

「ベテランゴルファーの自虐」というニッチは、20案のデザインを経て次の型に落ち着きました。

- **散財して、停滞したまま、それでも愛し続けている**——この世界観で全商品が統一されている
- コピーは英語ネイティブの鉄板構文で、説明なしに伝わるものだけを採用
- 最後に必ず「作者本人も同じ穴のムジナ」と明かして締める（商品説明文の最終行）

## 4. 画像生成のパイプライン（このプロジェクトの核心）

### 4-1. デザイン原本
Gemini（Nano Banana Pro）で20案を生成済み。`Downloads\P01_raw.png` 〜 `P20_raw.png`（848×1264）。
プロンプト集は [golf_towel_20patterns_brief.md](golf_towel_20patterns_brief.md)。

**Geminiでの再生成手順**（Chrome拡張が使える数少ない相手）:
モデルを **3.1 Pro** に切り替え → 参照画像を本人に添付してもらう → プロンプト送信 →
「フルサイズの画像をダウンロード」ボタンをJSでclick → `Downloads\Gemini_Generated_Image_*.png`

実測ノウハウ:
- 入力欄が最初の打鍵を飲み込むので、**必ず打ち直してDOMで文字数を確認**してから送信
- `execCommand('insertText')` が確実（`computer.type` は空振りすることがある）
- 生成物には**✦透かし**が入る。暗色・有色の上だと目立つので要レタッチ
- 円周に沿うテキストは**必ず崩れる**（P11が実例。出品不可のまま）
- 「EXACTLY:」のような指示語がそのまま画像に描かれることがある。
  「The text reads: ... Do not add any other words」の形にする

### 4-2. 入稿データ
`<TAG>_raw.png`（848×1264）→ 3倍拡大 → `<TAG>_print.png`（2544×3792）
→ カバー拡大＋中央クロップ → `<TAG>_upload_5043x7350.png`

### 4-3. 商品写真（Printifyを介さず作る）
Printifyのモックアップは取得できない（ブラウザ全滅）ので、**既存のタオル写真を使い回します**。

ベース: `listing_images\p15_mockup_front.jpg`（2048×2048、Printify生成の実写）

1. **旧印刷を検出** — 彩度で判定（`max(RGB) - min(RGB) > 8`）。生地は無彩色、印刷は有彩色
2. **クリーンプレート生成** — インクを除いた領域から正規化畳み込みで陰影を補間（**sigma 260**）、
   ワッフル地のテクスチャは無地部分からタイリング
3. **新デザインをmultiply合成** — 生地の質感と光が保たれる

実装は `make_towel_listing_images.py` の `mockup()` と `_clean_plate()`。

**座標系**（この写真における実測値・再利用可）:
```
印刷エリア PRINT_RECT = (515, 291, 1518, 1753)   # 入稿データ全体が収まる矩形
タオル本体 TOWEL_RECT = (539, 320, 1495, 1727)   # 全面ベタのデザインはここでマスク
レイアウト用 TBOX     = (517, 297, 1434, 1700)
```

## 5. デザイン破綻の検出と修正（実績4件）

AI生成デザインは**局所的にはもっともらしく、全体で破綻している**ことが多いです。
本人が「なんとなく気になる」と言ったものは、**4件中4件とも本当に壊れていました**。

### 検出手法
- 淡いパターン: 高域通過フィルタ or `ImageOps.autocontrast` で可視化
- 繰り返し模様: 行ごとの**自己相関でピッチを測る**。場所によって値が変われば破綻
- グリッド: 行ごとに要素数と中心座標を出す

### 修正の定石
**「壊れた部分を捨て、その作品自身の正しい部分から採取した要素で組み直す」**。
AIに描き直させると別物になるが、この方法なら筆致も色も完全に保たれます。

### 実績
| 案 | 破綻 | 修正 |
|---|---|---|
| P17 | 上半分7列・下半分8列の継ぎ接ぎ、6段目に穴 | ×と○を切り出して7列×9段に再配置。○が盤面中心に来て構図も改善 |
| P17 | キャプションが `STILL CHASING NUMBER TWO`（英語で「大便」の婉曲表現） | `2005. STILL WAITING FOR THE SEQUEL.` に差し替え |
| P20 | ディンプルが上部ピッチ165pxの不規則な散らばり／下部ピッチ113pxの正しい格子 | 正しい格子を採取して全面に展開 |
| P03 | テーブルの区切り線4本のうち1本だけ紺（他は赤）、太さもバラバラ | 4本とも赤5pxに統一 |
| P01 | 1px枠線／構図が174px下にずれ（上余白396px・下余白48px） | 枠線除去＋垂直センタリング |
| P12 | ✦透かしが残存 | 放射線の角度に沿って複製・除去 |

### 踏んだ罠（繰り返さないこと）
1. **部分差し替えの境目をぼかすと、新旧の模様が半透明に重なって二重に見える**
   → 部分ではなく**全面を組み直す**
2. **明暗マップの平滑化が模様の周期より小さいと、古い模様がマップ経由で新デザインに転写される**
   → 周期より十分大きくぼかす（P20では1/4縮小でGaussianBlur(40)）
3. **消し込み範囲が旧デザインぎりぎりだと、羽根ぼかしが旧インクに掛かってゴーストが残る**
   → 範囲を広く取る（pad 70）
4. グレースケールで処理すると色味が飛ぶ → **チャンネルごとに処理**
