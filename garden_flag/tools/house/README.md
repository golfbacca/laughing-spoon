# ハウスフラッグ 24.5"×32" の道具

## house_build.py — 入稿データを組む

**12"×18" の入稿データ（3900×5700）から** 24.5"×32"（7800×10012）を組む。
元のJPEGからやり直さないのは、12×18の入稿データに
**案ごとの手当てが既に入っている**ため（R01のギンガム補修、R11の紺の地色など）。

```bash
# 名字なし（注文時の合成用）
python3 house_build.py upload_r "R*_upload_3900x5700.png"
# 名字入り（商品作成用）
python3 house_build.py named_r  "R*_SMITHS_3900x5700.png"
```

`house/` に出る。1枚17〜28MB・5枚で約101MB あるので**リポジトリには入れていない。**
必要なときに上のコマンドで作る。

### 仕様

| | 値 |
|---|---|
| キャンバス | 7800 × 10012 px（26.0" × 33.4" @300DPI） |
| 裁ち落とし | 左右 225px(0.75") / 上下 206px(0.69") |
| 袖 | **900px(3") と仮定。⚠ Printifyで要確認** |
| 見える範囲 | 7350 × 8700 px（24.5" × 29.0"） |
| 12×18からの倍率 | 1.81倍 |
| 左右の余白（地色で埋める） | 各 1.38" |
| 実効DPI（Geminiの元画像から） | 85 DPI |

## size_two.py — 2サイズ併記のサイズ図

出品画像の5枚目を差し替える版を作る。
ハウス側は引き伸ばしではなく **実際の入稿データから描いている。**

```bash
python3 size_two.py     # size2/ に5枚出る
```

出来上がりは `garden_flag/listing_house/` に入れてある。
2サイズで出すなら、各商品の `5_size.jpg` をこれに差し替える。
