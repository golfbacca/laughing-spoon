## そのまま使えるもの

### 1. 出品画像7枚の構成テンプレート

ゴルフタオルで9商品ぶん運用した実績のある構成。ガーデンフラッグにそのまま移植できる。

| # | 内容 |
|---|---|
| 1 | メイン（商品名を大きく） |
| 2 | **オチ解説**（デザイン固有。絵柄だけでは伝わらない笑いどころを言語化） |
| 3 | 拡大 |
| 4 | サイズ図解 |

| 6 | ギフト訴求 |

2枚目は当初「装着写真」だったが、生成の手間に対して割に合わないため
**デザイン固有のコピー解説**に変更した経緯がある。転換率にはこちらの方が効くという判断。
ガーデンフラッグでも同じ判断でよい。

### 2. モックアップの自作パイプライン

Printifyのモックアップは環境制約で取得できない。ゴルフタオルでは
**実写1枚から、印刷部分だけを差し替える**手法を確立済み（`make_towel_listing_images.py`）。

1. **旧印刷を検出** — 彩度で判定（`max(RGB) - min(RGB) > 8`）。生地は無彩色、印刷は有彩色
2. **クリーンプレート生成** — インクを除いた領域から正規化畳み込みで陰影を補間（sigma 260）、
   生地のテクスチャは無地部分からタイリング
3. **新デザインを multiply 合成** — 生地の質感と光が保たれる

**ガーデンフラッグに移植する場合に必要なもの：**
- ベースとなるフラッグの実写1枚（Printifyの商品ページから保存、または1枚だけ購入して撮影）
- その写真における印刷エリアの座標実測（タオルでは `PRINT_RECT` 等を実測済み）

**注意：** 布の質感がタオル（ワッフル地・厚手）とフラッグ（ポリエステル・薄手・光が透ける）で
違う。sigma やテクスチャのタイリングは**測り直しが必要**。手法は再利用、数値は再測定。

### 3. Gemini / Nano Banana Pro の実測ノウハウ

- 入力欄が最初の打鍵を飲み込む → **必ず打ち直してDOMで文字数を確認**してから送信
- `execCommand('insertText')` が確実（`computer.type` は空振りすることがある）
- 生成物には **✦透かし** が入る。暗色・有色の上だと目立つので要レタッチ
- **円周に沿うテキストは必ず崩れる**（P11が実例。出品不可のまま）
  → ガーデンフラッグは縦長なので、円形リースの縁に沿う文字などは**設計段階で避ける**
- 「EXACTLY:」のような指示語がそのまま画像に描かれる
  → 「The text reads: ... Do not add any other words」の形にする

### 4. デザイン破綻の検出と修正

AI生成デザインは**局所的にはもっともらしく、全体で破綻している**ことが多い。

**検出：**
- 淡いパターン → 高域通過フィルタ or `ImageOps.autocontrast` で可視化
- 繰り返し模様 → 行ごとの**自己相関でピッチを測る**。場所によって値が変われば破綻
- グリッド → 行ごとに要素数と中心座標を出す

**修正の定石：**
「壊れた部分を捨て、**その作品自身の正しい部分から採取した要素で組み直す**」。
AIに描き直させると別物になるが、この方法なら筆致も色も完全に保たれる。

**踏んだ罠（繰り返さない）：**
1. 部分差し替えの境目をぼかすと、新旧の模様が半透明に重なって二重に見える → **全面を組み直す**
2. 明暗マップの平滑化が模様の周期より小さいと、古い模様がマップ経由で転写される → 周期より十分大きくぼかす
3. 消し込み範囲が旧デザインぎりぎりだと、羽根ぼかしが旧インクに掛かってゴーストが残る → 範囲を広く取る（pad 70）
4. グレースケールで処理すると色味が飛ぶ → **チャンネルごとに処理**

クリスマスのガーデンフラッグは**繰り返し模様（雪の結晶、格子、リース）を使いやすい**ので、
1と2の罠は特に踏みやすい。最初から気をつける。

### 5. 入稿データの作り方

```
<TAG>_raw.png（Gemini出力）→ 3倍拡大 → <TAG>_print.png → カバー拡大＋中央クロップ → <TAG>_upload_<W>x<H>.png
```

ゴルフタオルは 848×1264 → 5043×7350。
ガーデンフラッグ 12"×18" は **3600×5400 px（300DPI）**が目標。縦横比が 2:3 で
タオル（約 0.686）と違うので、**クロップ設計をやり直す**こと。

### 6. 価格設計の型

ゴルフタオル：原価 $10.61 ＋ 送料 $5.39 → 販売 $19.99 → 利益 約 $6.52（利益率 約33%）

同じ考え方でガーデンフラッグの価格を決める。**ただしPrintifyの実原価が未取得**なので、
`docs/01_商品仕様_Printify.md` のチェックリストを先に埋めること。

## 流用しないもの（今回は変える）

| ゴルフタオルでのやり方 | ガーデンフラッグでの方針 | 理由 |
|---|---|---|
| ニッチ性を**デザイン**に効かせ、検索語は一般語 | ニッチ性を**検索語**に効かせる | 検索に出なければデザインは届かない |
| タイトルにコピー（オチ）を置く | **オチは画像の2枚目**。タイトルは検索語だけ | タイトルの文字数は検索マッチ用の資産 |
| 広告なしでオーガニックを待つ | 少額のEtsy Adsで最初の露出を買う | オーガニック0・広告0では入口が存在しない |
| 9商品を作ってから数字を見る | **数字（勝てる語）を見てから作る** | 9商品ぶんの工数が検索0で無駄になった |
