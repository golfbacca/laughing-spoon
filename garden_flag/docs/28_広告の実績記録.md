## 初日（2026-09-27 開始 → 09-28 時点）

### Etsy Ads

| 項目 | 値 |
|---|---:|
| Views（広告の表示回数） | **46** |
| Clicks | 0 |
| **Spend** | **$0** |
| Orders | 0 |

**広告は回っている。** `Spend $0` は Etsy Ads が**クリック課金**だから（0クリック＝$0）で、異常ではない。

### 0クリックは異常ではない

| 想定CTR | 46回の表示で期待されるクリック数 |
|---:|---:|
| 1% | **0.46件** |
| 2% | 0.92件 |
| 3% | 1.38件 |

**そもそも1件出るかどうかの表示数。** CTRが意味を持ち始めるのは
**クリックが5件ほど出てから＝表示250〜500回**。

### ⚠ 本当の論点：表示回数が少なすぎる

| | |
|---|---:|
| $3/日を使い切るのに必要な表示 | **約1,000回/日**（CPC$0.30・CTR1%） |
| 実績 | 約1.5日で46回 ＝ **約31回/日** |
| 達成率 | **約3%** |

（参考：CPC$0.20・CTR1%なら1,500回/日、CPC$0.45・CTR2%なら333回/日が必要）

**予算$3がまったく消化されていない。** 新規リスティングに実績データが無く、
Etsyの広告オークションで勝てていない。Etsyが「30日は学習期間」と言っているのはこれ。

#### なぜ重要か

**予算が使われなければテストそのものが成立しない。**
30日後に「0件だったから撤退」と判断しても、それは
**「このニッチが駄目」ではなく「そもそも誰にも見せていない」**だけかもしれない。

#### 10/04 の判定基準（ここで追加）

| 7日間の消化額 | 意味 |
|---|---|
| $15〜21（予算どおり） | **テストは成立。** `docs/18` の価格調整ルールでCPCを判断する |
| **$5未満** | **テストが回っていない。** 撤退判断の材料にならない。別の手を考える |
