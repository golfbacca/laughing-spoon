## Driveのプロンプト履歴から復元できた作業フロー

1. 本人の「人生の棚卸し」文書を渡す
2. そこから海外デジタルコンテンツ／POD市場で埋もれない商品テーマを10案出す
3. 各テーマの実売状況をEtsy / Amazon KDP / Amazon.comで調査（レビュー数を代理指標にする）
4. 「ニッチだけど需要がある＝歪み」を根拠つきで3つに絞る
5. 最初に作る商品を1つだけ選ぶ → **⑩ ゴルフ自虐（One Pure Strike）** を採用

   （パターンごとに新規チャット、生成前に本人確認）
