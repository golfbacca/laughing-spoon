# 商品仕様とファイル要件（Printify / Garden Flag）

## 対象商品

Printifyカタログの **Garden and House Banner**（generic brand / 商品ID 976）。
※ Printifyには他にもフラッグ系商品がある。Product Creatorで "garden flag" / "banner" を
検索して、**両面印刷に対応しているもの**を選ぶこと。

| 項目 | 内容 | 確度 |
|---|---|---|
| サイズ | 12" × 18"（ガーデン）／ 24.5" × 32"（ハウス） | 調査済み |
| 素材 | ポリエステル | 調査済み |
| 取り付け | 上辺にポールスリーブ（横棒に通す方式） | 調査済み |
| 印刷 | 両面印刷に対応した選択肢あり | 調査済み |
| 原価 | **未確定** | 要確認 |
| 米国配送料 | **未確定** | 要確認 |
| print area実寸(px) | **未確定** | 要確認 |

12" × 18" が米国のガーデンフラッグの標準サイズ。既製のガーデンフラッグ用スタンドが
このサイズ前提で流通しているので、**まずは12×18の一択**。24.5×32（ハウスフラッグ）は
売れ筋が確認できてから追加する。

## 原価確認チェックリスト（本人がPrintify画面で読む）

Printifyのサイトは開発環境からアクセスできない（ネットワーク制限）ため、
以下の数値は画面を見て教えてほしい。これが揃わないと価格設定ができない。

Printify → Catalog → "garden flag" で検索 → 商品を開く、の順で以下を確認：

1. **Print Provider名**（複数出るので、US拠点かつ評価の高いものを選ぶ）
2. **Production cost**（12×18サイズ、両面印刷を選んだ状態の金額。$〜）
3. **Shipping to United States**（First item / Additional item の2つ）
4. **Production time**（何営業日か）
5. **両面印刷が「標準」か「追加料金」か**
6. Product Creator → 下部でprint areaを選択 → 左パネルの Upload →
   表示される **推奨ピクセル寸法**（例：3600 × 5400 px など）

## 入稿ファイル要件

| 項目 | 指定 |
|---|---|
| 形式 | PNG（推奨）または JPG |
| カラースペース | **RGB / sRGB**（CMYKではない。Printifyは標準でRGB入稿）※画面で要確認 |
| 解像度 | 実寸で 300 DPI。12×18インチなら 3600 × 5400 px が基準 |
| 塗り足し | キャンバス全面をデザインで埋める（白い余りを作らない） |
| セーフゾーン | **上辺から約2インチ（約600px）はポールスリーブに巻き込まれる。ここに文字・顔・重要要素を置かない** |
| 左右・下 | 端から最低 10mm（約120px）相当は余裕を持たせる |
| フォント | アウトライン化（画像生成なので実質不要だが、後から文字を載せる場合は注意） |

### 特に事故りやすい点

- **上辺2インチ問題**：ガーデンフラッグは上から吊るす。生成AIは中央〜上寄せで
  構図を作りがちなので、ブリーフの段階で「上部2インチは空ける」と明記すること
- **両面印刷の裏面**：両面の場合、裏面用の画像を別途用意するか、同じ画像を使うかを
  選べる。文字入りデザインの場合、裏面をミラー反転すると文字が鏡文字になる商品もある。
  Product Creatorのプレビューで必ず裏面を目視確認する
- **生成画像のアップスケール**：Nano Banana Proの出力は3600×5400に足りないので、
  前回ゴルフタオル同様「アップスケール＋白レベル補正」の工程が必須

## 価格設定の計算式

```
利益 = 販売価格 − 製造原価 − 配送原価 − Etsy手数料
```

Etsyの手数料スタック（2026年時点・**要確認**）：

| 費目 | 料率 |
|---|---|
| 出品料 | $0.20 / 1出品（4ヶ月ごとに更新課金） |
| 取引手数料 | 販売価格の 6.5%（送料にもかかる） |
| 決済処理手数料（米国） | 3% + $0.25 |
| Offsite Ads | 発生時 12% または 15%（売上$10k未満の任意参加なら外せる場合あり） |

※ Gmailに9/1付で $1.54 のEtsy課金あり。出品料の実績値として整合的。

**注意：2026年8月27日と9月2日にPrintifyから「商品・配送料金の改定」通知が届いている。
9月7日が設定更新期限だった分は既に過ぎているので、既存のゴルフタオル商品の利益率も
合わせて再確認すること。**
