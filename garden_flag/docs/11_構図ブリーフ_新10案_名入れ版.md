# 構図ブリーフ：ゴルフ・ガーデンフラッグ 新10案（名入れ版）

2026-09-17 作成。**旧10案（`docs/09`）は保留。** 市場データに基づき方向転換した。

## なぜ作り直したか

Etsy『golf garden flag』1ページ目24件の実測（`docs/12_市場実測.md`）：

| 指標 | 結果 |
|---|---|
| **名入れ商品** | **20/24 = 83%** |
| **看板・標識調／モノクロ寄り** | **0件** |
| **自虐・皮肉のコピー** | **0件** |
| 価格 中央値 | $22.74 |

旧10案は**ゴルフタオルのブランド拡張**として設計した（自虐・看板調・高コントラスト）。
しかしゴルフタオルは売上ゼロで、拡張すべきブランド資産が存在しない。
そして**このカテゴリの商品は「面白い看板」ではなく「庭に飾る装飾品」**だった。

ただしユーモア自体は効く。売れている面白い系（What Would Dolly Do / 2,400レビュー、
pimento cheese please! / 2,700レビュー）は、**いずれも「面白い」かつ「カラフル」かつ
「飾れる」**。ユーモアは、庭に飾りたくなる見た目であることが前提。

### 狙う空白

```
名入れ × 装飾的  → 20件（主流。ただし面白くない）
面白い × 装飾的  →  2件（ゴルフではない）
名入れ × 自虐    →  0件  ← ここ
```

**「名字入りで、美しくて、しかも正直なことを言っている」商品が1件もない。**

## 設計方針：名前はAIに描かせない

名入れ商品は注文ごとに名前を差し替える。**AIが名前を画像に焼き込むと差し替えられない。**

```
AIに描かせるもの : 装飾 ＋ 固定コピー（絶対に変わらない部分）
AIに空けさせるもの: 名前を入れる「無地のリボン／プレート」
Claudeが合成する : 名字（Pillow で後から描画）
```

ゴルフタオルの `make_year_towel.py`（年号を差し替える）と**同じ設計**。
注文が来たら3秒で入稿データができる。

### 空欄を確実に作らせるコツ

「テキストを置くな」と書くだけだとAIは埋めてしまう。
**「無地のリボン」「空白のプレート」という“物体”として描かせる**と空欄が残る。

```
An empty cream-colored ribbon banner with a smooth blank surface and NO text on it.
```

## 🔴 絶対ルール：ゴルフのモチーフを主役級の大きさで入れる（2026-09-18 追加）

**サムネイルでも遠距離でも、文字が読めなくても、絵だけでゴルフと分かること。**

初回生成で **10案中5案（N03・N05・N06・N10、およびN07）がゴルフ商品に見えなかった。**
原因は、ブリーフが「遠距離視認性」を**文字が読めることとしてしか定義していなかった**こと。
その結果、ゴルフの意味を100%テキストが背負う設計になり、
**文字が読めない状況ではゴルフ要素がゼロになった。**

Etsyの実売24件は**例外なくゴルフのモチーフを持っている**。
リース系の `THE HAWTHORNES` ですら中央に交差クラブがあり、
`Custom Golf Azalea` のピンクのツツジもゴルファーにはオーガスタ（マスターズ）の暗号。

### 使えるモチーフ（識別しやすい順）

| モチーフ | 識別性 | 備考 |
|---|---|---|
| **赤いピンフラッグの立ったカップ** | ◎ 最強 | 小さくても一瞬でゴルフと分かる |
| **ゴルフバッグ（クラブが刺さった状態）** | ◎ | 形が独特 |
| **ゴルフカート** | ○ | |
| **ディンプルのあるゴルフボール** | ○ | 単体だと白い丸に見えるのでティーや芝と組む |
| **ティーに載ったボール** | ○ | |
| **交差したクラブ** | △ | **大きく描かないと識別できない**（N04の失敗） |

### 検証方法

生成物を **200px幅に縮小**して見る。
**その状態でゴルフと分からなければ不合格。**

## 10案

各案：英語コピー／日本語訳／**なぜこの言い回しが効くか**／ビジュアル／名入れ帯

### 案N01 — STILL WORKING ON IT

- **名入れ**：`THE [NAME]S` ＋ `EST. [YEAR]`
- **日本語訳**：「まだ精進中」
- **語感**：`I'm still working on it`（まだやっている最中です）は、
  **うまくいっていないと認めつつ、諦めてはいない**という含みを持つ日常表現。
  米国の家庭的な看板でよく使われる穏やかな言い回しで、**品を保ったまま自虐になる**。
  `EST. 1985` と並べることで「40年やって、まだ」という時間の重みが乗る。
- **ビジュアル**：白と緑のギンガムチェックの縁取り。中央に水彩のゴルフバッグ。
  下部に無地のクリーム色リボン。

### 案N02 — 19TH HOLE · ALWAYS OPEN

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「19番ホール・年中無休」
- **語感**：`the 19th hole` はゴルフ界で**ラウンド後に飲むバー**を指す定番の隠語。
  全ゴルファーが知っている。`ALWAYS OPEN`（年中無休）が「飲んでばかり」を暗示。
  **自宅を19番ホールに見立てる**のは、庭に挿す商品として完璧な文脈。
- **ビジュアル**：鮮やかな芝生の緑。中央に赤い旗の立つカップ。白の太いサンセリフ。

### 案N03 — HANDICAP: EMOTIONAL

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「ハンディキャップ：精神的なもの」
- **語感**：ゴルフ用語の **handicap（ハンデ）** と、日常語の**「情緒的な問題」**を掛けた
  二重の意味。10案中もっとも短く、切れ味が鋭い。
  上品な水彩リースに載せると、**美しい見た目と内容のギャップ**が笑いになる。
- **ビジュアル**：クリーム地。ユーカリと白い花の水彩リース。中央に細いセリフ体。

### 案N04 — PAR IS A SUGGESTION

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「パーは、あくまで"ご提案"」
- **語感**：規則を **`just a suggestion`（提案に過ぎない）** と言い換えるのは
  英語の鉄板ジョーク構文（例：*Speed limits are a suggestion*）。
  ゴルファーなら全員が一瞬で理解する。**下品にならず品よく笑えるので、贈り物に最も安全。**
- **ビジュアル**：濃紺地に金の紋章。交差したクラブ。金の細い罫線。格式のある構図。

### 案N05 — MULLIGANS WELCOME HERE

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「打ち直し、歓迎します」
- **語感**：**mulligan** はゴルフの「非公式な打ち直し」。本来ルール違反だが仲間内では許される。
  `Welcome` と組むことで **「この家では、やり直しが許される」という人生訓**にも読める。
  **玄関先の歓迎の言葉として二重に効く。** 花の装飾と相性が良い。
- **ビジュアル**：白地に淡いピンクと水色の水彩の花。柔らかいセリフ体。

### 案N06 — PLAY IT AS IT LIES

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「あるがままに打て」
- **語感**：ゴルフの**正式ルール**（球は止まった場所から打つ）。
  同時に**「現実を受け入れろ」という人生訓**として英語圏で広く使われる。
  自虐ではなく**達観**。格式ある言い回しなので上品な装飾と合う。
- **ビジュアル**：白と緑のラティス（格子）模様。左右にトピアリーの木。中央にセリフ体。

### 案N07 — OUR SLICE OF HEAVEN

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「わが家という名の、"スライス"付きの楽園」
- **語感**：`a slice of heaven`（天国の一片＝最高の場所）という定番句と、
  ゴルフの **slice（右に大きく曲がるミスショット）** の掛詞。
  **知らない人には温かい歓迎の言葉、ゴルファーには笑い。** この二重構造が美しい。
  10案中もっとも「贈り物向き」。
- **ビジュアル**：淡い空色。水彩のフェアウェイと遠くの木立。白い雲。

### 案N08 — EXPENSIVELY BAD AT GOLF

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「金をかけて、下手」
- **語感**：bad（下手）を **expensively（高価に）という副詞で修飾する違和感**が笑いの核。
  「下手なのは仕方ない。問題はそこに大金を注いでいることだ」という自覚。
  **英語ネイティブが最も反応する構文。** ※ゴルフタオルP12から転用。
- **ビジュアル**：橙とティール（青緑）のミッドセンチュリー配色。幾何学的な装飾。

### 案N09 — GONE GOLFING · BACK EVENTUALLY

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「ゴルフに行ってる。そのうち戻る」
- **語感**：**`Gone fishing`**（釣りに行ってる＝店を閉めて遊びに行った）という
  古い定番句のゴルフ版。決め手は **`eventually`（いずれ／そのうち）**。
  「いつ帰るか自分でも分からない」という投げやりさが出る。`back soon` だと平凡。
- **ビジュアル**：クリーム地に赤と緑のタータンチェックの縁取り。中央に小さなゴルフカート。

### 案N10 — WORLD'S OKAYEST GOLFER

- **名入れ**：`THE [NAME]S`
- **日本語訳**：「世界で一番"まあまあ"なゴルファー」
- **語感**：**`World's Okayest ___`** は米国で完全に定着したジョーク定型
  （*World's Okayest Dad* など）。**okay の最上級 okayest という存在しない造語**が可笑しい。
  トロフィーやリボンの装飾と組むと「**表彰されているのに"まあまあ"**」というギャップが出る。
- **ビジュアル**：白地に金のトロフィーと月桂樹。金のリボン。
