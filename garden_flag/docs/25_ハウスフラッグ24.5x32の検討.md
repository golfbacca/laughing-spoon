# 25. ハウスフラッグ 24.5"×32" を出すか（2026-09-23）

本人の指摘：**「24.5"×32" はなぜ出さない？出品コストはあまりかからないと思うが？」**

**出品コストの点は指摘のとおり。** Printify の「Garden and House Banner」は
**同一商品のサイズ違いのバリエーション**なので、追加の出品料は $0。
タイトル・タグ・説明文・広告も同じリスティングを共有する。
この観点を `docs/22` の計画は検討していなかった。

そして**採算はガーデンより明確に良い。** ただしデザインと写真は流用できない。

---

> **2026-09-23 追記：Printify の実数値が判明し、結論が変わった。**
> 送料が両サイズとも同じ $6.39 で、着地原価の差はわずか $9.95。
> さらに、いまの5案をそのままハウスサイズに組めることを確認した（第2節を全面改訂）。
> **公開後の第2弾ではなく、最初から2サイズで出せる。**

## 1. 採算（Printify実測・2026-09-23）

### Printify画面の実数値

| | 12"×18" | 24.5"×32" |
|---|---:|---:|
| Production cost | $10.49 | **$20.44** |
| Buyer shipping cost | $6.39 | **$6.39**（同額） |
| **着地原価** | **$16.88** | **$26.83** |

**送料が同じ**なので、差は製造原価の **$9.95 だけ**。

### 手数料の式（Printify画面から逆算して検算済み）

```
Etsy手数料 = 買い手総額 × 9.5% + $0.45
             （取引6.5% ＋ 決済3%）  （決済$0.25 ＋ 出品$0.20）
```

検算：12×18 が $22.99+$6.39 のとき 画面$3.24 / 計算$3.24 ✓
　　　24.5×32 が $34.99+$6.39 のとき 画面$4.38 / 計算$4.38 ✓

### 価格別の利益

| 表示価格 | 買い手総額 | 12×18の利益 | 率 | 24.5×32の利益 | 率 |
|---:|---:|---:|---:|---:|---:|
| **$27.99** | $34.38 | **$13.78** | 40.1% | $3.83 | 11.2% |
| $44.99 | $51.38 | $29.17 | 56.8% | $19.22 | 37.4% |
| $49.99 | $56.38 | $33.69 | 59.8% | $23.74 | 42.1% |
| **$52.49** | $58.88 | $35.96 | 61.1% | **$26.01** | 44.2% |
| $54.99 | $61.38 | $38.22 | 62.3% | $28.27 | 46.1% |

**推奨：ハウスは 定価 $74.99 / 常時30%OFF / 表示 $52.49。**
利益 $26.01（44.2%）。ガーデン（$13.78）の **1.9倍**。

### 広告の損益分岐で見ると差が決定的

CPC $0.30・転換率2% → **獲得単価 $15**。

| | 1件の利益 | 獲得単価 | 差引 |
|---|---:|---:|---:|
| ガーデン 12×18（$27.99） | $13.78 | $15.00 | **−$1.22** |
| ハウス 24.5×32（$52.49） | $26.01 | $15.00 | **+$11.01** |

**ガーデンだけで広告を回すと、1件売れるごとに $1.22 のマイナス。**
ハウスが混ざれば黒に転じる。`docs/18` の30日テストの成否を左右する。

## 2. デザインは流用できる（方法を変えたら解決した）

最初は Gemini の元画像（1696×2528）から直接 24.5×32 に組もうとして失敗した
（R05とR11が破綻、他も左右に2.7〜4.0インチの余白）。

**12×18の入稿データ（3900×5700）から組み直したら、5案とも問題なく収まった。**

```
12x18入稿の「見える範囲」 3600×4800 (12"×16")
  ↓ 高さを合わせて1.81倍
24.5x32の「見える範囲」 7350×8700 (24.5"×29")
  ↓ 足りない左右（各1.38インチ）は、旗の地色を端から伸ばして埋める
```

この方法が効く理由：**12×18の入稿データには案ごとの手当てが既に入っている。**
R01のギンガム補修、R11の「白枠を捨てて紺を地色にする」処理など。
元のJPEGからやり直すとそれらが失われる。

| | 元画像から組んだ場合 | **12×18から組んだ場合** |
|---|---|---|
| 左右の余白 | 2.7〜4.0インチ | **各1.38インチ** |
| 実効DPI | 62〜91 | **85** |
| R05 | 破綻（四隅の花が横に伸びる） | **問題なし** |
| R11 | 破綻（左右が白いまま） | **問題なし（紺が端まで）** |

スクリプトは `tools/house/house_build.py`。

### 実効解像度

| | 元画像からの倍率 | 実効DPI |
|---|---:|---:|
| ガーデン 12×18 | 2.22倍 | 135 DPI |
| ハウス 24.5×32 | 3.54倍 | **85 DPI** |

`docs/10` の「3〜10m離れて見る商品なので実物は変わらない」という判断は
ハウスにも当てはまる（さらに遠くから見る商品）。

## 3. 出品画像

サイズ図（5枚目）を **2サイズ併記版**に差し替えた（`tools/house/size_two.py`）。
ハウス側は引き伸ばしではなく、**実際の入稿データ 7800×10012 から描いている。**

モックアップは当面ガーデンのまま。
ハウスフラッグは壁のブラケットに吊るすので背景写真が別途要るが、
**サイズ図と説明文があれば出品はできる。** 余裕ができたら作る。

## 4. Printifyの挙動（2026-09-23 画面で確認）

### 画像はサイズごとに分けられない

| | 12"×18" のみ選択 | 両方選択 |
|---|---|---|
| Production cost | USD 10.49 | USD 10.49**–20.44** |
| **Print area size** | 3900 × 5700 px | **7800 × 10012 px** |

**印刷エリアは1つ。** 両サイズを選ぶと大きい方（7800×10012）に切り替わり、
**1枚の画像が両サイズに使われる。**

### 配置は「はみ出す方に合わせる（cover）」

3900×5700 の画像を 7800×10012 の枠に置いたとき、
画面上で**枠を端まで埋めていた**（左右に空白が出ていない）。
「収まる方に合わせる」なら左右に各1.58インチの空白が出るはずなので、**coverで確定。**

### したがって載せる画像で結果が変わる

| 載せる画像 | 24.5×32 | 12×18 |
|---|---|---|
| **3900×5700**（ガーデン用） | **上下が各2.31インチ切れる** ✗ | ぴったり |
| **7800×10012**（ハウス用） | **ぴったり** ✓ | 左右が各0.90in切られるが、**それはハウス版で足した余白の分**。絵は端まで出る ✓ |

計算：ハウス版の左右の余白は412px。12×18へ縮小すると235pxになり、
切り取られる270pxがそれを上回るので**余白は完全に消え、絵が端まで届く。**

**→ 7800×10012 を載せるのが正解。両サイズとも正しく出る。**

実際に5案すべてを 12×18 に落として確認した。
**5案とも余白なし・歪みなしで、いまの12×18版と同等。**

### 袖の幅は未確認だが、リスクは低い

入稿データは袖3インチと仮定して組んでいる。実際が2〜4インチのどれであっても、
**5案とも上部は無地の地色**（ブリーフで「上15%は無地」と指示した）なので、
柄や文字が袖に飲まれることはない。

### 2枚目以降の送料も確定（2026-09-23）

配送の画面で **「サイズ/タイプ：全員（All）」** と表示されており、
**送料はサイズに依存しない。** 12×18も24.5×32も 1枚目$6.39 / 2枚目以降$1.99。
