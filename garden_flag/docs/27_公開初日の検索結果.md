# 27. 公開初日の検索結果（2026-09-27 実測）

本人が Etsy で `golf garden flag` を検索した画面から読み取った。
**ゴルフタオル9商品は全期間で検索流入ゼロだった**（`docs/04`）。同じ店の初日にこれ。

## 1. 5件とも1ページ目。R02は2位

| 順位（24件中） | 商品 |
|---:|---|
| **2位** | R02 19番ホール |
| 10位 | R09 ゴルフ中 |
| 12位 | R05 マリガン |
| 13位 | R01 まだ練習中 |
| 15位 | R11 ゴルフ倶楽部 |

### ⚠ この順位は続かない

**Etsyは新規リスティングに一時的な露出ブーストを与える。** データを集めるための
仕組みで数日で切れる。加えて本人のアカウントでログインして見ているので色が付く。

**いま見えているのは実力ではなく「お試し期間の席」。**

### だから広告はいま始める

```
新規ブーストで良い席にいる
  ↓ その間に売れる ＝ クリック率と転換率が記録される
  ↓ リスティング品質スコアが上がる
  ↓ ブーストが切れても席が残る
```

**ブーストは実績を作るための猶予期間。** ここで売上とレビューを作れなければ、
切れたときに後ろへ落ちる。

## 3. 価格：こちらは1ページ目でほぼ最高値

競合19件（自社5件を除く）の集計。

| | 表示価格 | 買い手が払う総額 |
|---|---:|---:|
| 競合19件の中央値 | **$22.49** | **$26.00** |
| 競合19件の範囲 | $12.99〜$28.00 | $18.99〜$34.39 |
| **こちら** | **$27.99** | **$34.38** |

- **総額でこちら以上の競合は19件中1件だけ**（$28.00 の1店）
- 中央値より **+$8.38（32%高い）**
- **競合19件のうち5件が送料無料**

### 送料無料に切り替える案（計算はしたが、いまは採らない）

| | 買い手総額 | 手数料 | 利益 |
|---|---:|---:|---:|
| いま（$27.99＋送料$6.39） | $34.38 | $3.72 | **$13.78** |
| 送料無料 $35.99 | $35.99 | $3.87 | **$15.24** |
| 送料無料 $34.99 | $34.99 | $3.77 | $14.34 |
| 送料無料 $32.99 | $32.99 | $3.58 | $12.53 |

**利益は送料無料のほうが増える**うえ、$35以上なのでEtsyの送料無料の優遇に乗る。

**それでも採らない理由：検索結果のグリッドに出るのは表示価格。**

| | 隣に並ぶ競合 $22.49 と比べて |
|---|---|
| いま `$27.99` | **24%高く見える** |
| 送料無料 `$35.99` | **60%高く見える** |

**総額はほぼ同じなのに棚での見え方が悪化する。押される前に負ける。**

### 判断：1週間後に実データで決める

`docs/16` で「公開1週間後に実CPCを見て価格を判断する」と決めてある。
そこに**今日の競合価格のデータが加わっただけ。**
いま動かすと**5案の比較も価格の評価もまとめて濁る。**
