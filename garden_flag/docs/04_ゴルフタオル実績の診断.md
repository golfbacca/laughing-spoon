## 診断

**売れない原因は、デザインでも価格でも写真でもない。「検索結果に表示されていない」。**

閲覧数が週1というのは、コンバージョンの問題ですらない。
Etsyの検索結果に商品が出ていないということ。この状態では、
どんなに良いデザインを作っても、どんなに説明文を磨いても結果は変わらない。

8/7の「16」は、Etsyが新規出品に一時的に与える露出（new listing boost）と
整合する。それが切れた瞬間、1〜4に落ちている。**ブーストが切れた後、
自力で検索順位を取れていない。**

### 表示されない理由（仮説、確度順）

1. **タイトルの大半が「検索されない言葉」で埋まっている**
   「My Best Score Is Old Enough to Drink」「Peaked In 2005 Still Showing Up」は
   ジョークとしては良いが、**誰もこの言葉で検索しない**。
   Etsyはタイトル全体を検索マッチングに使うので、タイトルの6割を
   検索ボリュームゼロの文言に使うと、その分だけマッチする機会を捨てている。

2. **狙ったキーワードの競合が強すぎる**
   "funny golf towel" "golf gift for dad" は大手・実績ショップがひしめく激戦区。
   販売実績ゼロ・レビューゼロの新規ショップが自力で上位に入るのは現実的でない。

3. **出品数が少ない（4点）**
   Etsyでは1出品＝1つの検索マッチ機会。4点では抽選券が4枚しかない。

4. **広告を使っていない**
   販売ゼロ・レビューゼロだと、オーガニック順位を上げるための
   「クリック率・購入率」のデータがそもそも溜まらない。鶏と卵になっている。

## Garden Flag案件への影響（最重要）

**同じやり方でガーデンフラッグを出すと、同じ結果（週1閲覧）になる。**

ゴルフタオルの進め方は「ニッチを決める → デザインする → 出品する」だった。
この順番だと、**そのニッチが検索されているかどうかを確かめないまま**
デザイン工数を使うことになる。

Garden Flagでは順番を逆にする：

```
【旧】 ニッチ決定 → デザイン → 出品 → 検索されず埋もれる
【新】 検索キーワード調査 → 勝てる語を特定 → その語に合わせてデザイン → 出品
```

### Garden Flagで必ずやること

| # | やること | 理由 |
|---|---|---|
| 1 | **キーワードを先に決める** | 需要があり、かつ競合が手薄な語を探す。デザインはその後 |
| 2 | **タイトルの全語を検索語で埋める** | ジョーク文言はタイトルではなく「画像の中」に置く |
| 3 | **1点ではなく複数出す** | 1点勝負は抽選券1枚。最低でも5〜10バリエーション |
| 4 | **Etsy Ads を少額で回す** | 販売ゼロの状態を抜けるには、最初の露出を買うしかない。1日$1〜3から |
| 5 | **Pinterestに投稿する** | ホーム／ガーデンデコアはPinterest経由の流入が効きやすいカテゴリ |

### 既存ゴルフタオルへの処置（Garden Flagと並行）

捨てる必要はない。タイトルを直せば再利用できる：

- ジョーク部分をタイトルから画像側へ移し、**タイトルは検索語だけで構成し直す**
- 例：ジョーク文言 → 検索語（golf towel, golf gift for men, funny golf gift,
  golf accessories, fathers day golf, golf towel with clip など）に置換
- タグ13個も同様に、ジョークではなく検索語で埋める

**注意：この診断は「表示されていない」ところまでしか特定できていない。**
どのキーワードで何位なのか、インプレッションが何回あるのかは、
Etsyのショップ管理ツール（Stats → Traffic → Search terms）を開かないと分からない。
