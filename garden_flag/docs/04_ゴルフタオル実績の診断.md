### なぜ検索に出ないのか

1. **競合が強すぎる領域を狙っている**
   タイトルが狙う `funny golf towel` `golf gift for dad` `sarcastic golfer gift` は
   実績ショップがひしめく激戦区。販売0・レビュー0・お気に入り0の新規ショップは
   検索順位の最下層に置かれ、実質的に誰の目にも触れない。
   後発の出品（Expensively Bad At Golf... など）は**タイトルのキーワード密度自体は
   悪くない**。それでも0件ということは、語の選び方ではなく
   **語の競合レベル**が問題。

2. **ショップの初期設定が未完了**
   Shop Manager上に「Add an About section to your shop」の案内が出ている＝
   **About セクションが未記入**。Etsyはショップの完成度も評価に使う。

3. **エンゲージメント信号がゼロのまま**
   お気に入り0・フォロー0・レビュー0・販売0。Etsyが順位を上げる根拠が何もない。
   新規出品ブーストが切れたあと、順位を維持する材料がない。

4. **広告を使っていない**
   Etsy Ads 0。オーガニックがゼロで広告もゼロなら、露出の入口が存在しない。

5. **2026-07-16 にショップが強制おやすみモードに入った前例がある**
   Payoneerの本人確認が未完了だったため、Etsyがショップごと非表示にした
   （`golf_towel/HANDOFF.md` §7）。全商品が検索から消える状態。
   期間の長さによっては、この間に順位が育つ機会を失っている。
   **現在は解消済み**（Stats上で全商品が Active）。

### まだ説明できていないこと（正直に書く）

9商品・約2ヶ月で検索流入が「少ない」ではなく**ちょうど0**というのは、
競合の厚さだけでは説明しきれない可能性がある。以下を切り分けるまで断定はしない。

**2分でできる切り分けテスト（本人が実行）：**

Etsyの検索窓に、自分の商品タイトルの一部を**そのまま**入れて検索する。例：

```
Expensively Bad At Golf Funny Golf Towel
```

- **自分の商品が出る** → インデックスは正常。純粋に「競合に埋もれている」だけ。
  対策はロングテール語＋広告
- **出ない** → インデックスまたは商品の状態に構造的な問題がある。
  こちらが先。タグ・カテゴリ・属性・ショップ設定を疑う

**この結果によって打ち手が変わるので、先に実行してもらうこと。**

### ここから言える、最も重要なこと

**「ニッチを狙う」という戦略自体は正しかった。適用する場所を間違えていた。**

ニッチ性を効かせたのは**デザインのコンセプト**（ベテランゴルファーの自虐）だった。
一方で**狙った検索語は激戦区の一般語**だった。この組み合わせが最悪で、

- 一般語では競合に勝てない → 検索に出ない
- デザインのニッチ性は、検索に出ないので誰にも伝わらない

正しい適用先は**検索語のほう**。競合が数十件しかないロングテール語を取りに行けば、
新規ショップでも1ページ目に入れる。デザインはその語に合わせて作る。

## Garden Flag案件への影響（最重要）

**同じやり方でガーデンフラッグを出すと、同じ結果（週1閲覧）になる。**

ゴルフタオルの進め方は「ニッチを決める → デザインする → 出品する」だった。
この順番だと、**そのニッチが検索されているかどうかを確かめないまま**
デザイン工数を使うことになる。

Garden Flagでは順番を逆にする：

```
【旧】 ニッチ決定 → デザイン → 出品 → 検索されず埋もれる
【新】 検索キーワード調査 → 勝てる語を特定 → その語に合わせてデザイン → 出品
```

### Garden Flagで必ずやること

| # | やること | 理由 |
|---|---|---|
| 1 | **キーワードを先に決める** | 需要があり、かつ競合が手薄な語を探す。デザインはその後 |
| 2 | **タイトルの全語を検索語で埋める** | ジョーク文言はタイトルではなく「画像の中」に置く |
| 3 | **1点ではなく複数出す** | 1点勝負は抽選券1枚。最低でも5〜10バリエーション |
| 4 | **Etsy Ads を少額で回す** | 販売ゼロの状態を抜けるには、最初の露出を買うしかない。1日$1〜3から |
| 5 | **Pinterestに投稿する** | ホーム／ガーデンデコアはPinterest経由の流入が効きやすいカテゴリ |

### 既存ゴルフタオルへの処置（Garden Flagと並行）

捨てる必要はない。タイトルを直せば再利用できる：

- ジョーク部分をタイトルから画像側へ移し、**タイトルは検索語だけで構成し直す**
- 例：ジョーク文言 → 検索語（golf towel, golf gift for men, funny golf gift,
  golf accessories, fathers day golf, golf towel with clip など）に置換
- タグ13個も同様に、ジョークではなく検索語で埋める

**注意：この診断は「表示されていない」ところまでしか特定できていない。**
