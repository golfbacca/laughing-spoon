# 21. 出品文言（タイトル・タグ・説明文）

Etsy に貼り付ける英語と、その**日本語訳＋なぜその言い回しなのか**。
そのままコピーして使える形にしてある。

---

## 0. 共通の設計

### なぜこの語を選んだか

`docs/07` と `docs/12` の実測で分かっていること：

| 事実 | 出典 | 文言への反映 |
|---|---|---|
| `golf garden flag` は**検索されている**（Etsyのmarketページが存在） | 07 | **タイトルの先頭に置く** |
| `golf christmas garden flag` は**検索の裏付けなし** | 07 | クリスマス語は**一切入れない** |
| 1ページ目24件のうち**83%が名入れ商品** | 12 | `Personalized` を先頭付近に置く |
| 価格中央値 $22.74、$74 の商品も存在 | 12 | 高めの $27.99 を正当化する文言を入れる |

**Etsyのタイトルは先頭40字が最も重視される。** だから
`Personalized Golf Garden Flag` を必ず先頭に置いている。

### 語の使い分け

| 英語 | 日本語 | なぜ使うか |
|---|---|---|
| **Personalized** | 名入れの | Etsyで名入れ商品を探す人が最も使う語。`Custom` より検索数が多い |
| **Custom** | あつらえの | 同義だが別の検索語。両方入れて取りこぼしを防ぐ |
| **Garden Flag** | ガーデンフラッグ | 商品カテゴリそのもの。外せない |
| **Yard Flag / Yard Decor** | 庭の旗／庭の飾り | 同じ物を指す別の言い方。`garden` で探さない人を拾う |
| **Double Sided** | 両面印刷 | 買い手が絞り込みに使う機能語。**競合が必ず書いている** |
| **12x18** | 12×18インチ | サイズで検索する人がいる |
| **Gift for Men / Dad / Her** | 男性／父／女性への贈り物 | **購買意図が最も強い語**。「買う気の人」が打つ |

## 1. R01 — STILL WORKING ON IT（黄色ギンガム・ゴルフバッグ）

### タイトル（125字／上限140字）

```
Personalized Golf Garden Flag, Funny Golf Gift for Men, Custom Family Name Yard Flag, Double Sided 12x18, Still Working On It
```

> 名入れゴルフ・ガーデンフラッグ／男性への面白いゴルフの贈り物／名字入りの庭用フラッグ／両面印刷 12×18／「まだ練習中です」

### デザインの決め台詞

**`STILL WORKING ON IT`** — 「まだ練習中でして」

40年やっていても言える、**永遠に終わらない言い訳**。
上達を問われたゴルファーが照れ隠しに使う定番の返し。
断定を避ける `still`（まだ）と、進行形の `working on it`（取り組み中）の組み合わせが、
**謙遜と開き直りの両方に読める**のが効いている。

## 2. R02 — 19TH HOLE, ALWAYS OPEN（鮮やかな緑・グリーンとピン）

### タイトル（124字）

```
Personalized Golf Garden Flag, 19th Hole Sign for Yard, Custom Family Name Flag, Golf Gift for Dad, Double Sided 12x18 Decor
```

> 名入れゴルフ・ガーデンフラッグ／庭用「19番ホール」看板／名字入りフラッグ／父へのゴルフの贈り物／両面印刷 12×18

### デザインの決め台詞

**`19TH HOLE - ALWAYS OPEN`** — 「19番ホール、年中無休」

**`19th hole`（19番ホール）はゴルフ界の隠語で、
18ホール回った後に行くクラブハウスのバーを指す。**
ゴルファーなら100%通じる内輪の言葉。

それを自宅の庭に掲げると「うちがバーだ、いつでも寄っていけ」という
**もてなしの合図**になる。`ALWAYS OPEN`（年中無休）が
店の看板の言い回しなので、冗談が成立する。

**ゴルフを知らない人には意味が分からない。それでいい。**
分かる人だけが反応する設計。

## 3. R05 — MULLIGANS WELCOME HERE（クリーム地・水彩の花）

### タイトル（127字）

```
Personalized Golf Garden Flag, Floral Golf Yard Decor, Custom Family Name Flag, Golf Gift for Her, Double Sided 12x18 Mulligans
```

### デザインの決め台詞

**`MULLIGANS WELCOME HERE`** — 「ここではやり直しOK」

**`mulligan`（マリガン）は、仲間内のゴルフで認められる

表向きは「うちのゴルフは緩いよ」、

## 4. R09 — GONE GOLFING, BACK EVENTUALLY（タータン枠・ゴルフカート）

### タイトル（120字）

```
Personalized Golf Garden Flag, Funny Golf Cart Yard Flag, Custom Family Name Sign, Golf Gift for Men, Double Sided 12x18
```

> 名入れゴルフ・ガーデンフラッグ／面白いゴルフカートの庭用フラッグ／名字入りの看板／男性へのゴルフの贈り物／両面印刷 12×18

### デザインの決め台詞

**`GONE GOLFING - BACK EVENTUALLY`** — 「ゴルフ中。そのうち帰る」

**`GONE FISHING`（釣りに行ってます）は、
米国の店や家に掛ける定番の不在札。** 誰でも知っている型。
それを `GOLFING` に差し替えている。

決め手は **`EVENTUALLY`（いつかそのうち）**。
普通の不在札は `BACK AT 3PM`（3時に戻ります）と書く。
そこを「そのうち」にすることで、**帰る気がないことを宣言している。**

**5案で最も汎用性が高い。** 退職祝いにも使える
（`docs/18` の広告で最も伸びる可能性があるのはこれ）。

### 日本語訳

> **「本当に使われるゴルフの贈り物」。**

### 効かせどころの解説

| 英語 | なぜこの言い方か |
|---|---|
| **A golf gift that actually gets used** | 「実際に使われる贈り物」。ゴルフ用品の贈り物は**使われずに仕舞われる**のが定番。買い手はそれを知っている。そこを先に突く |
| **made to live outdoors** | 直訳は「屋外で暮らすために作られた」。`weatherproof`（防水）と言い切ると誇大になるが、これなら**耐候性を印象づけつつ嘘にならない** |
| **not mirrored** | 「鏡文字になりません」。両面印刷の安物は裏が鏡文字になる。**買い手が実際に心配している点**を先回りして潰す |
| **I will send you a free preview** | 名入れ商品の最大の不安は「自分の名字だとどう見えるか」。**3秒で見本が出せる**というこちらの強みを、そのまま販売文句にしている |
| **any golfer who already owns every club ever made** | 「クラブはもう全部持っているゴルファー」。**贈り物選びに詰まった人の状況そのもの**を言い当てる。ここで笑って買う |
| **PLEASE NOTE ... NOT included** | 大文字で強調。**スタンド付属と誤解された低評価レビューは、この商品で最も多い事故。** 説明文と画像7枚目の両方で潰す |

## 7. Etsy の「Personalization」欄に入れる文

```
Enter your family name - for example: SMITH
It will be printed as "THE SMITHS". Any length fits.
```

> 名字を入力してください（例：SMITH）。「THE SMITHS」と印刷されます。長さの制限はありません。

設定：**必須（Required）にする。** 空欄で注文されると作業が止まる。

### 文字数と印刷サイズ（実測）

合成スクリプトは**帯に収まる最大サイズまで自動で拡大する**ので、
長い名字でも必ず収まる。ただし**その分だけ小さくなる。**

幅が最大の文字（M）だけで作った最悪ケースの実測値：

| 名字の文字数 | 5案での最小の文字高 | 実寸 | 屋外で読める距離の目安 |
|---:|---:|---:|---:|
| 5（SMITH） | 305px | 1.02" | 約10 ft |
| 6（SMITHS） | 254px | 0.85" | 約8.5 ft |
| 8（JOHNSONS） | 190px | 0.63" | 約6.3 ft |
| 10 | 152px | 0.51" | 約5.1 ft |
| 13 | 117px | 0.39" | 約3.9 ft |

※ 看板の目安「文字高1インチにつき10フィート」で換算

**実際の名字は M ばかりではないので、これより大きくなる。**
出品文言で文字数を制限しなかったのはこのため。
制限すると長い名字の人が買わなくなるが、実害は「少し小さい」だけ。

## 8. 未確認のまま書かなかったこと

| 項目 | なぜ書かなかったか |
|---|---|
| **Made in USA / 米国製** | Pic The Gift の生産国を**未確認**。裏取りできない産地表示は書かない。Printifyのプロバイダ詳細で確認できたら追記する |
| 防水・全天候 | 染料昇華のポリエステルだが、耐候性の公式数値がない。`made to live outdoors` に留めた |
| 具体的な素材名 | Printifyの商品ページに素材表記があるはず。確認後 `Soft, fade-resistant fabric` を正式名に差し替える |
