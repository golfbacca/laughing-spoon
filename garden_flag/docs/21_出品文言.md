# 21. 出品文言（タイトル・タグ・説明文）

Etsy に貼り付ける英語と、その**日本語訳＋なぜその言い回しなのか**。
そのままコピーして使える形にしてある。

---

## 0. 共通の設計

### なぜこの語を選んだか

`docs/07` と `docs/12` の実測で分かっていること：

| 事実 | 出典 | 文言への反映 |
|---|---|---|
| `golf garden flag` は**検索されている**（Etsyのmarketページが存在） | 07 | **タイトルの先頭に置く** |
| `golf christmas garden flag` は**検索の裏付けなし** | 07 | クリスマス語は**一切入れない** |
| 1ページ目24件のうち**83%が名入れ商品** | 12 | `Personalized` を先頭付近に置く |
| 価格中央値 $22.74、$74 の商品も存在 | 12 | 高めの $27.99 を正当化する文言を入れる |

**Etsyのタイトルは先頭40字が最も重視される。** だから
`Personalized Golf Garden Flag` を必ず先頭に置いている。

### 語の使い分け

| 英語 | 日本語 | なぜ使うか |
|---|---|---|
| **Personalized** | 名入れの | Etsyで名入れ商品を探す人が最も使う語。`Custom` より検索数が多い |
| **Custom** | あつらえの | 同義だが別の検索語。両方入れて取りこぼしを防ぐ |
| **Garden Flag** | ガーデンフラッグ | 商品カテゴリそのもの。外せない |
| **Yard Flag / Yard Decor** | 庭の旗／庭の飾り | 同じ物を指す別の言い方。`garden` で探さない人を拾う |
| **Double Sided** | 両面印刷 | 買い手が絞り込みに使う機能語。**競合が必ず書いている** |
| **12x18** | 12×18インチ | サイズで検索する人がいる |
| **Gift for Men / Dad / Her** | 男性／父／女性への贈り物 | **購買意図が最も強い語**。「買う気の人」が打つ |

| 英語 | なぜこの言い方か |
|---|---|
| **A golf gift that actually gets used** | 「実際に使われる贈り物」。ゴルフ用品の贈り物は**使われずに仕舞われる**のが定番。買い手はそれを知っている。そこを先に突く |
| **made to live outdoors** | 直訳は「屋外で暮らすために作られた」。`weatherproof`（防水）と言い切ると誇大になるが、これなら**耐候性を印象づけつつ嘘にならない** |
| **not mirrored** | 「鏡文字になりません」。両面印刷の安物は裏が鏡文字になる。**買い手が実際に心配している点**を先回りして潰す |

| **any golfer who already owns every club ever made** | 「クラブはもう全部持っているゴルファー」。**贈り物選びに詰まった人の状況そのもの**を言い当てる。ここで笑って買う |
| **PLEASE NOTE ... NOT included** | 大文字で強調。**スタンド付属と誤解された低評価レビューは、この商品で最も多い事故。** 説明文と画像7枚目の両方で潰す |
| **dyed INTO the fabric, not layered on top** | 「生地に染み込む、表面に乗せるのではなく」。**INTO を大文字にして on top と対比**させている。昇華転写の仕組みをそのまま売り文句にしたもの |
| **with a black inner lining ... no show-through** | 「内側に黒い裏地。裏写りしない」。**両面印刷の安物は裏の絵が透ける。** 黒い裏地はそれを防ぐ部品で、製造仕様に明記されている。買い手が心配する点を先に潰す |

| **cannot crack, peel or flake off** | 「割れない・剥がれない・欠けない」。動詞を3つ並べるのは、**安い旗が実際に壊れる3通りの壊れ方を全部名指しで潰す**ため。1つだけだと「他の壊れ方はするのか」と読まれる |

## 7. Etsy / Printify の「Personalization」欄に入れる文

```
Enter your family name - for example: Smith
We print it in capitals as The Smiths. Longer names print smaller.
```

> 名字を入力してください（例：Smith）。**大文字で「The Smiths」と印刷します。**
> 長い名字はその分だけ小さく印刷されます。

**110字（Printifyの上限120字）。全大文字の語は0個。**

### ⚠ 全大文字の語は使えない（2026-09-27・Printifyサポートで判明）

**Etsyは名入れの説明文に「大文字が連続する語」を1つまでしか許さない。**
超えると **Publish が汎用エラーで失敗し、理由は画面のどこにも出ない。**

旧版は `SMITH` / `THE` / `SMITHS` の**3つ**あり、これが5商品すべての
公開失敗の原因だった（`docs/26` 第10節。丸1日を溶かした）。

**上限1に対して0にしてある。** PrintifyとEtsyで数え方がずれても落ちないため。

検査ツール：

```bash
python3 garden_flag/tools/check_personalization.py "文面"
```

`Smith` を先頭だけ大文字にしたのは、**買い手の入力の大小がこちらの作業に
無関係**だから（名字はスクリプトに打ち直す）。
`in capitals`（大文字で）を足したのは、**出品画像が `THE SMITHS` と全部大文字**で、
文中の `The Smiths` と見た目がずれるのを先に埋めるため。

設定：**必須（Required）にする。** 空欄で注文されると作業が止まる。

### 「Any length fits」をやめた理由（2026-09-24）

以前は `Any length fits.`（長さの制限はありません）と書いていた。
しかし **Printify には「Character limit for buyer response」という必須欄があり、
必ず上限を1つ決めなければならない。** 制限を入れておきながら
「制限はありません」と書くのは、そのまま矛盾になる。

言い換えた `Longer names simply print a little smaller.`
（長い名字はその分だけ小さく印刷されます）は、
**上限の存在と両立しつつ、長い名字の人を追い返さない。**
`simply`（ただ〜なだけ）が「それ以外に不都合はない」と言い切る働きをしていて、
不安を打ち消す役に立っている。

### 文字数の上限は 16 にする

買い手が打つのは**名字だけ**（`SMITH`）で、こちらが `S` を足して
`THE SMITHS` にする。つまり **上限16字 ＝ 印刷されるのは最大17字。**

実在する長い名字でも 14字（`CHRISTOPHERSON` `SCHWARZENEGGER`）なので、
**16字あれば実質すべて通る。** 逆に上限を外すと
`THE SMITH FAMILY EST 2015` のような一文を打たれて極端に小さくなり、
低評価の原因になる。**16は「名字以外は打てない」と伝わる長さ。**

### 文字数と印刷サイズ（2026-09-24 実測・R09再生成とR01の楕円化を反映）

合成スクリプトは**プレートに収まる最大サイズまで自動で拡大する**ので、
長い名字でも必ず収まる。ただしその分だけ小さくなる。

**最悪ケース**（幅が最大の文字 `M` だけを並べた場合）の、5案での最小値：

| 印刷される字数 | 最小の文字高 | 12×18の実寸 | 24.5×32の実寸 |
|---:|---:|---:|---:|
| 5 | 235px | 0.78" | 1.42" |
| 6（THE SMITHS） | 196px | 0.65" | 1.18" |
| 8 | 147px | 0.49" | 0.89" |
| 10 | 118px | 0.39" | 0.71" |
| 13 | 91px | 0.30" | 0.55" |
| 16 | 74px | 0.25" | 0.45" |
| 17（上限） | 70px | 0.23" | 0.42" |

**実在の名字はMばかりではないので、実際はこれより大きい：**

| 名字 | 字数 | 文字高 | 12×18の実寸 |
|---|---:|---:|---:|
| SMITHS | 6 | 283px | 0.94" |
| JOHNSONS | 8 | 243px | 0.81" |
