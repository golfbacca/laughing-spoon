# 29. Etsy サイバースペシャルセールへの参加（2026-10-18）

Etsyから案内が来た。

| | |
|---|---|
| 名称 | サイバースペシャルセール |
| 期間 | **2026年11月23日 〜 12月1日** |
| 割引の選択肢 | 25% 〜 60% |
| **早期登録の締切** | **2026年10月27日** |
| 早期登録の利点 | **「Etsyのマーケティングで紹介されるチャンスが上がります」** |

## 参加する。理由は割引ではなく露出

**この店に足りないのは露出だけ**（`docs/04`・`docs/28`）。
$3/日の広告では買えなかったものが、**無料で手に入る可能性**がある。乗らない理由がない。

---

## ⚠ 既定のままだと損をする。2か所変える

### ① 「すべての商品情報」→「商品を自分で選択する」

**ガーデンフラッグ5商品だけにする。全商品のままだとゴルフタオルが赤字になる。**

| 割引 | ゴルフタオル | ガーデン12×18 | ハウス24.5×32 |
|---:|---|---|---|
| 25% | $14.99 → $1.99 | $29.99 → $15.59 | $56.24 → $29.40 |
| 30% | $13.99 → $1.09 | $27.99 → $13.78 | $52.49 → $26.01 |
| **40%** | $11.99 → **−$0.72 ★赤字** | **$23.99 → $10.16** | **$44.99 → $19.22** |
| 50% | $9.99 → −$2.53 ★赤字 | $20.00 → $6.55 | $37.49 → $12.43 |
| 60% | $8.00 → −$4.33 ★赤字 | $16.00 → $2.93 | $30.00 → $5.65 |

※ 利益＝表示価格 − 製造原価 − Etsy手数料（買い手総額×9.5%＋$0.45）
※ タオルは原価$10.61。**40%引くと売るほど損をする**

### ② 割引率 25% → **40%**

**いま常時30%OFFで出している。25%だとイベントなのに今より値上げになる**（$27.99→$29.99）。

**40%を推す理由：**

| | |
|---|---|
| 利益が残る | ガーデン **$10.16** / ハウス **$19.22** |
| 価格競争力が出る | 買い手総額 $30.38。1ページ目の中央値$26.00 との差が **+32% → +17%**（`docs/27`） |
| **いま必要なのは利幅ではない** | **0件・レビュー0。最初の1件とレビューの方が$3の利幅より価値がある** |

50%（$20.00・総額$26.39）なら中央値と並ぶが利益が$6.55まで落ちる。
**年に一度の最大イベントなので40%で勝負し、それでも動かなければニッチ自体の判断でよい。**

## ⚠ 10/27〜11/22 に定価へ戻る穴がある

**いまの30%セールは約10月27日で切れる**（30日で設定したため）。
サイバーセールは**11月23日から**。

```
10/27  いまの30%セールが切れる
  ↓
       ★約1か月、$39.99 の定価に戻る
       1ページ目で突出して高い（競合の表示中央値は$22.49）
  ↓
11/23  サイバーセール開始
```

**10月27日に30%セールを掛け直すこと（11月22日まで・5商品）。**

## タオルをどうするか（任意）

5商品だけを選ぶと、タオル9商品はサイバー期間も $19.99 のまま。
**25%なら利益$1.99で赤字にはならない**ので、別途 `Sales and discounts` から
タオルだけ25%のセールを掛ける手はある。ただし全期間0件の商品なので優先度は低い。
