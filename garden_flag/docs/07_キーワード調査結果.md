## 読み取れること

### ① 基準線は「二極化」していて、新規に勝ち目がない

`christmas garden flag` の上位8件は **225〜618 の小規模が4件、10,000〜29,800 の巨大が4件**。
巨大ショップが半分の枠を恒久的に押さえている。**ここは捨てて正解。**

### ② クラスタA（ゴルフ×クリスマス）は巨大ショップがほぼ不在

**A1・A3・A4 は 10,000超が1件もない。** 最大でも 3,700〜5,700。
これは「1ページ目の全枠に入れ替わりの可能性がある」ことを意味する。

特筆すべきは **A4（golf gift christmas garden flag）の最小値 26**。
**レビュー26件のショップが1ページ目にいる。**
OnePureStrikeはレビュー0だが、29,800のショップと戦うのと、26のショップと戦うのは別の話。

### ③ クラスタB（自虐系）は最も薄いが、大手が2件いる

B7 は中央値525・8件中6件が1,000未満・最小13 と、数字だけ見れば最良。
ただし 12,700 と 14,000 の大手が2件。上位2枠は固定されると見るべき。

なお B6 と B7 は **525 / 600 / 13 / 12,700 / 14,000 が共通**。
同じ商品群を拾っている＝ `funny` と `sarcastic` は実質同じ市場。片方を選べばよい。

## ⚠️ まだ判断できないこと（これが決定打になる）

### クラスタA の5語は、ほぼ同じ商品群を返している

5語すべてに **144 / 1,200 / 850 / 3,700** が出現、611が4語に出現。
つまり `golf christmas garden flag` も `golf santa garden flag` も、
**大差ない同じ商品リストを表示している。**

解釈が2通りあり、**どちらかで結論が正反対になる**。

| 解釈 | 意味 | 打ち手 |
|---|---|---|
| **(a) 供給が薄い** | ゴルフ×クリスマスの商品が市場にほとんど無い | **最大のチャンス。即作る** |
| **(b) 需要が無い** | その語で検索する人がいないので、Etsyが関連の薄い一般商品で埋めている | **参入しても客が来ない。捨てる** |

**レビュー数は「競合の強さ」を測るが、「需要の有無」は測れない。**
この切り分けをしないまま作ると、ゴルフタオルと同じことになる。

### 切り分けに必要な2つのデータ

1. **オートコンプリートに出るか**
   検索窓に途中まで打ったとき、候補に出るか。
   **Etsyは実際に人が打っている語しか候補に出さない。** これが需要の直接証拠。

2. **上位8件の「中身」**
   上位8件のうち、**本当にゴルフとクリスマスの両方の要素がある商品**は何件か。
   - 多い → (a)。その語にマッチする商品が実在し、市場が成立している
   - ほとんど無く、ただのクリスマスフラッグやゴルフ用品ばかり → (b)。死んだ語

# 追加調査：Etsy外部からの需要検証（2026-09-16）

Etsyは僕の実行環境から直接読めないため、**Etsyのmarketページの存在**と
**他の小売市場での商品実在**から需要を推定した。

## Etsyのmarketページ（`etsy.com/market/<語>`）

Etsyは**検索ボリュームのあるクエリに対して自動的にmarketページを生成する。**
ページの存在は、その語が実際に検索されていることの傍証になる。

### 存在が確認できた

| ページ | 意味 |
|---|---|
| `/market/golf_garden_flag` | **「ゴルフ×ガーデンフラッグ」は検索されている** |
| `/market/golf_flags` | 〃 |
| `/market/golf_flag_welcome` | 「ゴルフ×Welcome」は独立したサブジャンル |
| `/market/custom_golf_flags` | 名入れゴルフフラッグも成立 |
| `/market/golf_flags_for_the_backyard` | 〃 |
| `/market/christmas_garden_flag` | 「クリスマス×ガーデンフラッグ」も検索されている |
| `/market/holiday_garden_flags` | 〃 |

### 確認できなかった

**`golf christmas garden flag` に相当するmarketページは見つからなかった。**

`golf_garden_flag` と `christmas_garden_flag` が**それぞれ単独では存在するのに、
掛け合わせのページが無い。**

※ 検索エンジンの索引が網羅的とは限らないため、これは「存在しない証明」ではない。
ただし、レビュー数調査で判明した**「クラスタA 5語がほぼ同じ商品群を返す」**という
事実と合わせると、解釈(b)＝**需要が無い語**である可能性が高いと判断する。

## ここから導かれる結論

### 「ゴルフ×ガーデンフラッグ」は需要が確認できる。「ゴルフ×クリスマス」は確認できない。

そして最も重要な点：

> **クリスマス仕様にしなくても、ゴルフのガーデンフラッグは12月にギフトとして買われる。**

Amazonの出品者が実際にそう訴求している。つまり、**クリスマスのモチーフを入れなくても
12月のギフト需要は捕まえられる。**

### 推奨の変更

**クリスマス「テーマ」ではなく、通年で売れるゴルフ・ガーデンフラッグを、いま出す。**

| | クリスマス仕様 | 通年ゴルフ仕様 |
|---|---|---|
| 12月のギフト需要 | ○ | **○（同じく捕まえられる）** |
| 検索需要の裏付け | **✗ 確認できず** | **○ marketページ・Amazon両方で確認** |
| 1月以降 | **✗ 死に在庫** | ○ 売れ続ける |
| 本人の当事者性 | ○ | ○ |
| ゴルフタオルとのクロスセル | ○ | ○ |
| デザイン資産の転用 | ○ | **◎ トーンも世界観もそのまま** |
| 締切 | **9/30必達** | 急ぐが、外しても死なない |

**プランA（今季を狙う）の趣旨は満たしたまま、
「需要ゼロの語を狙う」という最大のリスクだけを外せる。**
