# 22. 公開手順（Printify → Etsy → 広告）

**この文書どおりに上から順に進めれば公開できる。**
判断が要る箇所には ⚠ を付けてある。そこだけ止まって考えればよい。

所要時間の目安：**1商品あたり25分 × 5商品 ＝ 約2時間。**
最初の1商品に時間がかかるだけで、2商品目からは早くなる。

---

## 準備：手元に用意するもの

| # | もの | どこにあるか |
|---|---|---|
| 1 | 入稿データ5枚（3900×5700 PNG・名入れ「THE SMITHS」） | リポジトリ `garden_flag/upload/` |
| 2 | 出品画像 35枚（7枚 × 5商品） | このリポジトリ `garden_flag/listing/` |
| 3 | タイトル・タグ・説明文 | このリポジトリ `garden_flag/docs/21_出品文言.md` |

### 出品画像をPCに落とす

GitHubの画面から**フォルダごと**は落とせないので、リポジトリ全体をZIPで取る。

```bash
start https://github.com/golfbacca/laughing-spoon/archive/refs/heads/claude/great-mayer-lissxp.zip
```

ZIPを展開すると `garden_flag/listing/` の中に商品ごとのフォルダが5つある。
**ファイル名の先頭が 1〜7 の番号になっている。その順にEtsyへ上げる。**

## 第1部：Printify で商品を作る（5回くりかえす）

### 1-1. 商品を開く

```bash
start https://printify.com/app/products
```

1. 画面左上の紫のボタン **「Create product」** を押す
2. 検索窓に **`Garden and House Banner`** と打つ
   ⚠ **「garden flag」では出てこない。** 商品名は "Banner" になっている
3. 出てきた商品の画像を押す

### 1-2. 製造元とサイズを選ぶ

4. Print Provider の一覧から **「Pic The Gift」** を選ぶ
   （これ以外の選択肢は無い。`docs/10` で確認済み）
5. サイズは **「12" x 18"」と「24.5" x 32"」の両方にチェック**を入れる
   （2026-09-23 変更。原価が判明し、2サイズで出すほうが明確に有利。`docs/25`）

   チェックを入れると **Print area size が 7800 × 10012 px に変わる**ことを確認する。
   Printifyは**印刷エリアを1つしか持たない**ので、1枚の画像が両サイズに使われる。
6. 右下の **「Start designing」** を押す

### 1-3. デザインを載せる

7. 左の **「Upload」** タブ →「Upload your artwork」
8. 入稿データを選ぶ。
   ⚠ **`house/` の 7800×10012 の方を使う**（例 `R09_SMITHS_house_7800x10012.png`）。
   3900×5700 を載せると **24.5"×32" で上下が各2.31インチ切れる**（`docs/25` 第4節）。
   7800×10012 なら**両サイズとも正しく出る**（実測で確認済み）。
9. 載ったら、右側の **「Scale」を 100%** に合わせ、
   **画像がキャンバス全体を覆っている**ことを目で確認する
   ⚠ 四隅に白い隙間があってはいけない。あったら Scale を上げる
10. 左下の **「Preview」** を押して仕上がりを見る。
    ★ **12"×18" と 24.5"×32" の両方**を切り替えて確認すること。
    どちらかで絵が切れていたら保存せず、画面を送ってほしい
11. ⚠ プレビュー画面の **「現実的（CMYK）」** に切り替える
    （初期値のRGBは実物より鮮やかで、**届いた物とのギャップが低評価になる**）
12. 右上の **「Save product」**

**これを5商品ぶん繰り返す。** 保存だけしておき、Etsyへの公開はまだしない。

## 第2部：Etsy に出品する（5回くりかえす）

Printify の商品一覧から **「Publish」** を押すとEtsyに下書きが作られる。
**Printify側で入れた文言はあとでEtsy側が上書きするので、ここでは気にしなくてよい。**

```bash
start https://www.etsy.com/your/shops/me/tools/listings
```

下書きを開いて、次を上から順に埋める。

### 2-1. 写真（Photos）

- `garden_flag/listing/<商品フォルダ>/` の中の **1〜7 を番号順に**ドラッグする
- ⚠ **1枚目が検索結果に出るサムネイル。** ここを間違えないこと
- Printifyが自動で入れた写真があれば**すべて削除する**
  （既製モックアップは競合と同じ絵になる。`docs/15` の指摘☆9）

### 2-2. タイトル（Title）

`docs/21_出品文言.md` の該当商品のタイトルをそのまま貼る。

### 2-3. About this listing

| 項目 | 選ぶもの |
|---|---|
| Who made it | **A member of my shop** |
| What is it | **A finished product** |
| When did you make it | **Made to order** |

### 2-4. カテゴリ（Category）

`Home & Living` → `Outdoor & Gardening` → `Garden Flags`

### 2-5. 説明文（Description）

`docs/21_出品文言.md` 第6節の英語をそのまま貼る。
**決め台詞の1行だけ、その商品のものに差し替える。**

### 2-6. 名入れ設定（Personalization）⚠ ここが最重要

1. **「Personalization」のスイッチをONにする**
2. 「Personalization instructions for buyers」に貼る：

```
Enter your family name - for example: SMITH
It will be printed as "THE SMITHS". Any length fits.
```

3. **「Required」（必須）にチェックを入れる**
   ⚠ 任意にすると空欄で注文が来て、作業が止まる

### 2-7. 価格と在庫

| 項目 | 値 |
|---|---|
| Price | **39.99** |
| Quantity | 999 |

保存したあと、**Shop Manager → Marketing → Sales and discounts** で
**30% OFF のセール**を全商品に掛ける。→ 表示が **$27.99** になる。

⚠ **定価$39.99のまま出すと「割引なし」に見えて不利。**
Etsyの検索結果はセール表示だらけなので、消し線が付いている方が押される（`docs/16`）。

### 2-8. 送料（Shipping）

| 項目 | 値 |
|---|---|
| Processing time | **1-3 business days** |
| Ship from | United States |
| US 送料（1点目） | **6.39** |
| US 送料（2点目以降） | **1.99** |

⚠ 2点目 $1.99 を入れ忘れると、2枚買いの利益が出ない（`docs/10`）。

### 2-9. タグ（Tags）

`docs/21_出品文言.md` のタグ行を**カンマ区切りのまま丸ごとコピーして、
タグ欄に1回貼る。** Etsyがカンマで切って13個に分けてくれる。

⚠ もし分かれずに1個の長いタグになってしまったら、
**貼ったものを消して、1個ずつ入れて都度 Enter を押す。**
（カンマ区切りが効くかはEtsyの画面の版による）

Etsyのタグは20字までだが、**13個とも20字以内で作ってある**ので、
どちらの入れ方でも弾かれない。

### 2-10. 公開

⚠ **ここで止まる。5商品すべてが上の項目を埋め終わってから、まとめて公開する。**
1商品ずつ公開すると、広告の開始日がばらばらになって比較できなくなる。

## 第3部：Etsy Ads を入れる（5商品を公開した直後）

```bash
start https://www.etsy.com/your/shops/me/advertising
```

1. **「Start advertising」** を押す
2. Daily budget に **`3`** と入れる（＝ $3/日）
3. 広告する商品の一覧で、**この5商品だけをON**、他はすべてOFF
   ⚠ ゴルフタオル9商品は入れない。予算が割れる
4. **Offsite Ads は触らない**（売上$10k未満なので任意。オフのまま）
5. **「Start advertising」** を押して確定

**総額 $90／30日。** 30日経ったら自分で止めること（自動では止まらない）。

### 撤退ライン（`docs/18` で先に決めてある）

| 30日後の販売件数 | 判断 |
|---|---|
| 0〜1件 | このニッチは成立しない。**撤退** |
| 2〜4件 | 写真・説明文・価格を直して再挑戦 |
| 5件以上 | 継続。予算を$5/日に上げる |

## 第4部：注文が来たときの作業

名入れ注文は**Printifyが自動では作れない。** 毎回この手順を踏む。

1. Etsyの注文画面で、買い手が入力した名字を見る（例 `JOHNSON`）
2. PCのターミナルで：

```bash
python3 make_name_flag_r.py JOHNSONS
```

※ 末尾に **S を付ける**（`THE JOHNSONS` になる）。
※ 既に S で終わる名字（例 `ROGERS`）は `ROGERSES` ではなく **`ROGERS`** のまま。
※ 5案すべての画像が一度に出る。**必要なのは注文された1案だけ。**

3. Printify の該当商品で **「Edit design」** → 新しい画像に差し替え
4. 注文を Printify に送る

⚠ **ここは自動化していない。** 注文が増えたら仕組みを作る。
いまは月に数件の想定なので、手作業で足りる。

## 公開後にやること（毎週）

`docs/18_広告計画.md` に追記する。

- 表示回数 / クリック数 / 実CPC / 販売件数
- **Etsy Adsが見せた検索語の上位10語** ← これが一番価値がある
- 5案それぞれのクリック率

### 公開1週間後の価格調整（`docs/16` で先に決めてある）

| 実CPC | 対応 |
|---|---|
| $0.35超 | 表示を **$29.99** に上げる（定価$42.99の30%off） |
| $0.20〜$0.35 | **$27.99** のまま |
| $0.20未満 | **$24.99** に下げて転換率を取りにいく |
