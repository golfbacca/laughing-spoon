| 注文 / 売上 | 0 / $0.00 |

**検索結果に出ていないことが確定した。**
デザイン・価格・写真・説明文は、まだ一度も評価の土俵に上がっていない。

さらに切り分けテスト（2026-09-16実施）の結果：
**Etsy検索で商品タイトルを完全一致で入れると、自分の商品は出る。**
→ インデックスは正常。構造的な不具合ではなく、**純粋に順位が低くて埋もれている**。

**そして最大の教訓：「ニッチを狙う」戦略は正しかったが、適用先を間違えていた。**

- ニッチ性を効かせたのは**デザインのコンセプト**
- 一方で狙った**検索語は激戦区の一般語**（funny golf towel / golf gift for dad）
- 結果、検索に出ないのでデザインのニッチ性が誰にも届かない

**正しい適用先は検索語のほう。** 競合が数十件しかないロングテール語なら
新規ショップでも1ページ目に入れる。デザインはその語に合わせて作る。

## 前回案件（ゴルフタオル）から引き継ぐ進め方

Drive上のプロンプト履歴から復元した、機能していた分担：

- 画像生成は**別AI（Gemini / Nano Banana Pro）**に投げる。Claudeは構図ブリーフと英語プロンプトを作る側に回る
- 各パターンは**新規チャット**で生成する（文脈汚染を避けるため）
- 生成後は**スペルミス・文字崩れ・余白・ロゴ混入**を必ずチェックする
- 出品作業で詰まったら、Claudeが「どのボタンを押すか」「何を入力するか」レベルまで細分化して指示を出す
- **パスワード入力・購入・公開・投稿・設定変更はClaudeが勝手にやらない。必ず本人に確認して止まる**

## 引き継がない進め方（診断の結果、変更したもの）

- ~~ニッチを決めてからデザインする~~ → **キーワードを確かめてからデザインする**
- ~~1デザインだけ作って様子を見る~~ → **複数バリエーションを同時に出す**
- ~~タイトルにジョークを入れる~~ → **ジョークは画像の中。タイトルは検索語だけ**
- ~~広告なしでオーガニックを待つ~~ → **少額広告で最初の露出を買う**
