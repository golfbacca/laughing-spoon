# Garden Flag（米国Etsy向け・クリスマス／ウィンター）

Printifyで製造し、Etsyで米国向けに販売するガーデンフラッグ案件。
既存ショップ **OnePureStrike**（ゴルフ自虐タオルで開設済み）を使う想定。

## 進行状況（2026-09-16 時点）

- 方向性決定：**クリスマス／ウィンター系で新規デザイン**
- 商品仕様の一次調査済み → `docs/01_商品仕様_Printify.md`
- 市場と差別化方針の整理済み → `docs/02_市場と差別化方針.md`
- **既存ゴルフタオルの実績を診断済み → `docs/04_ゴルフタオル実績の診断.md`**

### 最重要の発見

既存のゴルフタオル4商品は、**最も見られている商品でも週の閲覧数が1**、
ショップ全体の週間訪問者数が1〜4、販売実績ゼロ。

**売れない原因はデザインではなく「検索結果に表示されていないこと」。**
同じ進め方でガーデンフラッグを出すと、同じ結果になる。

そのため本案件は**作り方の順番を変える**：

```
【旧】 ニッチ決定 → デザイン → 出品 → 検索されず埋もれる
【新】 キーワード調査 → 勝てる語を特定 → その語に合わせてデザイン → 出品
```

### いま止まっている理由（次に解消すべきもの）

| # | 止まっているもの | 解消方法 |
|---|---|---|
| 1 | **どのキーワードなら勝てるか** | 本人がEtsy Shop Manager → Stats → Traffic → Search terms を開いて現状の実数を取る。加えてキーワード調査（eRank等） |
| 2 | Printifyの実原価・print area実寸 | 本人がProduct Creatorを開いて数値を読む（`docs/01` のチェックリスト） |
| 3 | 前回ゴルフタオルの成果物 | 別のAIチャットに残存。タグ13個・説明文・20パターンブリーフをコピペで回収 |
| 4 | Etsy Ads を回すかどうか | 販売ゼロを抜けるには最初の露出を買う必要がある。1日$1〜3の可否を判断 |

## スケジュール（Etsyの「3ヶ月前ルール」から逆算）

クリスマス商材は**9月中に公開**が定石。10月に入ると検索順位が育つ前に商戦が終わる。

| 時期 | やること |
|---|---|
| 9/16〜9/18 | **キーワード調査**（最優先）＋ Printify原価確定 ＋ 過去資産の回収 |
| 9/19〜9/22 | 勝てる語に合わせて構図ブリーフ作成 → Nano Banana Proで画像生成 → アップスケール＋白レベル補正 |
| 9/23〜9/26 | モックアップ、英語タイトル・タグ13個・説明文（**全語を検索語で埋める**） |
| 9/27〜9/30 | Printifyで商品作成 → Etsyへ公開（**1点ではなく5〜10バリエーション**）→ Etsy Ads開始 |
| 10月〜11月 | Pinterest投稿。反応を見て追加。11月がピーク |

**9/30を過ぎたら、今季クリスマスは捨てて通年商材に切り替える判断をする。**

## 前回案件（ゴルフタオル）から引き継ぐ進め方

Drive上のプロンプト履歴から復元した、機能していた分担：

- 画像生成は**別AI（Gemini / Nano Banana Pro）**に投げる。Claudeは構図ブリーフと英語プロンプトを作る側に回る
- 各パターンは**新規チャット**で生成する（文脈汚染を避けるため）
- 生成後は**スペルミス・文字崩れ・余白・ロゴ混入**を必ずチェックする
- 出品作業で詰まったら、Claudeが「どのボタンを押すか」「何を入力するか」レベルまで細分化して指示を出す
- **パスワード入力・購入・公開・投稿・設定変更はClaudeが勝手にやらない。必ず本人に確認して止まる**

## 引き継がない進め方（診断の結果、変更したもの）

- ~~ニッチを決めてからデザインする~~ → **キーワードを確かめてからデザインする**
- ~~1デザインだけ作って様子を見る~~ → **複数バリエーションを同時に出す**
- ~~タイトルにジョークを入れる~~ → **ジョークは画像の中。タイトルは検索語だけ**
- ~~広告なしでオーガニックを待つ~~ → **少額広告で最初の露出を買う**
