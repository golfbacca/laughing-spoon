## スケジュール（Etsyの「3ヶ月前ルール」から逆算）

クリスマス商材は**9月中に公開**が定石。10月に入ると検索順位が育つ前に商戦が終わる。

| 時期 | やること |
|---|---|
| 9/16〜9/17 | ニッチ確定 ＋ Printify原価確定 ＋ 過去資産の回収 |
| 9/18〜9/21 | 構図ブリーフ作成 → Nano Banana Proで画像生成 → アップスケール＋白レベル補正 |

## 前回案件（ゴルフタオル）から引き継ぐ進め方

Drive上のプロンプト履歴から復元した、機能していた分担：

- 画像生成は**別AI（Gemini / Nano Banana Pro）**に投げる。Claudeは構図ブリーフと英語プロンプトを作る側に回る
- 各パターンは**新規チャット**で生成する（文脈汚染を避けるため）
- 生成後は**スペルミス・文字崩れ・余白・ロゴ混入**を必ずチェックする
- 出品作業で詰まったら、Claudeが「どのボタンを押すか」「何を入力するか」レベルまで細分化して指示を出す
- **パスワード入力・購入・公開・投稿・設定変更はClaudeが勝手にやらない。必ず本人に確認して止まる**
