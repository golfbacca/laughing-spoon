# SUZURIステッカー シリーズ「中身が見えていた時代」

平成10年代（1998–2008）のハードウェアを、ノートPC・水筒・手帳に貼るためのステッカー。

4枚とも「中身が見えていた／触れた」ものでできている。いまのデバイスは全部密閉されていて、
中身は見えないし触れない。そこが通し概念。

## 4枚

| 順 | ディレクトリ | モチーフ | 役割 |
|---|---|---|---|
| 1 | `mouse_underside/` | 裏返したマウスのボール | 起点。出品中 |
| 2 | `floppy_shutter/` | 半分開いたフロッピー | 再購入に最も効く |
| 3 | `cdr_surface/` | CD-Rの記録面 | 水筒という別の入口 |
| 4 | `skeleton_gadget/` | 中身が透けるスケルトン | 新規層に広げる。**権利リスクあり／要判断** |

4枚目は実在製品に似せるほど刺さり、似せるほど事故に近づくという緊張がある。
差し替え候補（MD）を含めた判断材料は `docs/SUZURI_横展開3枚_出品一式.txt` に書いた。

## 各ディレクトリの中身

| ファイル | 内容 |
|---|---|
| `prompt.txt` | 画像生成用の英語プロンプト |
| `raw.png` | 生成AIが出した元画像（**自分で保存する**） |
| `sticker.png` | 入稿用の透過PNG（スクリプトが生成） |

## 手順

```
# 1. prompt.txt で画像を生成し、raw.png として保存する
# 2. 地を抜いて透過PNGにする（白フチはそのまま残す設定）
python3 tools/suzuri_cutout.py suzuri/<名前>/raw.png -o suzuri/<名前>/sticker.png
```

スクリプトには Pillow と numpy が要る。

```
python3 -m pip install Pillow numpy
```

## ドキュメント

| ファイル | 内容 |
|---|---|
| `docs/SUZURI_マウス裏_出品一式.txt` | 1枚目の商品名・説明文・タグ・トリブン・権利チェック |
| `docs/SUZURI_マウス裏_入稿手順.txt` | 画像の置き場所から公開までの手順（4枚とも使い回す） |
| `docs/SUZURI_横展開3枚_出品一式.txt` | 2〜4枚目の設計と出品文 |

## 守っていること

- 実在キャラ・企業ロゴ・ブランド・芸能人・既製書体を使わない
- 画像内に文字を入れない（実在メーカー名に読めた瞬間に事故る）
- 原価・販売価格・振込手数料・最低申請額・入金日数は**書かない**。
  変動する数字なので、SUZURIの管理画面で自分の目で確認する
- 画像生成AIの規約が商用利用可かは、自分で規約本文を読んで確認する
